## 1. 今天解决什么问题，与前面哪些单元有关

一步目标里有两种不同问题。第一种是：后继状态已经给定，但 SARSA 还要抽一次下一动作，目标会随它变化。第二种是：动作价值估计带噪声，用同一组估计既挑最大动作又评价它，可能偏向挑中被高估的值。

Expected SARSA 对给定策略的下一动作做加权求和，处理第一种抽样噪声。Double Q-learning 分别维护两张估计表，用一张选动作、另一张评这个动作，处理第二种选择与评价的耦合。它们没有消除所有不确定性，也不自动解决前课的覆盖、反馈和行为成本问题。

今天先用相同 pre 表独立比较三个单表目标，再另起两张表演示 Double Q，最后用一个独立噪声枚举解释最大化偏差。三组材料不能顺序串写，也不能把一个手算目标较小称为真实改进。

建议用约 12 分钟学 Expected SARSA 与条件方差，约 12 分钟学 Double Q 与噪声例子，再用余下时间检查边界、应用与三题。完整收敛条件留给 RL-019。

## 2. 学习目标

1. 能计算 Expected SARSA 的下一动作期望、目标与单项写入，并准确说明它消除的是哪一个条件下的动作抽样分量。
2. 能按 Double Q 的 A/B 两个对称更新支，区分选动作表、评价表与实际写入表，解释两张存储表为何不自动统计独立。
3. 能用有限噪声枚举区分无偏的单个估计与带偏的最大值，说明独立性、合法动作、终止和真实研究证据的限制。

## 3. 直觉、定义和必要公式

### 3.1 Expected SARSA：已知后继上的动作期望

沿用完整状态 x=(page,h)。一次转移中，x 是动作前状态，a 是已执行合法动作，r 是即时奖励，x′ 是真实后继；A(x′) 是已知非空合法动作集合，u 是其中的候选动作。Q_pre 是当前写入前的估计表，π(u|x′) 是本次目标使用的策略概率，须合法、已知且在 A(x′) 上归一化。

对非终止后继，Expected SARSA 先算：

\[
\overline Q_{\pi}(x')=
\sum_{u\in A(x')}\pi(u\mid x')Q_{\mathrm{pre}}(x',u).
\]

横线表示对**下一动作**求期望，竖线表示给定状态，不是在这里对所有后继和奖励求完整模型期望。令 d=1 表示原任务真终止，否则 d=0；γ 为折扣，本课 0.9；α 为步长，本课 0.5：

\[
y_{\mathrm{ES}}=
\begin{cases}
r,&d=1,\\
r+\gamma\overline Q_{\pi}(x'),&d=0,
\end{cases}
\quad
\delta=y_{\mathrm{ES}}-Q_{\mathrm{pre}}(x,a),
\quad
Q_{\mathrm{post}}(x,a)=Q_{\mathrm{pre}}(x,a)+\alpha\delta.
\]

ES 是 Expected SARSA 的缩写。pre/post 是本次写入前后，只改当前状态动作对；即使存在自转移，也先从 pre 表读完再写。α 控制改变量，不是本课的访问次数倒数。δ 是含估计量的目标差，不是真实价值误差。

本例设目标策略 π 等于实际行为 b，二者均为当前快照的 ε-greedy，因此是 on-policy 用法。一般也可以指定与行为不同的目标 π；Expected SARSA 并非始终 on-policy。必须明说目标策略，不能把未知动作概率当作已知的精确期望。[公式与一般策略用法见教材 §6.6，式 6.9。](https://www.andrew.cmu.edu/course/10-703/textbook/BartoSutton.pdf)

### 3.2 条件方差减少的准确范围

把 r、x′、Q_pre、π 固定，仅令下一动作 A′ 按 π 抽取。SARSA 的随机目标为 r+γQ_pre(x′,A′)，Expected SARSA 的目标等于它在这些条件下的期望，不需再抽一个 A′ 来构造当前目标。

因此减少的是**给定后继与快照后的下一动作抽样噪声**。若奖励和后继本身随机，不同运行的估计表或策略不同，Expected SARSA 仍会变化；Q 估错、策略概率估错或数据缺失也不会被求和自动修正。对全部目标方差、估计器偏差或实际性能，不能无条件宣布为零或更优。

当前实际下一动作依然由行为策略执行。Expected SARSA 的当前目标不要求它先被抽出；不能把求和中的每个动作都当成已经执行，更不能编造未执行动作的奖励。

### 3.3 最大化偏差与 Double Q

Q-learning 用估计值的最大值构造后继项。即使每个动作估计单独无偏，最大值也未必是最大真实价值的无偏估计，因为选择更容易留下正误差。这里的 bias 是相对明确真值，在假设分布上对估计误差取期望；单张表里某个差值不能直接叫作统计偏差。

Double Q 分别维护 Q^A、Q^B；上标 A、B 是表的名称，不是幂。通常每条有效转移使用一个与转移样本独立的公平随机分支选择，只更新 A 或 B 中的一个。教学演示会人为指定 A 支，不把它称为一次真实抛硬币。

对非终止转移，A 支从 Q^A_pre 的合法最大集合中选定一个动作 a_A*，再用 Q^B_pre 评价**同一个动作**：

\[
\begin{aligned}
a_A^*&\in\arg\max_{u\in A(x')}Q^A_{\mathrm{pre}}(x',u),\\
y_A&=r+\gamma Q^B_{\mathrm{pre}}(x',a_A^*),\\
Q^A_{\mathrm{post}}(x,a)
&=Q^A_{\mathrm{pre}}(x,a)+\alpha\big[y_A-Q^A_{\mathrm{pre}}(x,a)\big],
\qquad Q^B_{\mathrm{post}}=Q^B_{\mathrm{pre}}.
\end{aligned}
\]

对称的 B 支交换角色：

\[
\begin{aligned}
a_B^*&\in\arg\max_{u\in A(x')}Q^B_{\mathrm{pre}}(x',u),\\
y_B&=r+\gamma Q^A_{\mathrm{pre}}(x',a_B^*),\\
Q^B_{\mathrm{post}}(x,a)
&=Q^B_{\mathrm{pre}}(x,a)+\alpha\big[y_B-Q^B_{\mathrm{pre}}(x,a)\big],
\qquad Q^A_{\mathrm{post}}=Q^A_{\mathrm{pre}}.
\end{aligned}
\]

argmax 表示取得最大值的动作集合；本课并列时在该集合中均匀选一个，并用另一表评价这一已选动作，不能在评价表里另取一个 max。星号标识本次被选动作，不证明它是真正最优动作。两支都使用本条转移写入前的快照；没有一次转移先 A 后 B 的隐含双更新。

实际行为可以对 Q^A+Q^B 的合法动作值采用 ε-greedy。行为如何选动作、当前转移更新哪张表、后继目标如何构造，是三个应分别记录的选择。Double Q 不是把两个 max 平均，也不是重复训练两个完整模型再投票。[教材 §6.7 式 6.10 与原论文 Algorithm 1 给出了此结构。](https://proceedings.neurips.cc/paper_files/paper/2010/file/091d584fced301b442654dd8c23b3fc9-Paper.pdf)

两张表可从相同初值开始，例如都为 0；问题不在于初值必须不同。它们要分别维护、按不同更新支获得经验，而不是每次同步复制。两表因共享任务、行为和自举而可能相关，**分别存储不自动等于统计独立**。独立评价的简化性质只在相应假设下成立，不能据此称实际 Double Q 总无偏、没有低估或必然提升。

### 3.4 终止、mask 与外部截断

真终止时，两种方法都直接取 y=r，保留进入终态的奖励；不做下一动作求和或 argmax，不读取终止空动作表。Double Q 仍只写选中的一张表。任务本身规定 h=0 结束，与采集器外部停止要分开。

| 非终止当前目标所需条件 | Expected SARSA | Double Q |
|---|---|---|
| 原任务真实旧后继与合法 mask | 必须有效 | 必须有效 |
| 写入前估计 | 同一 Q_pre，包含合法动作估计 | Q^A_pre 与 Q^B_pre，保持本次读取一致 |
| 目标相关选择 | 有效、已归一化的目标 π | 已声明的 A/B 更新支与合法平局规则 |
| 是否需要已选下一行为动作或实际续接 | 不需要 | 不需要 |

外部截断但原任务按定义继续、上述资料有效时，可完成该一步目标，不要求未来真实续接。若后继、mask 或所需 π 缺失，保留原因并**跳过本次 Q 和更新计数写入**；不能把 reset 新图当旧后继，不能靠伪造终止或动作概率补算。失败、截断和缺失记录保留，不只挑成功完整样本再无条件声称对同一目标无偏。

## 4. 手算例子或更新过程

### 4.1 沿用教学核，所有比较从明确初表开始

H 为主页、F 为表单页、z 为终止；完整状态 (page,h)，h≤2，每动作消耗一次预算，h=0 真终止。Hopen 奖励 −1，预算可继续则到 F；Hstop 为 0 并终止。Fsave 以 0.8 概率得 10、以 0.2 概率得 0，均终止；Fcancel 为 0 并终止。没有额外 F 操作成本或终止加分。

以下是人工指定的教学转移与快照，没有随机采样或真实 GUI。γ=0.9、α=0.5。Expected SARSA 主表从 H2 的 open=1、stop=0，F1 的 save=4、cancel=−2 开始；这些是猜测，不继承前课最终表。ε=0.2、唯一贪心的全合法探索给 π(Fsave)=0.9、π(Fcancel)=0.1，π=b。本条观察为 H2 执行 open、r=−1 到 F1，尚未结束。

### 4.2 Expected SARSA 主例与独立目标对照

| 同一原始 pre 表上的量 | Expected SARSA | Q-learning 独立对照 | SARSA 独立对照，已选 cancel |
|---|---:|---:|---:|
| 后继项 | 0.9×4+0.1×(−2)=3.4 | max(4,−2)=4 | −2 |
| 目标 y | −1+0.9×3.4=2.06 | 2.6 | −2.8 |
| 误差 δ，当前 pre=1 | 1.06 | 1.6 | −3.8 |
| 当前项 post，α=0.5 | 1.53 | 1.8 | −0.9 |

三列用三份相同初表独立计算，不把 1.8、−0.9 接在 1.53 后继续写，也不按目标数值大小宣布算法排名。3.4 是策略加权的估计，2.06 是一步目标，1.53 是写入后估计；它们都不等于已知真实价值。

继续 ES 主例，若人为指定下一实际行为为 cancel，得到 r=0 到 z，则目标为 0，Fcancel 从 −2 写为 −1，H2,open 不自动回写。最终 ES 表按 Hopen、Hstop、Fsave、Fcancel 顺序为 1.53、0、4、−1，两个被更新的对各写一次，其他仍为初值。实际奖励 −1、0 给完整 G_H2=−1、G_F1=0。ES 的当前目标不需要事先选定 cancel，这里也没有执行 save 或观察其奖励。

### 4.3 只随机下一动作时，究竟消除了多少方差

固定条件 C 为 r=−1、x′=F1、Q_pre(Fsave,Fcancel)=(4,−2)、π=(0.9,0.1)。仅重新抽下一动作，SARSA 的目标取 2.6 或 −2.8，概率分别 0.9、0.1；其条件均值为 2.06：

\[
\begin{aligned}
\operatorname{Var}(Y_{\mathrm{SARSA}}\mid C)
&=0.9(2.6-2.06)^2+0.1(-2.8-2.06)^2=2.6244,\\
\operatorname{Var}(Y_{\mathrm{ES}}\mid C)&=0.
\end{aligned}
\]

大写 Y 表示在这个假设随机机制中的目标随机变量，C 表示上述固定条件，Var 是围绕其条件均值的方差。这里没有把奖励或后继再次抽取，也没有让 Q 与 π 随训练改变。ES 对下一动作的精确求和是 SARSA 在这些条件下的平均方向；这个 0 不能改写成“所有训练目标方差为 0”或“真实价值估计无偏”。

### 4.4 Double Q 的另一对初表与 A 支

下面另起一对**分别维护的教学表**，不沿用 ES 的 1.53，也不声称这些给定数值来自两个统计独立训练过程：

| 状态动作 | Q^A_pre | Q^B_pre |
|---|---:|---:|
| H2,open | 1 | 0 |
| H2,stop | 0 | 0 |
| F1,save | 4 | 1 |
| F1,cancel | −2 | 5 |

行为可用两表和的 ε-greedy：Fsave 的和为 5，Fcancel 为 3，ε=0.2 时概率为 0.9、0.1。它与 A/B 更新支选择分开。对同一条 H2 open、r=−1 到 F1 的观察，**人为指定 A 支**：

| A 支步骤 | 计算 |
|---|---|
| 从 Q^A_pre 选后继动作 | save，因为 4>−2 |
| 用 Q^B_pre 评价这一动作 | Q^B_pre(F1,save)=1，不取其最大值 5 |
| 目标 y_A | −1+0.9×1=−0.1 |
| 当前项误差 | −0.1−1=−1.1 |
| Q^A(H2,open) 的 post | 1+0.5×(−1.1)=0.45 |
| 另一表及其他表项 | Q^B 全部不动；Q^A 其他项不动 |

主演示只更新这一个 A 表项，其更新计数增一次，B 表更新计数不增。没有把 0.45 当成任务成功、低偏差或更好的实际策略。

作为**独立的同原始 pre 对称支核对**：如果本次选 B 支，先按 Q^B 选 cancel=5，再用 Q^A 的 cancel=−2 评价，得到 y_B=−2.8。当前 Q^B(Hopen)=0，所以 Q^B 的 post=0+0.5×(−2.8)=−1.4；Q^A 的 Hopen 仍为 1。这不接在 A 支的 0.45 之后，也不把两个支合并为本次实际双更新。

### 4.5 独立噪声枚举：无偏估计的 max 可以有偏

这是**独立于 GUI 的估计量教学分布**。两个动作真实价值均为 0。X1、X2 是各自的估计，彼此独立，均以概率 1/2 取 +1 或 −1，因此每个单独估计的期望为 0：

| X1 | X2 | 联合概率 | max(X1,X2) |
|---:|---:|---:|---:|
| 1 | 1 | 1/4 | 1 |
| 1 | −1 | 1/4 | 1 |
| −1 | 1 | 1/4 | 1 |
| −1 | −1 | 1/4 | −1 |

max 的期望为 (1+1+1−1)/4=0.5，最大真实价值为 0，因此该假设分布下的最大估计有 0.5 的正偏差。这个结果对整个枚举取期望，不是把某个一次出现的正误差命名为 bias。

再引入另一组 Z1、Z2：整组 Z 与整组 X 独立，每个 Z 也按独立 ±1 各半、均值 0。按 X 的 argmax 选索引 I，并列时均匀选且选择随机性不使用 Z；再读 Z_I。给定由 X 选出的任何索引，Z_I 的条件均值仍为 0，所以其总期望为 0。完整的 X/Z 联合枚举有 4×4=16 种等概率组合；并列动作再按该规则计算条件平均，实际算法每次仍只选一个动作。

如果改成同步复制 Z=X，所选评价又等于 max(X1,X2)，本例均值仍为 0.5。它说明独立性/相关性条件为什么重要，不能据“有两个数组”宣布无偏。这里真值相等且评估噪声独立是特定假设；真值不同、选择错动作、估计相关或自举时，Double Q 仍可有误差甚至低估。原论文也说明双估计并非普遍无偏的最大期望估计器。[机制讨论见 van Hasselt 2010，§2～3。](https://proceedings.neurips.cc/paper_files/paper/2010/file/091d584fced301b442654dd8c23b3fc9-Paper.pdf)

### 4.6 Double Q 单转移伪代码

输入为真实当前状态动作、奖励、真终止标志和两张 pre 表；非终止还需有效原任务后继与合法 mask。以下仅说明控制流，**未运行（NOT_RUN）**：

```text
核验当前 x、已执行 a、实际 r 与 true_terminal；任一必需输入无效则保存原因并立即返回
若非真终止且旧 x_next 或 mask 缺失/无效：
    保存待核日志与原因；立即返回，不写 Q 或更新计数
J = 与该转移样本独立的公平分支选择，只取 A 或 B
old = 本次所选 J 表的 pre[x,a]
若真终止：target = r，不选后继动作
否则若 J=A：
    a_star = 从 QA_pre 的合法 argmax 中按规则选一个动作
    target = r + gamma*QB_pre[x_next,a_star]
否则：
    b_star = 从 QB_pre 的合法 argmax 中按规则选一个动作
    target = r + gamma*QA_pre[x_next,b_star]
只写 J 表的当前项：old + alpha*(target-old)，只增该表更新计数
另一张表与其他表项不动；记录 pre、分支、选中索引和评价值
```

真实终止优先决定直接奖励分支，缺少终止后的动作集合不影响它。Expected SARSA 的相应流程则检查目标 π，再求合法动作加权和；π 缺失或不合法时也立即跳过该次写入。两种流程都不能让 target 未定义却继续写 Q。

## 5. 与前一种方法的关系

| 方法或机制 | 后继项如何构造 | 本课重点与新增代价 |
|---|---|---|
| SARSA | 已选下一动作的 Q | 目标含下一动作抽样分量，需沿用该实际动作 |
| Q-learning | 合法 Q 最大值 | 行为可探索，估计的最大化可能耦合选择与正误差 |
| Expected SARSA | 给定目标 π 的合法 Q 加权和 | 去掉相应条件下的动作抽样分量，需已知动作概率并汇总合法动作 |
| Double Q | 一表 argmax，另一表评选中索引 | 分离选择评价，每转移只更新一表，需两表与明确分支规则 |

Expected SARSA 没有求掉环境转移、奖励和估计误差，也不保证当前贪心策略建立在正确 Q 上。Double Q 没有把实际行为变成无成本探索，也不自动获得覆盖。两种目标调整分别处理不同问题，名称里的 Expected 和 Double 都不是效果保证。

表格实现中，Expected SARSA 需要对合法动作求和；Double Q 通常存储两张表，并扫描所选表的合法动作、查询另一表的选中项，每转移仍只写一项。两表可以相同初始化，但不持续同步复制。动作候选很多、视觉编码昂贵或环境反馈缓慢时，真实训练与推理成本还包括采集、核验、模型前向、执行和恢复，不能从表格操作量推断业务时延或数据效率必然改善。

## 6. 一个主要研究应用

主应用选择**具有多步后果和可核验结果的 GUI 控制**。研究前应先判断：误差主要来自下一动作抽样、环境随机性、价值估计、动作合法性还是反馈缺失？本课未读取真实运行数据，不能替业务诊断哪一项占主导。若只是截图上的独立定位，先用监督定位或固定流程，不人为制造多步目标。

| 真实合同 | 研究前需要补齐的内容 |
|---|---|
| 1. 观测与完整状态 | 【待确认】指令、画面、结构信息、历史和预算，隐藏状态是否影响操作后果 |

## 7. 常见误解、失败条件和适用边界

| 误解 | 核查办法 |
|---|---|
| “Expected 意味着目标已经没有随机性” | 写出固定的 r、x′、Q_pre、π 与仅随机 A′；其他来源仍在 |
| “把 next Q 平均就行” | 按目标 π 加权并核验合法归一化；不是无条件算术平均 |
| “两个数组就等于两个独立无偏估计” | 区分存储分离与统计假设，核查复制、共享数据和自举相关性 |
| “A 支在 B 表取另一个 max，或平均两个 max” | 先记录 A 选出的索引，再只读 B 的同一动作值 |
| “一条转移顺便把 A、B 都更新” | 只取一个已声明分支；本课对称 B 是独立同 pre 核算 |
| “同初值非法，必须先训练两套模型” | 可以同初值，但分别维护和分支更新；不是两个完整训练流程 |
| “max 的一次正误差就是统计 bias” | 明确真值、估计分布、独立性与跨假设重复的期望 |
| “目标较小或方差分量为零就保证更好” | 检查实际目标、奖励、覆盖、相关性和评价成本，不能跳过真实证据 |

本课没有证明固定 α=0.5 的短记录必收敛，也没有将表格条件推广给任意神经网络。原论文的条件性收敛与有限样本偏差是不同问题；双估计还可能低估。更完整的覆盖、步长和收敛讨论留给下一课。

## 参考答案（练习完成后再看）

**题 1 参考答案。** 后继均值为 0.9×4+0.1×(−2)=3.4；y=−1+0.9×3.4=2.06，δ=2.06−1=1.06，post=1+0.5×1.06=1.53。三个目标列须从独立同 pre 表算，QL 为 2.6/1.8，已选 cancel 的 SARSA 为 −2.8/−0.9，不串写。

固定 r、x′、Q_pre、π，只随机 A′ 时，SARSA 的目标以 0.9 取 2.6、以 0.1 取 −2.8，均值 2.06；条件方差为 0.9×0.54²+0.1×(−4.86)²=2.6244。ES 对该随机动作精确求和，目标固定为 2.06，故这一条件方差为 0。它没有消除奖励转移、训练快照及估计误差，不证明真实价值无偏或实际表现更优。本例 π=b；一般 ES 可以用与行为不同的目标 π。

**题 2 参考答案。** A 支用 Q^A_pre 选 save=4，再读 Q^B_pre(F1,save)=1；不能改取 B 的 cancel=5。y_A=−1+0.9×1=−0.1，δ_A=−0.1−1=−1.1，Q^A_Hpost=0.45。Q^B 全不变，A 其他项不变，只增该 A 项更新计数。

独立同原始 pre 的 B 支用 Q^B 选 cancel=5，再读 Q^A(F1,cancel)=−2：y_B=−2.8，当前 B 的 Hopen=0，所以 δ_B=−2.8，Bpost=−1.4；A 的 Hopen 保持 1。这个核对不接 A 支之后，不与其合成实际双更新。实际程序每转移取一个与样本独立的 A/B 分支，行为可用两表和，但行为选择与更新支不是一回事；两表可以同初值，分开维护不保证统计独立。

真终止直接 y=r，不做 argmax 或后继查询，Double 仍只写选定表。非终止旧后继或 mask 缺失则记录并立即返回、不写 Q 或更新计数；ES 还需有效目标 π。reset 新图不能补旧后继，外部截断在原任务继续且所需资料有效时可构一步目标，不要求已选下一行为动作或实际续接。

**题 3 参考答案。** X1、X2 各独立 ±1 各半，单个均值 0；四等概率组合的 max 为 1、1、1、−1，均值 0.5，与最大真值 0 的差为正偏差。这是分布期望性质，单次差值不是这个 bias。

若整组 Z 与 X 独立且每个 Z 的均值 0，选择索引仅依赖 X 和独立的均匀平局随机性，则给定索引后的 Z_I 均值仍 0，总期望为 0。若 Z=X，同一选择与评价又得到 max，均值仍为 0.5。这里真值相等、误差分布和独立性均为明确教学条件；真实双表可能相关、有估计误差或选择错动作，所以不推出实际 Double Q 总无偏、无低估或效果保证。

合同可列完整状态与预算、合法 mask、行为/目标 π 与更新支日志、奖励单位和独立后果核验、终止/截断/reset、初态可达性、覆盖和相关性、评价及训练推理成本。非 RL 行为对照可用固定流程或监督定位加流程，匹配输入、权限、预算和成功判据；SARSA 等属于方法对照。路由输入、标签、动作与业务成本仍待确认，不代用旧标签。当前真实研究为 NOT_RUN。
