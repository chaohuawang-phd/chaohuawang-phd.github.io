1. 今天解决什么问题，与前面哪些单元有关

RL-003 已经计算出一个给定路由策略的总体期望净收益 J(πA)=7.22。这个数把不同请求、不同动作和不同结果混合起来。现在想进一步问：如果当前已经处在某个具体状态，继续按这个策略执行，预期表现怎样？如果先指定某个动作，再让策略接着执行，又会怎样？

这两个问题分别由状态价值 Vπ 和动作价值 Qπ 回答。它们都在评价从当前位置往后的期望回报，而不是给一次已经发生的结果重新命名。

例如，某次文本分支答错，净奖励为 −0.5，不说明这个分支在同类请求上的期望价值就是 −0.5。一次 GUI 点击顺利完成，也不足以说明之后的策略能够完成整个任务。

本课先复用上一课的单步路由，建立 V、Q 和总体 J 的关系；再用一个新的两步 GUI 环境说明后续策略与剩余时域为什么重要。我们只按给定分支计算期望，不推导完整 Bellman 方程或价值更新算法；那是下一课的内容。

2. 学习目标

学完后，应当能够：

  1. 区分即时奖励、一次回报、状态价值 Vπ、动作价值 Qπ 与总体期望 J(π)，正确说明 Q 的首个动作由谁决定。
  2. 在给定环境和策略的情况下，手算状态价值、动作价值及初始分布加权的整体表现。
  3. 解释价值为什么依赖后续策略、奖励定义和剩余时域，并指出从实际日志估计价值时缺少的条件。

3. 直觉、定义和必要公式

3.1 奖励、回报和期望是三个层次

沿用前课的下标：在时刻 t 执行动作 a_t，随后收到 r_(t+1)。一次终止于 T 的轨迹，其剩余折扣回报为：

Gt=∑k=0T−t−1γkrt+k+1G_t=\sum_{k=0}^{T-t-1}\gamma^k r_{t+k+1}Gt​=k=0∑T−t−1​γkrt+k+1​
  • r_(t+k+1)：对应一步实际获得的奖励。
  • G_t：这条轨迹从 t 开始的总回报，通常是随机量。
  • γ：折扣因子；当前一步奖励不折扣，之后按 γ 的幂加权。
  • T：任务的终止时间，不是某个动作名称；k 是向后数的步数。

价值是对可能回报取期望。下面讨论完整可见的 Markov 状态、给定环境与策略；任务按定义在有限步内结束，回报期望存在。若有任务内剩余预算，它必须进入状态或在符号中明确写出。

3.2 状态价值 Vπ：从这里开始，全部按 π 执行

Vπ(s)=Eπ[Gt∣St=s]V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s]Vπ(s)=Eπ​[Gt​∣St​=s]
  • s：当前完整状态。
  • π：之后一直采用的指定策略，包括当前这一步的动作选择。
  • Eπ：对策略采样和环境随机结果产生的回报取期望。
  • 上标 π：强调这是这个策略下的价值，不自动等于最优价值。

Vπ(s) 回答：“已经在 s，接下来按 π 做，预期还能获得多少回报？”它不是整个任务从任意起点开始的平均，也不是“这个状态本身有多好”的不带条件评分。

3.3 动作价值 Qπ：先强制做 a，再按 π 继续

常见教材记号写为：

Qπ(s,a)=Eπ[Gt∣St=s,At=a]Q^\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a]Qπ(s,a)=Eπ​[Gt​∣St​=s,At​=a]

必须把这一定义理解为：先从 s 强制执行一个合法动作 a，后续动作再按 π 选择。当前这个 a 不是重新从 π 中抽一次，也不再乘一次 π(a｜s)。环境仍然按照执行 a 后的结果规律返回反馈。

如果 π(a｜s)=0，不能用原策略日志对这个零概率事件硬取条件平均。动作价值的模型定义仍可由“先执行 a、后续按 π”的过程给出；只是当前日志可能没有这类数据，无法直接估出它。这个区分也提醒我们：量可以在模型中定义，不等于数据里已经知道。

Qπ(s,a) 不只是当前奖励的均值；只要任务还继续，它就包含该动作之后按 π 行动产生的回报。前课若用小写 q 表示某个正确概率，也不能把那个概率当作这里的 Q。

上述 V、Q 定义可核对 Sutton 与 Barto 第二版教材原稿册页 58、式 (3.12)～(3.13)，以及 Spinning Up 官方 Value Functions。

3.4 在同一状态，把不同首动作的 Q 按策略平均

Vπ(s)=∑a∈A(s)π(a∣s)Qπ(s,a)V^\pi(s)=\sum_{a\in A(s)}\pi(a\mid s)Q^\pi(s,a)Vπ(s)=a∈A(s)∑​π(a∣s)Qπ(s,a)

因为 V 的第一个动作也由 π 选择，所以要按首动作的概率平均各个 Q；而 Q 已经指定第一个动作。这里的 A(s) 是合法动作集合。

这个关系只是同一状态内的动作平均，还不是下一课跨状态展开的 Bellman 方程。也不能不经说明就把加权平均改成最大值，那相当于改变了所评价的行为。

对给定初始分布，整体表现是起点价值的平均：

J(π)=∑sρ0(s)Vπ(s)J(\pi)=\sum_s\rho_0(s)V^\pi(s)J(π)=s∑​ρ0​(s)Vπ(s)

ρ₀(s) 是从状态 s 开始的概率。一个具体状态的 V 与整体 J 不相同；只改变起点混合，也可能改变 J，而不改变某个固定状态下的 V。

3.5 有限时域要把剩余步数写清楚

令 h 表示还允许执行的真实动作数，不是前课表示交互历史的 h_t。若 s 只表示页面或物理状态分量，完整状态应是 (s,h)。本课写作：

Vhπ(s)=Vπ((s,h)),Qhπ(s,a)=Qπ((s,h),a)V_h^\pi(s)=V^\pi((s,h)),\qquad Q_h^\pi(s,a)=Q^\pi((s,h),a)Vhπ​(s)=Vπ((s,h)),Qhπ​(s,a)=Qπ((s,h),a)

策略也可以依赖 h，写为 π(a｜s,h)。剩两步与剩一步时，即使截图相同，能够得到的后续回报可能不同。另一种等价表达是使用时间下标 V_t、Q_t；本课统一使用剩余步数 h，避免混用。

任务已终止或 h=0 时，未来没有真实动作，本课约定剩余状态价值为 0。此时不要求给不存在的合法动作定义 Q。外部采集被截断则是另一回事，不能仅因为日志结束就把真实后续价值设成 0。

4. 手算例子：从单步路由走到两步 GUI

4.1 复用 RL-003：单步路由中的 V 与 Q

这里完全沿用 RL-003 的教学条件：上下文 u/v 在动作选择前可见，分布为 0.60/0.40；文本动作 T 成本 0.5，图像动作 I 成本 2；答对收益 10，答错收益 0。它们不是实际业务标签。表中的 T 是文本动作名，与第 3 节终止时间符号不同。

单次调用后任务立即结束，本小节省略相同的 h=1 下标。因此：

Qπ(x,a)=E[r1∣x,先执行 a]Q^\pi(x,a)=\mathbb E[r_1\mid x,\text{先执行 }a]Qπ(x,a)=E[r1​∣x,先执行 a]

u T：文本 0.90 10×0.90−0.5=8.5
u I：图像 0.95 10×0.95−2=7.5
v T：文本 0.40 10×0.40−0.5=3.5
v I：图像 0.85 10×0.85−2=6.5

策略仍为 πA(T｜u)=0.80、πA(I｜u)=0.20；πA(T｜v)=0.30、πA(I｜v)=0.70。于是：

VπA(u)=0.80×8.5+0.20×7.5=8.3V^{\pi_A}(u)=0.80\times8.5+0.20\times7.5=8.3VπA​(u)=0.80×8.5+0.20×7.5=8.3

这里的 Q 不依赖后续 π，是因为执行一次动作就终止，没有后续动作。它不能证明一般多步问题的 Q 都与 π 无关。即使在这个例子里，V 仍受当前策略的动作选择概率影响。

若一次 u、T 调用答错，实际奖励及本次回报为 −0.5；但假设环境中的 Q(u,T) 仍是 8.5。一个是一次样本，一个是对可能结果的期望。

4.2 一个新的两步 GUI 教学环境

以下是独立的新教学例子，不是对 RL-002 的转移或奖励修订。本例 open 的奖励为 −1；save 成功收益为 10、失败为 0，不另扣保存成本。不能把上一课其他环境的 0.75 成功率或 +9 净奖励混入这里。

页面有 H（主页）、F（已准备好的表单）和 z（任务终态）。本教学模型假设页面与剩余预算 (s,h) 足以描述后果；这不证明现实中的 GUI 截图充分可见。

页面及合法动作 后果 即时奖励 概率
H, open 到达 F，剩余预算减 1 −1 1.00
H, stop 进入终态 z 0 1.00
F, save 保存成功，进入 z 10 0.80
F, save 保存失败，进入 z 0 0.20
F, cancel 放弃并进入 z 0 1.00

每个当前页面—动作组分别归一，未列后果概率为 0。真实动作每执行一次，h 减 1；预算耗尽就结束，未完成任务没有额外失败罚分。进入 z 或预算为 0 后不再执行真实动作，吸收后的奖励为 0。

初始状态为 (H,2)，γ=0.9。两种给定策略的选择规则如下；在 h>0 的合法决策点采用这些概率，在 h=0 没有动作：

策略 H：open / stop F：save / cancel
πα 0.75 / 0.25 1.00 / 0.00
πβ 0.75 / 0.25 0.50 / 0.50

两种策略只在后面的 F 不同。它们均不是“最优策略”的定义，而是我们要评价的指定行为。

4.3 先强制 open，后面策略不同，Q 就不同

从 (H,2) 强制执行 open，第一步得到 −1 并到达 (F,1)。接下来才由 πα 或 πβ 选择。在 F，保存成功时整条轨迹回报为 −1+0.9×10=8；保存失败或取消时回报为 −1。

πβ save，成功 0.50×0.80=0.40 8
πβ save，失败 0.50×0.20=0.10 −1
πβ cancel 0.50 −1

Q2πα(H,open)=0.80(8)+0.20(−1)=6.2Q_2^{\pi_\alpha}(H,\mathrm{open})=0.80(8)+0.20(-1)=6.2Q2πα​​(H,open)=0.80(8)+0.20(−1)=6.2

若计算状态价值 V，第一步也由策略决定；两种策略在 H 都以 0.75 选择 open、0.25 选择 stop，而 stop 的回报为 0。因此 V₂πα(H)=0.75×6.2=4.65，V₂πβ(H)=0.75×2.6=1.95。

从 (F,1) 开始，πα 的状态价值为 0.80×10=8，πβ 为 0.50×0.80×10=4。这里的奖励、策略和时域都是价值定义的一部分。

4.4 同一页面，剩一步与剩两步

如果从 (H,1) 强制 open，唯一动作预算已经用完，任务结束。虽然页面到达 F，也不能继续执行 save，更不能再给一次保存成功收益。因此两种策略下的 Q₁(H,open)=−1；继续评价给定的 open/stop 概率时，V₁(H)=0.75×(−1)+0.25×0=−0.75。

所有数字都来自已知教学模型和给定策略的枚举；没有训练价值网络，没有真实 GUI 测试或性能提升证据。

5. 与前一种方法或概念的关系

本课没有加入训练算法，而是把前课对完整轨迹的计算，整理成可以从局部状态或动作开始询问的量。

前课的量或概念 本课增加的表达 解决的问题及代价
一条轨迹的 G 对可能轨迹回报取期望 减少把单次结果当稳定表现的误读；需要覆盖或模型
从初态分布开始的 J 给定当前状态的 V 能讨论“已经在这里”的未来；必须说清当前状态
策略 π 的动作概率 强制首动作再跟随 π 的 Q 能比较某个指定首动作；日志可能没采过它
固定任务起止规则 显式剩余时域 h 处理期限差异；需要记录预算或时间

Q、V、J 是不同条件下的期望，不能仅凭名字互换。它们还共同依赖环境、奖励单位、γ、终止与期限；比较实验时这些条件要对齐。

模型已知时，小环境可以像本课一样枚举。真实任务需要估计，而数据少、只记录成功、只采过部分动作，或者日志的后续策略不同，都可能造成估计偏差。今天先明确估计目标是什么；具体怎样从数据学习，后续单元逐步展开。

6. 主要应用：多步 GUI 应该评价哪个价值？

这一节属于工程推断。现实 GUI 中，截图与预算未必足以成为完整状态；焦点、登录、异步加载、历史操作和隐藏应用状态都可能影响结果，需要分析可观察信息与历史表示。

设计项目 一个可检查的多步 GUI 方案 必须核实的条件
观测或状态 指令、截图、合法历史、必要的执行状态与剩余预算 哪些变量真实可见，是否存在同图不同后果
动作 点击、输入、滚动、返回、取消、结束及参数 合法动作与坐标/文本语义，失败如何返回
奖励与回报 独立任务成功收益减真实过程成本，固定 γ 与期限 收益单位、操作/调用成本、任务内超时惩罚
反馈来源 应用结果、持久状态回读或可信人工核查 保存提示是否等于目标真正完成
时间结构 当前动作改变后续界面、动作和完成机会 terminated、truncated 和预算分别记录
价值目标 Vπ 评价当前策略从这里继续；Qπ 评价先做指定动作再由它继续 后续到底由哪个策略版本控制，是否有首动作覆盖
数据 决策前信息、动作、奖励、终止、预算、策略版本和完整后续轨迹 保留失败和取消，不将不同策略后续混作同一目标
评价指标 固定任务分布下的完整成功率、回报、步骤、非法动作、超时和成本 除预测误差外，还要核实实际任务结果
训练成本 采样执行、环境重置、结果验证和计算 每个策略和预算条件需要多少有效反馈
推理成本 每步模型调用、价值估计、执行与等待 额外价值模型调用是否抵消收益，端到端时延与费用

非 RL 基线先行：固定流程或有限状态机、规则加监督控件定位、相同初始模型的示范学习执行策略；模型已知时可以比较枚举或搜索规划。使用相同任务、初态、输入权限、动作预算、成功验证和成本统计。

如果只拿“成功演示中这个按钮后来都完成了任务”来估计 Q，会遗漏失败和取消；如果把多个后续执行器版本混合，却叫作一个固定 π 的价值，也改变了目标。没有数据的合法首动作可以在模型里定义 Q，但不能凭定义补出真实测量值。单次定位命中率仍有用，却不等于整段任务的价值。

路由与 SR 的边界：单步路由可以先用分支的成本敏感期望目标和监督/Bandit 反馈框架，不因出现 Q 这个符号就变成多步 RL；实际标签、输入来源与业务代价以真实合同为准。SR 若研究早停、迭代或计算分配，也要先定义状态、动作、质量—成本回报和固定预算基线，不能把重建指标直接称为已验证的长期价值。本课没有开展这些方向的研究实验。

7. 常见误解、失败条件和适用边界

误解或失败 本课的纠正 检查办法
一次失败就说明 Q 很低 样本回报不等于期望 区分本次结果和模型/数据估计目标
Q 是选择动作的概率 Q 的单位是回报，可大于 1 或为负 与 π 的概率单位分开
算 Q 还要乘首动作概率 首动作已被指定 V 才对首动作选择作平均
π 不选 a，Q 就等于 0 未选不等于无效或失败 定义与估计、支持与反馈分别讨论
单步 Q 不依赖后续 π，所以多步也不依赖 单步终止只是特例 比较新 GUI 中相同 open 的两种后续
截图相同，价值就应相同 历史、隐藏变量或剩余时域可能不同 检查完整状态与 h
终止后仍反复给成功收益 到达时的奖励与之后的零奖励不同 明确成功只计一次
采集停止意味着 V=0 外部截断不等于任务终止 保留停止原因与真实最后状态
Vπ 就是最优价值 上标 π 代表指定策略 不未经说明改为最大化或贪心行为

如果没有明确后续策略、奖励定义或预算，先补齐价值目标。即使模型输出了一个数，也不能据此声称它是可信的 Q 或 V。

8. 三道理解题：先独立作答

请先用约 8 分钟回答，再看文末答案。

题 1｜单步路由与一次结果。 复用第 4.1 节的四个 Q 值、πA 动作概率和 0.60/0.40 初始分布，计算 VπA(u)、VπA(v) 和 J(πA)。如果一次 u、T 调用答错，得到 −0.5，能否说 QπA(u,T)=−0.5？为什么本例 Q 不依赖后续 π，却不能据此推广到多步任务？

题 2｜先做动作还是先抽动作？ 按第 4.2 节新 GUI 规则，从 (H,2) 强制 open，后续分别采用 πα、πβ，列出各完整分支的概率与回报，求 Q₂πα(H,open) 和 Q₂πβ(H,open)。再按 H 上 open=0.75、stop=0.25 求两个 V₂(H)。为什么 Q 不乘 0.75，而 V 要乘？

题 3｜剩余一步、剩余两步与截断。 在同一 GUI 模型中，比较 (H,2) 与 (H,1) 的 Qπα(H,open) 和 Vπα(H)；h=0 时 V 为多少？为什么仅相同截图不够？如果只因为采集器提前停止，能否自动把真实后续价值设为 0？

参考答案（练习完成后再看）

题 1。 VπA(u)=0.80×8.5+0.20×7.5=8.3，VπA(v)=0.30×3.5+0.70×6.5=5.6，J(πA)=0.60×8.3+0.40×5.6=7.22。一次错误的 −0.5 是样本回报，题目给定环境的 Q(u,T) 仍为 8.5。本例执行一个动作就终止，没有后续策略发挥作用；在一般多步任务里，Q 包含首动作之后按 π 继续产生的回报，因此通常依赖 π。

题 2。 强制 open 后，πα 的完整分支为成功概率 0.80、G₀=−1+0.9×10=8，失败概率 0.20、G₀=−1；所以 Q₂πα(H,open)=6.2。πβ 的分支为保存成功 0.40、G₀=8，保存失败 0.10、G₀=−1，取消 0.50、G₀=−1；所以 Q₂πβ(H,open)=2.6。两个 V₂(H) 分别为 0.75×6.2+0.25×0=4.65、0.75×2.6+0.25×0=1.95。Q 已指定首动作 open，不再乘选择它的概率；V 的首动作仍按策略采样，需要把 open 与 stop 两种情况平均。Q 的差异来自后续策略不同，不是环境表或首动作改变。

题 3。 πα 下，h=2 时 Q₂(H,open)=6.2、V₂(H)=4.65；h=1 时 open 得到 −1 后预算耗尽，不再保存，因此 Q₁(H,open)=−1，V₁(H)=−0.75。h=0 时任务已结束，剩余 V₀=0，没有需要执行的真实动作。相同页面可能有不同预算，实际截图还可能遗漏焦点、登录等变量，所以需明确完整状态或时间条件。外部采集停止不自动终止真实任务，也不证明真实未来回报为 0；必须区别任务终止、任务内期限和外部截断。
