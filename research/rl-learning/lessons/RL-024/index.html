1. 今天解决什么问题，与前面哪些单元有关

上一课已经把数据放进 buffer，也声明每次优化期间目标固定。接下来的问题是：这一次固定的目标，下一次还用哪组参数计算？如果刚更新在线预测，就马上用新预测当下一次的参考，参考也会跟着变化；网络不仅在拟合一个值，还在持续改变以后要拟合的值。

目标网络（target network）单独保存生成 TD 目标的参数。在线网络（online network）接受损失梯度更新，目标网络按另一套明确的维护规则跟随。这样可以延迟或平滑估计变化传入后续目标的速度，但不是获得了真实答案，更不是把两个网络变成统计独立或保证训练收敛。

今天区分两件事：本次反向传播在哪里停止；多次优化之间目标参数何时变化。前者是 stop-gradient，后者是 hard copy 或 soft update。本课不引入下一单元的 Double DQN，也不改变旧 GUI 的任务、许可或奖励。

2. 学习目标

  1. 能解释移动目标与参数共享的联系，区分本步目标停止梯度和跨优化步维护目标网络。
  2. 能按明确计数单位和先后顺序复算硬复制、软更新，说明 τ 的权重约定及“复制影响下一目标”的含义。
  3. 能正确处理终止、外部截断和旧反馈，判断目标滞后不能修复的覆盖、估计与业务问题，并补齐 GUI 评价和成本合同。

3. 直觉、定义和必要公式

3.1 一次优化内固定，与优化之间滞后

Q(s,a;θ) 是在线参数 θ 对完整状态 s、合法动作 a 的价值估计；Q(s,a;bar θ) 用目标参数 bar θ 作同样的前向预测。二者通常架构兼容、参数分别保存。目标参数可从在线参数复制初始化，初值相同合法，但复制后应能独立维护，不能只是指向同一份可变权重。

给定记录 (s_i,a_i,r_i,s′_i,d_i)，i 是记录编号，r_i 为即时奖励，d_i=1 为原任务真终止。令 j 表示已经完成的在线优化次数，θ_j、bar θ_j 为第 j+1 次优化开始前的两组参数；γ 是折扣，A(s′_i) 是有效后继的合法集合：

yi(j)={ri,di=1,ri+γmax⁡u∈A(si′)Q(si′,u;θˉj),di=0,Lj(θ)=1B∑i∈B12(Q(si,ai;θ)−SG⁡[yi(j)])2.y_i^{(j)}=\begin{cases} r_i,&d_i=1,\\ r_i+\gamma\max_{u\in A(s'_i)}Q(s'_i,u;\bar\theta_j),&d_i=0, \end{cases} \qquad L_j(\theta)=\frac1B\sum_{i\in\mathcal B} \frac12\big(Q(s_i,a_i;\theta)-\operatorname{SG}[y_i^{(j)}]\big)^2.yi(j)​={ri​,ri​+γmaxu∈A(si′​)​Q(si′​,u;θˉj​),​di​=1,di​=0,​Lj​(θ)=B1​i∈B∑​21​(Q(si​,ai​;θ)−SG[yi(j)​])2.

𝓑 是本次批次，B 是批大小，u 遍历合法候选。SG 前向保留 y、反向不对目标求导；本课用半平方损失的批均值。优化器以学习率 η 只更新在线 θ，从 θ_j 写到 θ_(j+1)，目标网络不接受这次损失的梯度。

这仍然是自举：bar θ 的输出也是估计，不是真实 Q*。stop-gradient 只界定当前反向路径，不能单独说明下一次目标是否会变；即便每步都停止目标梯度，也可能在每次优化后立即重建一个跟着在线参数变化的目标。

3.2 硬复制：先优化，再按计数维护

本课定义 H 为正整数（H≥1）的硬复制间隔，单位是成功完成的在线优化器 step。全局计数 c 从 0 开始；每次真实完成一次在线参数写入后 c 加 1，若 c 为 H 的倍数，再把这次 post 在线参数完整复制给目标参数。计数不在复制后清零，后续按倍数触发。

θˉj+1={θj+1,(j+1) mod H=0,θˉj,其他情况.\bar\theta_{j+1}=\begin{cases} \theta_{j+1},&(j+1)\bmod H=0,\\ \bar\theta_j,&\text{其他情况}. \end{cases}θˉj+1​={θj+1​,θˉj​,​(j+1)modH=0,其他情况.​

式中 mod 表示余数；公式对应初始 c=0、每次成功优化恰加一次的连续情形。先使用 pre 目标算本次 y，更新在线网络，再检查复制；复制后的 bar θ 用于下一次目标，不回头改刚才已使用的 y、损失或梯度。

H 不等于上一课 buffer 容量 C，c 不等于环境步、记录使用次数或任务内预算 h。一个 B=2 的批只完成一次 optimizer step，c 只加 1；只采集环境而没有优化，c 不加。若实现采用其他计时单位，必须另行注明并换算，不能沿用同一个数字假装频率相同。2015 DQN Methods 明确描述复制在线网络生成目标，Algorithm 1 将复制放在梯度步骤之后。

H=1 表示每次在线优化后复制；它没有取消当前步骤的 stop-gradient，但不保留跨优化步的参数滞后。H 大一些意味着更久使用旧参数，也可能更慢传播新估计，复制时仍可能出现跳变。没有脱离任务、学习率和数据条件的通用最佳 H。

3.3 软更新：明确 τ 乘的是谁

另一种参数维护方式是在每次在线优化之后执行：

θˉj+1=(1−τ)θˉj+τθj+1,0≤τ≤1.\bar\theta_{j+1} =(1-\tau)\bar\theta_j+\tau\theta_{j+1}, \qquad 0\le\tau\le1.θˉj+1​=(1−τ)θˉj​+τθj+1​,0≤τ≤1.

本课 τ 是新在线参数的权重；旧目标参数的权重为 1−τ。τ 小时每次只跟随一部分，τ=0 永远不动，τ=1 等于每次优化后直接复制。某些实现用另一个系数表示旧参数保留率，必须看乘法位置，不能只对比配置名或数值。

这是参数插值，不是奖励平均、两个独立学习者投票或自动降低价值误差。一般非线性网络中，平均参数后的输出不等于旧/新网络输出的加权平均；本课线性替身可以手算，不能据此推广非线性等式。

该软目标式可在 Lillicrap 等的作者原始论文中核查；本课只引用参数维护式，不展开其 DDPG 主算法，也不把软更新说成 2015 DQN 原始硬复制配置。原始论文所读版本的第 4 页。

3.4 最短执行顺序

分别保存 online θ 和 target barθ；初始化 barθ 为 θ 的参数副本；c=0
取一个资料有效的批，读取本次 pre θ 与 pre barθ
用 pre barθ 构造目标；真终止直接用实际奖励；目标停止梯度
按声明的半平方/均值损失，只完成一次 online optimizer.step
c += 1
若选硬维护且 c 是 H 的倍数：复制 post θ 到 barθ
若选软维护：barθ = (1-tau)*旧 barθ + tau*post θ
保存 pre/post 版本、目标来源和维护事件；下一次才重建新目标

硬维护与软维护是本课的两条替代分支，不是每次都先硬再软。资料缺失、没有完成在线写入时应记录跳过原因，不把它计为一次成功 optimizer step。这里是机制伪代码，未执行任何训练。

4. 手算例子或更新过程

仍是 RL-020～023 的有限教学 GUI：状态仅 N2（菜单，h=2）、C1（确认页，h=1）、z（终止），初态 N2；每动作耗一预算，h=0 真终止，也可提前结束。γ=0.9，核不改：

全局 ID 为 (0review,1exit,2confirm,3cancel)，N2 mask=(1,1,0,0)，C1 mask=(0,0,1,1)；所有行为与目标都过滤非法输出，delete 不在该字典。教学观测给出完整状态和可信 mask，不代表真实截图具备同样条件。

新目标网络的 Q(C1,confirm)=4×0.799+0.336=3.532，另一个合法 cancel 为 −1.262，所以合法最大仍是 confirm 的 3.532。若下一次再读同一 Nreview 记录，其目标将为 −1+0.9×3.532=2.1788。

这不是第 2 次已经使用的目标；第 2 次始终使用 2.6。c 仍保留为 2，下一次硬复制在成功完成第 4 次优化之后。每批两条、两次优化总共使用四次记录，不等于新采了四次环境交互；原 buffer 的唯一事件仍三条，confirm 反馈仍零条。

4.4 软维护的含义与局限

独立软分支只演示共同第 1 次优化后的那一次维护：bar θ 从 (1,0) 跟到 (0.988,0.018)。τ=0.1 的 0.1 乘新在线 θ₁，不是乘旧目标；若反过来会是不同规则。较小 τ 往往让参数每次变化更少，也会增加滞后，不能据此无条件承诺更快学习或更高真实回报。

参数变化平滑，不代表所有状态的 max 目标、贪心动作或真实误差都平滑。非线性网络、动作最大值切换及数据变化都可能改变结果。本课线性式恰能直接计算目标值，不把参数插值等同于一般输出平均；hard 或 soft 都可能持续传播错误的估计。

4.5 终止与外部停止保持原合同

批中的 e_2 真终止且实际 r=0，所以每次 y=0；若有另一条独立成功记录 Cconfirm、r=8 到 z，则 y=8，失败实际 −4 则 y=−4。它们都不依赖 bar θ，目标维护不能抹掉进入终态的奖励。本课没有新增这些 confirm 记录或额外梯度。

如果采集器在 review 后外部停止，原任务仍 C1，且旧后继/mask 有效，应按当时声明的目标参数 bootstrap。比如硬分支 c=1 的 bar θ 仍 (1,0)，目标为 2.6；没有已选下一行为动作也可构这个 max 目标。若只有 reset 新图或旧 mask 缺失，保存原因并跳过无法核实的更新，不伪标真终止。

5. 与前一种方法的关系

RL-023 解决从哪些已存转移构造批次；本课解决这些转移中的后继值由哪组参数、按什么时钟提供。两者作用不同：随机回放不自动固定目标，目标滞后也不生成新的独立记录或修复采样偏向。

机制 控制哪一部分 新代价与限制
回放 数据使用顺序与频率 存储、读取、历史版本与覆盖仍需核查
stop-gradient 当前 loss 的反向路径 不规定下一次用哪组目标参数
硬复制 分段保持，再按间隔整组复制 旧估计滞后，复制边界可能跳变，需要明确时钟
软维护 每次把目标参数向 post 在线参数移动一部分 增加平滑也增加滞后，τ 语义与频率不能省略

目标网络通常增加一份参数存储和目标前向计算；维护还要复制或逐参数混合。它不是第二个独立学习过程，也不自动有真值监督。过大间隔或过小 τ 可能让有用更新传播太慢，过小间隔或较大 τ 又减少滞后；具体效果需在相同数据、优化与评价条件下检验。

原始 DQN 使用目标网络缓解移动目标问题，但不是任意非线性函数、任意任务和有限数据都收敛的定理。任务表示不充分、反馈错误、非法动作混入、记录版本不兼容或未访问动作缺数据，都不会因维护一份 bar θ 自动解决。

6. 一个主要研究应用：GUI 日志中的目标版本是否可追溯

主应用是多步 GUI 价值学习中，对齐每次更新的数据、在线版本和目标版本。若任务只是独立控件定位，仍先建立监督定位或固定流程；若当前动作影响后续画面与持久结果，再讨论长期价值控制。实际系统字段均【待确认】：

合同项 真实研究必须补齐的内容
观测与状态 【待确认】指令、截图/结构、历史、焦点登录及预算，状态是否充分且编码版本稳定
动作与许可 【待确认】稳定 ID/控件映射、权限与 mask 的来源/版本，后继空或未知集合如何留待核；行为与目标同样过滤
奖励与独立反馈 【待确认】成功失败/取消、步骤时间与误操作成本、单位及 γ；谁何时独立验证持久结果，提示不能自动充当完成
多步、初态与结束 【待确认】动作后果、任务分布和可达性、预算、真终止/外部截断/reset 的独立标志，保留真实旧后继和恢复成本
数据与回放版本 【待确认】唯一事件、任务步骤、状态动作奖励后继、许可/反馈/环境版本、失败与缺失；逐对覆盖、抽样与复用次数
两网络初始化与保存 【待确认】online/target 的架构、权重及模型状态如何对应，初始复制与分别存储，保存/恢复时是否保留目标版本
维护规则与时钟 【待确认】硬/软选择、H 的计数单位、τ 乘法位置、维护频率和发生在 step 前还是后；跳过更新与恢复计数怎样记录
梯度与优化 【待确认】pre online、pre target、y、stop-gradient、损失系数/mean、学习率和真正 optimizer step；target 不由当前损失写入
评价与诊断 【待确认】冻结评价策略的持久成功率/回报、错误/违规、步数时延、覆盖和不确定性；目标漂移/复制跳变、loss 与 Q 尺度只作诊断
采集与训练成本 【待确认】交互、核验标注、reset、重复调参，以及两网络存储、目标前向、复制/混合、反向与训练耗时
推理与执行成本 【待确认】实际部署用哪组参数、编码/候选/mask/前向、交互等待、恢复和结果核验；目标训练副本不等于必须额外执行 GUI 动作
非 RL 基线与公平性 【待确认】固定流程、监督定位加流程、示范策略等，匹配任务、输入、先验、许可、交互/计算预算和成功判据，独立划分训练/调参与测试

研究可以提出一个尚未验证的假设：可追溯的目标版本与维护事件，能否帮助发现“离线 loss 变化来自目标同步，而非真实任务改善”的 GUI 失败？它仍需真实日志、非 RL 对照、独立评价和成本记录。本课没有验证硬/软更新谁更好，状态 NOT_RUN。

模态路由的实际输入、标签语义、动作和错误成本仍待确认，单次选择先对比监督或单步反馈基线。SR 先有迭代、早停或计算分配等真实决策与质量—成本目标；普通一次重建先用监督及固定处理基线，不强套目标网络控制。

7. 常见误解、失败条件和适用边界

误解或失败 本课核查
“目标 detach 了，就已经有滞后网络” 查看跨优化步 bar θ 是否独立保持或被立即替换
“H=2 是读两条样本或做两个 GUI 动作” 本课只按成功 optimizer step，B=2 的一批只加一次
“先 copy post 参数，再回改本次 loss” 当前目标先固定；维护只影响下一次目标构造
“硬复制后 c 清零，或 reset 环境就重置所有时钟” 本课 c 为保留的全局优化计数，恢复协议需另行明确
“τ 越小总越好，或者 τ 是旧参数的系数” 看清 τ 乘新 online，并考虑维护频率与滞后
“软参数平均就是所有 Q 输出平均” 一般非线性网络没有这个等式，还可能发生 max 动作切换
“两个网络就独立、收敛或覆盖更充分” 数据与估计相关性仍在，confirm 没新增反馈
“表里的硬 θ₂ 也可以当软分支 θ₂” 不同下一目标会改变后续优化，分支不能拼接

如果参数对象实际共享引用，所谓 target 可能随 online 即时变化；如果复制漏掉影响预测的模型状态，版本也可能对不上。这些是应检查的工程失败条件，不能仅看两个变量名就宣布目标已冻结。终止、许可和持久反馈错误则要从任务日志修复，而非靠调整 H 或 τ 掩盖。

8. 三道理解题

题 1｜两种时间尺度。 stop-gradient 与目标网络维护分别约束什么？本课 H=2、B=2、c 从 0 开始时，完成第一批与第二批后何时复制，分别影响哪次目标？只交互但没有优化，或资料无效而跳过 step，c 应如何处理？为何不能把 buffer 容量、环境步和预算 h 混用？

题 2｜硬两步与独立软对照。 从本课 fresh θ₀/bar θ₀ 与固定批出发，复算第一步 θ₁、硬 H=2 维护后的 bar 与下一目标；在相同 θ₁ 边界，H=1 的目标与 τ=0.1 的软 bar/下一目标各是多少？然后只沿硬 H=2 继续第二步，给两条梯度、均值、θ₂、复制事件及下一次目标。能否把第二步目标改成 2.1788，或把硬 θ₂ 移到软分支？

题 3｜结束与真实 GUI。 在硬分支 c=1、bar θ=(1,0) 时，Cconfirm 实际 r=8 真终止的目标是什么？review 后只外部停止、旧 C1/mask 有效时呢；若只有 reset 新图又怎么办？列四项真实合同、一个独立持久判据、一个非 RL 基线和训练/推理各一项成本；能否以目标更慢变化证明真实成功率提高或训练收敛？

参考答案（练习完成后再看）

题 1 参考答案。 stop-gradient 限制本次求导路径，y 不对当前 θ 反传；维护规则决定后续步骤使用哪组 bar θ，两者不同。初始 c=0，第一批成功 step 后 c=1，不复制；第二批 step 后 c=2，复制本次 post θ₂，作用于第三次目标。c 不清零，下次触发在 c=4。每批虽两条，只算一次 optimizer step；只有环境交互、数据无效或没有完成在线写入不加 c。环境预算 h 描述任务剩余动作，buffer 容量描述存储，环境步描述交互，不能与优化时钟互换。

题 2 参考答案。 首步目标 (2.6,0)，均值梯度 (1.2,−1.8)，θ₁=(0.88,0.18)。硬 H=2 在 c=1 保留 bar=(1,0)，下一目标 2.6；共同 θ₁ 边界的 H=1 对照复制后，后继最大 3.7，下一目标 2.33。独立软维护以 τ=0.1 乘新在线参数，bar=(0.988,0.018)，后继最大 3.97，下一目标 2.573。这里只比较共同首步后的维护，不继续或混合这些分支。

硬 H=2 第二步依然用目标 (2.6,0)，在线预测 (1.06,−1.58)，两梯度 (−1.54,−1.54)、(3.16,−1.58)，均值 (0.81,−1.56)，在线 θ₂=(0.799,0.336)。完成后 c=2 才复制，目标网络 confirm=3.532、cancel=−1.262，下一次 Nreview 目标 2.1788。不能回改第二步已经用过的 2.6，也不能把硬分支 θ₂ 当成软分支后续结果。所有读取仍只有原有事件；参数复制和软平均不产生新环境反馈，也不保证真实误差降低。

题 3 参考答案。 真终止目标直接 y=8，进入奖励保留；不读终止空集合。外部停止但旧 C1/mask 有效且原任务继续，在指定 bar=(1,0) 下 y=2.6；如果只有 reset 新图或缺旧 mask，就记录截断与缺失原因，跳过无法核实的非终止更新，不补后继、不伪标终止。当前不执行这些新记录或额外梯度。
