1. 今天解决什么问题，与前面哪些单元有关

表格可以为 N2,review 单独存一个值，但真实截图、任务历史和界面配置很难逐项穷举。能否用已有的深度学习基础，让一个可训练函数从输入预测各动作的长期价值？这就是今天从 Q 表走向 Q 网络的出发点。

学习目标仍是动作价值，改变的是表示与写入方式：过去更新一个独立表项，现在更新共享参数 θ。一次记录不仅可能改变当前动作的预测，还可能改变其他动作、其他状态的预测。这带来泛化机会，也带来干扰和不稳定；“能输出很多 Q”不等于“已经学准很多动作”。

本课讲 DQN 的动作价值近似与一次 TD 回归接口，不是完整训练实现。2015 年原始 DQN 还包含经验回放和独立目标网络等组成；它们将分别在 RL-023、024 深入讨论。今天只给定一个在本次计算中固定的目标快照，用它解释目标停止梯度；不提前设计缓存、目标同步或 Double DQN，也不把一个线性算例称为深度 DQN 实验。

2. 学习目标

  1. 能解释 Q(s,a;θ) 与表格 Q 的区别，说明离散有限动作输出、稳定动作编号、合法 mask 及输入状态/观测的含义。
  2. 能从固定目标、半平方损失计算一次半梯度更新，准确指出梯度流过当前预测，目标不在本步反向传播。
  3. 能用两参数例子检查未访问动作预测为何改变，并说明损失下降、目标快照、真实反馈与研究结论之间的边界。

3. 直觉、定义和必要公式

3.1 Q 网络预测价值，不直接输出动作概率

Q(s,a;θ) 是参数 θ 下，对完整状态 s 执行动作 a 的长期折扣价值估计。θ 包含网络权重和偏置；分号区分输入与参数，不是条件概率。估计目标通常是指定任务中的最优动作价值 Q*，但初始化或有限训练后的输出不自动等于 Q*。

典型离散动作 DQN 将状态表示输入一个共享网络，一次前向产生 K 个值：

qθ(s)=[Q(s,a0;θ),…,Q(s,aK−1;θ)].\mathbf q_\theta(s)= \big[Q(s,a_0;\theta),\ldots,Q(s,a_{K-1};\theta)\big].qθ​(s)=[Q(s,a0​;θ),…,Q(s,aK−1​;θ)].

K 是全局有限动作数，a_j 是固定编号 j 对应的动作，j=0,…,K−1；q 的粗体表示向量。每个分量是对应动作的价值估计，允许负数，不要求总和为 1，也不必经 softmax。若用 ε-greedy 选择行为，其概率是另外一层规则，不是把 Q 当概率。2013 原论文 §4.1 与 2015 Methods 的 Model architecture 均说明了逐动作输出接口。

合法集合 A(s) 仍需独立提供。执行时与目标 max 都只看合法分量；终止后不查询空集合。输出编号不能随页面重新解释，否则同一网络分量在训练记录间代表不同动作。实际 GUI 若有动态控件、坐标或输入内容，先明确有限候选及语义；本课的四输出接口不自动解决任意连续坐标定位。

这里 s 是已声明的完整决策状态，网络可用编码 φ(s) 输入，φ 表示特征转换。教学例直接提供 N2/C1；真实场景通常只有观测 o 或历史序列 H，编码截图并不自动满足 Markov 性。指令、历史、焦点、登录和剩余预算等必要信息是否充分，必须另核；原论文也讨论了仅当前画面的部分观测问题，不能把“用了 CNN”当作完整状态证明。

3.2 一次固定目标的 TD 回归

给定一条有效记录 (s,a,r,s′,d)：a 已执行，r 是该步奖励，s′ 是原任务真实后继，d=1 表示真终止，否则原任务继续。γ 是折扣。令 θ 为本步当前预测参数，bar θ 是本次更新期间固定的目标参数快照：

y={r,d=1,r+γmax⁡u∈A(s′)Q(s′,u;θˉ),d=0.y=\begin{cases} r,&d=1,\\ r+\gamma\max_{u\in A(s')}Q(s',u;\bar\theta),&d=0. \end{cases}y={r,r+γmaxu∈A(s′)​Q(s′,u;θˉ),​d=1,d=0.​

u 遍历后继合法动作；max 读取估计最大值，不挑环境最大奖励分支，也不要求真正执行这个最大动作。y 是样本奖励加后继估计的一步目标，不是完整回报、真实 Q* 或环境期望标签。本课不给定转移模型来替换这条实际记录的反馈。

真实终止直接 y=r，后续为零不等于抹掉进入终态的奖励。外部采集停止则不自动 d=1：若仍有有效旧后继与 mask，非终止目标仍按原任务构造；若缺失，就保留原因并跳过无法核实的更新，不能接上 reset 后的新图。这里沿用 RL-020 的边界合同。

完整 2015 DQN 的目标参数有自己的更新安排。本课只把固定快照作为一个输入接口，不讲它何时复制、怎样长期维护；bar θ 可以从当前初值复制，数值相同不代表两者在这一步一起求导，也不意味着统计独立。

3.3 明确损失系数、梯度方向与停止位置

为方便手算，本课采用单条记录、半平方损失、普通梯度下降：

ℓ(θ)=12(Q(s,a;θ)−SG⁡[y])2,δ=y−Q(s,a;θ).\ell(\theta)=\frac12\big(Q(s,a;\theta)-\operatorname{SG}[y]\big)^2, \qquad \delta=y-Q(s,a;\theta).ℓ(θ)=21​(Q(s,a;θ)−SG[y])2,δ=y−Q(s,a;θ).

ℓ 是当前这条记录的损失，1/2 是本课明确的系数；δ 仍按“目标减预测”定义。SG（stop-gradient）前向返回 y 的数值，反向对当前 θ 的导数为 0。只对当前已执行动作的预测求导；本步不沿目标快照、后继 max 或奖励反传。

∇θℓ=(Q(s,a;θ)−y)∇θQ(s,a;θ)=−δ∇θQ(s,a;θ),θnew=θ−η∇θℓ.\nabla_\theta\ell =\big(Q(s,a;\theta)-y\big)\nabla_\theta Q(s,a;\theta) =-\delta\nabla_\theta Q(s,a;\theta), \qquad \theta_{\mathrm{new}}=\theta-\eta\nabla_\theta\ell.∇θ​ℓ=(Q(s,a;θ)−y)∇θ​Q(s,a;θ)=−δ∇θ​Q(s,a;θ),θnew​=θ−η∇θ​ℓ.

∇_θ 表示对参数向量求梯度，η 是正的优化步长，new 是这一次参数写入后。等价写法是 θ_new=θ+ηδ∇Q。梯度下降是减去梯度；δ 为正时不能因此把符号写反。共享参数让其他输出也可能跟着改变，尽管本次损失只直接读取一个动作预测。

这种更新通常称为半梯度（semi-gradient）：在 TD 目标含价值估计时，不对目标依赖求导。它不是把两侧同一参数都反传的完整残差梯度。这里从自己明确的 1/2 损失求导，避免把不同文献的损失系数或更新方向记号混用；实际原始 DQN 还有其优化与误差处理细节，本课不声称逐参数复现。2013 第 3 页与 2015 Methods 说明了 Q 回归和固定目标的关系。

4. 手算例子或更新过程

4.1 任务不改，近似函数重新声明

仍是 RL-020 的有限教学 MDP，状态只有 N2、C1、z；N2 是菜单且剩余 h=2，C1 是确认页且 h=1，初态为 N2。每动作耗一预算，h=0 真终止，也可提前退出。γ=0.9：

状态与合法动作 后继与奖励 概率 结束
N2：review C1，−1 1 否
N2：exit z，0 1 是，退出
C1：confirm z，8 0.9 是，独立持久核验成功
C1：confirm z，−4 0.1 是，独立持久核验失败
C1：cancel z，0 1 是，取消

奖励是无量纲教学效用，review 的 −1 已含其成本；无额外 confirm 步骤费、终止加分或预算补偿。z 后续为 0，进入 z 的奖励保留。核验待定不补成功。reset 只开始新 N2，不提供旧后继、任务内奖励或新任务预算扣减；真实重置成本需另记，环境 reset 不自动重置模型参数。

固定全局动作 ID 与 mask 如下，沿用合法集合而不改任务：

状态 ID 0：review ID 1：exit ID 2：confirm ID 3：cancel
N2 的 mask 1 1 0 0
C1 的 mask 0 0 1 1

1 表示允许，0 表示屏蔽。delete 不在这四个 ID 中，即使外部原始候选评分为 99 也不进入本任务。mask 是设计先验，不是真实安全保证。

4.2 两参数线性近似，仅用于展示梯度

下面不是深度网络，也不是完整 DQN。用线性函数代替网络，才能手算共享参数的影响：

Q(s,a;θ)=k(s,a)w+b,θ=(w,b),θ0=(1,0).Q(s,a;\theta)=k(s,a)w+b,\qquad \theta=(w,b),\qquad \theta_0=(1,0).Q(s,a;θ)=k(s,a)w+b,θ=(w,b),θ0​=(1,0).

w 是共享权重，b 是共享偏置；k(s,a) 是预先给定、不可训练的教学特征，不是动作概率、风险标签或真实输入统计。其完整数表为：

k(s,a) review exit confirm cancel
N2 1 0 0 0
C1 0 0 4 −2

有了 θ₀，合法预测按 Nreview、Nexit、Cconfirm、Ccancel 顺序为 (1,0,4,−2)，与前课 fresh 表的数值一致；这是新近似函数的初值，不继承前课最终估计。非法分量即使算出 0 也没有合法性或真实价值含义，始终屏蔽。

典型 DQN 用一次状态前向输出整个动作向量；这里用 (s,a) 的标量线性式逐项算，只是它的手算替身，不能把这种函数接口说成原论文的深度架构。本次只作一次参数更新，不产生随机轨迹或训练运行。

4.3 固定快照构造目标，再算一次梯度

人为给定记录：N2 执行 review，收到 −1，到 C1，d=0。目标快照 bar θ=θ₀，在这一步不变。后继合法预测为 4、−2，因此：

量 计算
固定 y −1+0.9×max(4,−2)=2.6
当前预测 q₀ Q(N2,review;θ₀)=1
δ₀ 2.6−1=1.6
初始半平方损失 (1/2)×(1−2.6)²=1.28
当前预测梯度 ∇Q=(k,1)=(1,1)
损失梯度 (1−2.6)×(1,1)=(−1.6,−1.6)
新步长 η=0.1，本课重新指定，不是前课 α=0.5
参数写入 θ₁=(1,0)−0.1×(−1.6,−1.6)=(1.16,0.16)

这里不执行 confirm，不把它的模型期望 6.8 或成功奖励 8 替换进估计 4。后继 max 不需要已选下一行为动作。今天到此停止，不续接一条新的实际操作，也不修改前课的 cancel 主轨迹。

4.4 重算输出，观察未访问项也变化

合法状态动作 Q(θ₀) 用同一 θ₁ 重算的 Q 本次新增环境访问
N2,review 1 1×1.16+0.16=1.32 仅这一对给定一条记录
N2,exit 0 0×1.16+0.16=0.16 无
C1,confirm 4 4×1.16+0.16=4.8 无
C1,cancel −2 −2×1.16+0.16=−2.16 无

未访问项改变是参数共享的代数结果，不表示它们有了新监督、访问或正确价值。这里连 cancel 的预测也可能朝不准确的方向变；不能只叫它“泛化提升”。所有非法输出的偏置变化仍被 mask 屏蔽，不参与决策或目标。

保持本次目标 y=2.6，新预测 1.32 的损失为 (1/2)×(1.32−2.6)²=0.8192，小于 1.28。这只说明这一固定教学样本的所选损失下降，不证明真实回报、成功率、全体价值误差或收敛改善。

如果在这一步擅自拿更新后的当前参数替换固定 bar θ，后继 confirm 会变成 4.8，目标将成为 −1+0.9×4.8=3.32；这违反了本次冻结快照的计算合同。以后根据明确协议重构新目标是另一件事，不能泛称所有未来目标改变都错。如何维护目标网络留到 RL-024。

还可检查为什么不直接套表格写入：即使用同样 η=0.1、同一 y=2.6，独立单表项从 1 会变成 1.16；这里预测变成 1.32，因为其梯度 (1,1) 的平方范数是 2。二者作用在不同参数化上，步长数值相同也不等价，不能据增量大小比较学习效率。前课 α=0.5 的 1.8 更不是本次网络输出。

4.5 终止奖励与外部停止的两项自查

若另有一条独立教学记录 C1 confirm、实际奖励 8、到 z，则 y=8，不再访问后继 max；失败实际为 −4 时 y=−4。这里只核目标分支，不执行额外梯度、不改 θ₁，也不声称已经采到任何 confirm 结果。

若只是 review 后采集器停止，原任务仍 C1，且旧后继与合法 mask 有效，则仍是 d=0，本课固定快照目标为 2.6；没有下一行为动作也不影响这个 max 目标。旧状态/mask 缺失则记录并跳过，不用 reset 新 N2 补旧 s′，不因采集停止抹掉未来。

5. 与前一种方法的关系

比较项 表格 Q-learning Q 网络近似
存什么 每个合法状态动作单独一个数 共享参数，输入经过编码再输出预测
一条记录改什么 当前表项，其他项不动 参数；其他动作/状态输出也可能改变
未见组合的值 通常仍是显式初值 可得到函数预测，但准确性需另外验证
目标里的 max 后继合法表值 固定目标接口下的后继合法预测
新成本 状态表、覆盖与交互 编码、前向、反向、参数/优化状态存储与调参
保证边界 特定表格充分条件 不能直接继承同一定理，表示与优化已改变

共享参数不仅改变存储量，也改变误差传播。顺序经验可能相关；Q 变化会改变行为与数据分布；bootstrap 目标依赖估计，若跟着更新也会移动。表示不足会把真实后果不同的状态混在一起。原始 2015 论文明确指出了这些不稳定来源，并在完整方法中使用回放与目标网络；这里识别问题，不提前展开其实现。原文主文第 529 页及 Methods。

这不等于所有网络必发散，也不等于用了完整 DQN 就有普遍稳定保证。RL-019 的有限平稳表格、每对更新与步长条件不能直接替任意共享网络背书。模型输出变化也不能替代逐对真实覆盖与反馈核验。

6. 一个主要研究应用：有限候选下的多步 GUI 动作价值

主应用选择多步 GUI 中，对已定义有限动作候选估计长期价值。若只是一次截图控件定位，监督定位或固定流程应先建立；若当前动作改变后续画面、许可与持久结果，再考虑控制。下面是工程合同，不是已经确定的研究实现，真实字段均【待确认】。

合同项 实际研究需补齐的内容
观测与状态 【待确认】指令、截图/结构、历史、焦点登录与预算，输入编码是否遗漏影响后果的信息；不能只靠网络深度声称 Markov
动作与稳定输出 【待确认】候选粒度、固定 ID 语义和动态控件映射，点击/输入内容如何离散；四输出 toy 不处理任意连续坐标
权限与 mask 【待确认】允许范围、依据与版本，未知/空 mask 和候选失效如何处理；行为与目标都过滤，不能把负奖励当禁止操作
奖励与独立反馈 【待确认】成功失败/取消、步骤时间和误操作成本、单位、γ；谁何时独立核验持久输出/记录，待核验不补成功提示

目标与优化 【待确认】目标快照的来源、stop-gradient 位置、损失系数、学习率、更新次数及参数版本；不把教学 η 或特征当实际选择
指标与评价 【待确认】冻结评价策略下持久成功率/回报、错误后果、违规、取消、步数时延、覆盖空缺及不确定性；损失和 Q 尺度只作诊断
采集与训练成本 【待确认】交互、核验标注、reset、调参和独立重复，视觉编码/反向计算、显存/内存及训练时间；不从两参数 toy 推算 GPU 需求
推理与执行成本 【待确认】视觉与历史编码、候选/mask、一次前向与动作选择、交互等待、失败恢复和持久结果核验的完整任务成本
非 RL 基线与公平性 【待确认】固定流程、监督定位加流程、示范策略；匹配任务、输入、先验、权限、交互/调参预算和成功判据，训练/验证/测试分开

值得检验的研究假设是：在明确有限动作与可靠反馈下，共享表示能否降低相近 GUI 状态的价值估计成本，同时避免对未访问动作产生有害干扰？这要用真实数据、非 RL 对照和独立测试来回答，不能从 loss 下降或论文 Atari 结果代推，当前 NOT_RUN。

模态路由的输入来源、标签语义、动作与业务成本均待确认；单次选择先核监督/单步反馈的基线，不强写多步 DQN。SR 先明确早停、迭代或计算分配等真实动作与质量—成本目标；普通单次重建先用监督及固定处理基线。

7. 常见误解、失败条件和适用边界

误解或失败 本课核查
“四个输出就是四个动作概率” 输出是价值估计，可负且不归一；行为概率另定
“网络给出一个分量就能合法执行” 先核固定 ID 与 mask，非法预测不进选择和 max
“用网络后等于学习完整状态” 区分输入编码与 Markov 充分性，检查历史和隐藏状态
“y 与 Q 两边都对当前 θ 反传” 本步 y 停止梯度，只沿当前已执行动作预测求导
“网络更新也只改一个 Q” 重算共享参数下的其他输出，预测改变不代表新访问
“loss 降、confirm 到 4.8，说明成功率提升” 只有固定单样本算术，未执行 confirm，无真实性能结果
“线性两参数就是完整 DQN” 它只是可手算的替身；原始深度架构和完整训练组成另有定义
“本步固定快照足以永久解决移动目标” 它只定义这一次计算，不提供长期目标维护或稳定保证

表格收敛、泛化准确性、训练稳定与业务完成是不同命题。当前既无真实学习曲线，也无覆盖、风险或算力优势的实测；不能因为使用某个算法名称跳过数据与任务条件。

8. 三道理解题

题 1｜网络输出与合法动作。 四个固定 ID 是什么？N2、C1 的 mask 如何限制行为和目标？为什么输出不是动作概率，不能将当前页面的第 0 个候选随意改成另一个动作？给出真实 GUI 不能仅靠一张截图就声称完整状态的原因。

题 2｜一次半梯度复算。 用本课完整 k 表、θ₀=(1,0)、固定 bar θ=θ₀、γ=0.9、η=0.1，处理 Nreview、r=−1 到 C1。计算 y、δ、初始半平方损失、预测/损失梯度、θ₁、四个合法 post 输出及保持 y 后的新损失。哪些项没有新环境记录却变化？为什么不能照搬单表项写入，或把 1.32 叫作训练性能？

题 3｜目标边界与研究判断。 独立记录 Cconfirm、r=8、真终止时目标是什么？review 后仅外部停止、旧 C1/mask 有效时呢；若只有 reset 新图又怎么办？本步用更新后的当前预测替换固定目标得到 3.32，哪里违反合同，是否意味着以后任何新目标都不允许？列四项真实 GUI 合同、一个非 RL 基线与训练/推理各一项成本，说明两参数算例和完整 DQN 的区别。

参考答案（练习完成后再看）

题 1 参考答案。 全局 ID 0/1/2/3 分别为 review、exit、confirm、cancel，N2 mask 为 (1,1,0,0)，C1 为 (0,0,1,1)。行为与目标 max 都只看允许分量，非法输出不能因为数大或为零就被执行；delete 不在该动作字典。Q 是长期价值估计，非概率，可负且无需和为 1；ε-greedy 概率另按合法集计算。跨页若随意重解释分量，同一训练目标与动作语义就不一致。截图可能遗漏历史、焦点、登录、任务指令或预算，网络编码不自动修复这种状态混淆。

题 2 参考答案。 固定快照合法最大为 4，y=−1+0.9×4=2.6；q₀=1，δ=1.6，ℓ₀=(1/2)×1.6²=1.28。当前特征 k=1，∇Q=(1,1)，∇ℓ=(1−2.6)×(1,1)=(−1.6,−1.6)，所以 θ₁=(1.16,0.16)。按 Nreview、Nexit、Cconfirm、Ccancel 排列，新预测为 (1.32,0.16,4.8,−2.16)，后三对无新增环境记录，只是共享参数改变。非法分量仍屏蔽。

固定 y=2.6 后 ℓ₁=(1/2)×(1.32−2.6)²=0.8192。梯度只过当前预测，目标 SG[y] 不反传。独立单表项若同样用 0.1 步长会得到 1.16；共享线性参数的预测得到 1.32，与梯度平方范数 2 有关，不是更多反馈或更高数据效率。前课 α=0.5 的表格值 1.8 与本次 η 也不同；这一次 loss 降不能当作真实训练效果、完整回报或普遍价值误差下降。

题 3 参考答案。 真终止时 y=r=8，后续为零不抹奖励，不查询终止空集合；这里只核另一条记录的目标，不执行额外梯度。外部停止但原 C1/mask 有效且同一任务时仍 d=0，用本步快照可得 2.6；若只有 reset 新图或缺旧 mask，保留原因、跳过无法核实的非终止更新，不伪标真终止。用 θ₁ 重新算出 3.32 是替换了本次声明不变的 bar θ，违反当前计算合同；以后按明确协议重新构造目标不因此被禁止，长期安排留 RL-024。

真实合同可列状态/历史与预算、固定候选 ID 和权限 mask、独立持久反馈与奖励单位、结束/reset、数据覆盖版本、目标与优化、评价及成本。非 RL 基线可用固定流程或监督定位加流程，匹配信息、任务、权限、预算和成功判据。训练成本可计交互核验及反向计算/显存，推理成本可计视觉编码、前向、等待与持久结果验证。两参数函数是线性教学替身；完整 2015 DQN 使用深度表示、回放与目标网络等组成，不能称本算例已实现或验证完整训练。所有真实研究仍为 NOT_RUN。
