1. 今天解决什么问题，与前面哪些单元有关

RL-008～009 对已知环境的全部可能结果求和，可以评价或优化行为。但真实任务可能没有可直接求和的转移概率表，只有执行后记录下来的状态、动作和奖励。今天问：如果固定一个策略，拿到它产生的完整任务轨迹，怎样估计这个策略的期望回报？

Monte Carlo（MC）预测从实际或模拟的完整回报取平均，不要求显式知道环境联合核 p。本课只估计固定策略的状态价值 Vπ，不选择更优动作、不改策略，也不把 MC 预测直接称为控制算法。

为保持目标一致，今天明确回到旧 πα：H 的 open/stop 为 0.75/0.25，F 必定 save。RL-009 优化后的 π′ 是另一条策略，不能把其数据或 6.2 的最优价值混入今天的 πα 预测。已知教学核只用来说明样本是否合法、核对精确目标，MC 更新本身不读取它。

2. 学习目标

学完后，应当能够：

  1. 从真正终止的完整 episode 计算各访问时刻的折扣回报，分清一次 G、样本均值和目标 Vπ，说明 MC 需要的数据与不需要的显式 p。
  2. 按前向最早出现位置实现 first-visit，用逐状态计数的增量均值复算例子；区分未访问、终态零边界与每次访问。
  3. 解释回报方差、样本不足和轨迹筛选的影响，列出真实 GUI 评价的完整数据、可信反馈、成本与匹配基线条件。

3. 直觉、定义和必要公式

3.1 完整 episode 才提供本课所需的完整回报

episode 是一次从初始条件开始、按固定 π 执行到真正任务终止的完整记录。仍约定 t 时刻执行 A_t，随后收到 R_(t+1)；本课有限任务终止于 T。对于一次已经记录的轨迹：

Gt=∑j=0T−t−1γjrt+j+1,Gt=rt+1+γGt+1,GT=0G_t=\sum_{j=0}^{T-t-1}\gamma^j r_{t+j+1}, \qquad G_t=r_{t+1}+\gamma G_{t+1},\quad G_T=0Gt​=j=0∑T−t−1​γjrt+j+1​,Gt​=rt+1​+γGt+1​,GT​=0
  • t 是当前访问时刻，T 是本次真正终止时刻，j 从当前奖励向后数。
  • r_(t+j+1) 是这条轨迹实际记录的奖励，γ 是折扣因子；当前第一份奖励的系数为 1。
  • G_t 是从该次访问开始的一次实际回报，G_T=0 表示终止之后没有新奖励，不抹去进入终态那一步的奖励。

这里用 G_(t+1) 递推只是倒序汇总同一条已经完整发生的奖励序列，没有拿下一状态的估计价值补未来。实际执行中先等任务真正结束，再处理本次完整回报。

继续用 x=(s,h) 表示 GUI 的完整教学状态，h 为剩余真实动作数。任务自身的预算耗尽可以是真正终止；采集器提前停录、连接中断或外部超时不自动成为这个边界。缺了后续奖励时，不能把未知未来补 0 后称为原任务的完整 MC 回报，也不能接上新一次重置后的轨迹。

3.2 first-visit：每条 episode 对每个完整状态最多取一次

一次 episode 中每出现一次完整状态 x，就是一次 visit。first-visit（首次访问）只取该 episode 中按时间向前最早出现的 x 对应的 G_t；新的 episode 重新判定首次访问。every-visit（每次访问）则保留所有访问对应的回报。

若已经为状态 x 接受 n 个首次访问回报，则：

V^n(x)=1n∑i=1nG(i)(x),n≥1\widehat V_n(x)=\frac{1}{n}\sum_{i=1}^{n}G^{(i)}(x), \qquad n\ge1Vn​(x)=n1​i=1∑n​G(i)(x),n≥1

V̂_n 是样本估计，Vπ 是固定策略的期望目标；G^(i)(x) 是第 i 个被接受的首次访问回报，不是第 i 个环境步骤。每个状态有自己的计数 N(x)：某条任务没有访问 x，就不给 x 增加一次计数，也不补一条 0。

N(x)=0 表示没有可平均的样本，估计保持“未知”。终态的后续价值按定义为 0，是另一回事；不能把所有没到过的非终止状态也填成学会了 0。

倒序计算 G 时容易犯错：反向扫描第一次遇到 x，可能是它在正向轨迹中的最后一次访问。正确做法是先向前标记 first_index[x]，再倒序算回报，只在 t=first_index[x] 时更新。也可以倒序时检查 x 是否出现在更早的前缀，不能用反向 seen 集合替代首次访问定义。

首次访问的定义和倒序回报伪代码，可核对 Sutton 与 Barto 第二版原稿 §5.1，册页 92。

3.3 增量均值：不必保存全部历史回报

对同一个状态，在接受第 n 个回报后，普通算术平均等价于：

V^n(x)=V^n−1(x)+1n[G(n)(x)−V^n−1(x)]\widehat V_n(x)= \widehat V_{n-1}(x)+ \frac{1}{n}\left[G^{(n)}(x)-\widehat V_{n-1}(x)\right]Vn​(x)=Vn−1​(x)+n1​[G(n)(x)−Vn−1​(x)]

n=N(x) 是这个状态已接受的回报数；1/n 是由均值恒等式决定的权重。新回报与旧均值的差决定调整方向。第一次 n=1 直接设 V̂_1=G^(1)，无需先给未知状态一个有业务含义的零值。

这只是“总和除以计数”的等价实现，更新目标仍是完整 G。若任意把 1/n 改成固定常数，就不再是本课这个普通样本均值，不能继续不加说明地引用同一计算结果。

3.4 方差、覆盖与收敛条件

同一固定策略也可能走出不同轨迹。回报中的环境随机性、策略随机性和长路径奖励都可能带来波动；一次失败回报与期望不同，不构成矛盾。

在固定策略、合适的 Markov 状态、独立同分布的完整 episode 抽样、目标状态持续被访问、回报有限方差等条件下，first-visit 均值随样本数增加趋近 Vπ。对 n 个独立同分布的首次访问回报，若其方差为 σ²_x：

Var⁡ ⁣[V^n(x)]=σx2n\operatorname{Var}\!\left[\widehat V_n(x)\right] =\frac{\sigma_x^2}{n}Var[Vn​(x)]=nσx2​​

Var 是随机估计的方差；σ²_x 是回报分布的方差，n 是固定的回报样本数。标准误随 1/√n 缩小是这些抽样条件下的性质，不表示每添一个样本，当前数值就一定更接近目标；更不表示四条人为构造轨迹已经验证了这种统计结论。

同一 episode 中重复访问产生的回报可能相关，不能把 every-visit 的每个回报都当独立 episode 直接套上式。不同状态的回报也可能来自同条任务、相互相关；“更新不使用其他状态的估计值”不等于这些随机数据在统计上独立。

只留下成功任务、复制同条日志当新样本、混用变更后的策略，都会破坏评价目标或抽样条件。没有覆盖的状态不会因别的状态样本增加而自动获得可信估计。丢掉外部截断任务也可能偏向容易结束的任务；完成子集的均值不能未经说明就代表整个任务分布。统计说明可核对 教材册页 93，其结论依赖相应抽样假设。

4. 手算与更新过程：四条完整教学轨迹

4.1 保留环境与旧策略，明确数据性质

以下核与轨迹全部为教学假设或人为构造，没有采集真实 GUI，也没有运行随机模拟实验。仍用 H（主页）、F（准备好的表单）、z（终态），完整状态为 (页面,h)，初态 H2=(H,2)，γ=0.9：

页面与合法动作 下一页面 当前奖励 环境概率
H, open F −1 1.00
H, stop z 0 1.00
F, save z，成功 10 0.80
F, save z，失败 0 0.20
F, cancel z 0 1.00

每个真实动作消耗一步；save 不另扣成本，终态或 h=0 后结束，无额外期限罚分和补发收益。旧 πα 在 H 的 open/stop 为 0.75/0.25，在 F 的 save/cancel 为 1/0。

这些条件下完整路径的教学概率为：stop 0.25，open 后成功 0.60，open 后失败 0.15。精确目标 Vπα(H2)=4.65、Vπα(F1)=8，仅用来核对本课样本估计；MC 算法本身不需要读取这些概率或精确答案。

4.2 四条序列逐条算 G，不按环境概率再乘一次

下面的顺序是为了讲解而指定的；它们是在旧 πα 下可能发生的轨迹，但不是本次实际随机抽到的数据，也不能从出现频次反推真实成功率。

episode 依次发生的状态、动作与奖励 H2 的 G₀ F1 的 G₁
E1 H2 —open,−1→ F1 —save,10→ z −1+0.9×10=8 10
E2 H2 —stop,0→ z 0 未访问
E3 H2 —open,−1→ F1 —save,0→ z −1 0
E4 H2 —open,−1→ F1 —save,10→ z 8 10

每个 GUI 完整状态在各自 episode 中只出现一次，所以本例 first-visit 与 every-visit 完全相同。不能把 E1 的 H2 与 F1 当成同一状态，也不能把不同 episode 中再次出现 H2 排除为“不是首次访问”。

按实际接受的回报取普通平均：

  • H2 接受 [8,0,−1,8]，N(H2)=4，V̂(H2)=15/4=3.75。
  • F1 接受 [10,0,10]，N(F1)=3，V̂(F1)=20/3≈6.67。E2 没访问 F1，不补零也不把分母改成 4。
  • H1、F2 在这些数据里 N=0，保持未知；它们在教学核里可定义价值，不等于已经被这些轨迹估计出来。

普通 MC 平均中不再把每条回报乘 0.60、0.25、0.15。模型期望与样本平均是两种不同计算；把它们混在一起会重复加权。

样本结果与精确目标 4.65、8 不同，只说明这四条构造数据的均值不同。它不证明 MC 有系统偏差、已收敛、某策略变差或真实 GUI 性能发生变化。

4.3 逐状态增量更新，与完整平均互相核对

处理完哪条 episode N(H2) V̂(H2) N(F1) V̂(F1)
E1 1 8 1 10
E2 2 8+(0−8)/2=4 1 10
E3 3 4+(−1−4)/3=7/3 2 10+(0−10)/2=5
E4 4 7/3+(8−7/3)/4=15/4 3 5+(10−5)/3=20/3

两列计数不是全局 episode 数。处理 E2 时 F1 的值不动；它既没新增一个错误样本，也没观测到一次 F1 保存失败。均值一时上升或下降也不是策略被改进了，πα 从始至终没变。

4.4 分开的重复状态小例子：首次访问到底取哪个？

仅为解释重复访问，另设一个与上述 GUI 完全分开的教学任务：唯一非终止完整状态为 X，没有 GUI 的预算变量 h，某合法动作可自环或结束。一条人为构造的完整 episode 为 X —奖励1→ X —奖励2→ z，γ=1。

前向访问位置 完整状态 从该位置到终止的回报 first-visit 是否接受
t=0 X 1+2=3 是
t=1 X 2 否

仅这一条 episode 时 first-visit 的 X 样本为 3；every-visit 接受 3 和 2，均值 2.5。反向扫描先遇到 t=1，不表示它是首次访问；若只用反向 seen 记录，会错取 2。此例只展示两个取样规则的有限样本差异，没有给出 X 的期望价值、收敛或谁更好的结论。

真实同页面若预算从 h=2 变为 h=1，完整状态已经不同。不能为了制造重复访问而从主例状态键中删掉 h。

4.5 首次访问的短伪代码

N = empty_count_map(default=0)
V = empty_value_map()                  # N=0 is UNKNOWN
for each recorded episode from the same fixed_pi:
    if not verified_true_task_end:
        keep_incomplete_record()      # no zero-filled MC update
        continue
    first_index = {}
    for t = 0 .. T-1:                  # forward time
        x = full_state_key(S[t])
        if x not in first_index:
            first_index[x] = t
    G = 0
    for t = T-1 .. 0:                  # backward rewards
        G = R[t+1] + gamma * G
        x = full_state_key(S[t])
        if first_index[x] == t:
            N[x] = N[x] + 1
            if N[x] == 1: V[x] = G
            else: V[x] = V[x] + (G - V[x]) / N[x]

输入是同一固定策略的状态、动作、奖励、完整起止与终止原因记录；GUI 的 full_state_key 包含页面和 h，终态 S_T 不在访问更新循环内。先正向标记首次，再倒序累计奖励；每个 episode 重建 first_index，跨 episode 的 N、V 保留。不需要转移概率 p，也不需要上一状态或下一状态的估计值作为回报目标。

不完整记录必须留在总评价台账中并单独报告，不能因为代码没有更新它，就声称完成子集的均值代表所有尝试。应补齐真实后续，或明确重新定义、验证任务本身的真实期限及相应目标；不能仅为计算方便把外部停录当作终止。

5. 与前一种方法的关系

与 RL-008～009 比较 本课使用什么 新条件与代价
已知 p，枚举可能后果求期望 完整 episode 的实际回报均值 不需显式概率表，但需要可靠完整经验
策略评估或最优更新的价值表 本课只评价固定 πα 的 Vπ 不能把更新均值当作策略改进
用后继表数值组织规划计算 从实际奖励一直累计到终止 必须等待结束，长任务与失败恢复有成本
完整模型能计算未到达状态 无访问就没有相应 MC 样本 数据覆盖和样本波动不可省略

MC 可以使用真实经验，也可使用能够按相应规律产生完整轨迹的模拟器。模拟器不必向算法提供完整 p 表，但依然可能存在模型偏差；“无需显式 p”不等于无需环境假设或免费获得数据。

本课的递推 G 是对已发生奖励做算术汇总，1/N 是均值更新，不是用估计价值替代未知后续，也没有在任务途中改变策略。本课不展开其他采样估计或控制方法。

6. 主要应用：完整 GUI 轨迹的固定策略评价

本节属于工程推断。如果真实 GUI 能按固定执行策略产生可信的完整任务记录，可以用任务回报和被访问状态的后续回报评价它。单次按钮定位准确率不自动变成多步任务回报，保存提示也不自动证明状态已经持久保存。

项目 真实系统需要明确什么 当前事实边界
观测与状态 指令、截图、合法历史、接口权限和预算；完整状态键 【待确认】真实可见信息，截图不自动 Markov
合法动作 点击、输入、滚动、结束、参数与执行反馈 【待确认】实际接口与失败含义
固定数据策略 动作概率、动作屏蔽、回退、底层模型和执行器版本 【待确认】不把旧 πα 当真实业务策略
奖励与单位 完成收益、调用/操作/错误代价、γ 和成本换算 【待确认】业务目标，不移植教学收益 10 与成本 1
可信反馈 独立回读目标值或持久状态，必要时人工核查 【待确认】保存提示不代替独立成功验证
时间与完整起止 任务分布、真正终止、任务内预算和外部截断 【待确认】完整轨迹判据，未结束不能补零未来
初态与重置 任务抽样、初始配置、重复尝试和跨任务隔离 【待确认】重置记录，不把新任务接到旧回报
数据与覆盖 完整状态/动作/奖励、失败/取消、首次访问、版本和缺失 【待确认】N=0 保留未知，不编未选分支
评价指标 任务完整成功率/回报、各状态 N 与均值、波动、截断/失败比例 【待确认】整个任务分布与完成子集分别说明
数据/训练成本 完整执行、重置、反馈核查、标注和采样规模 【待确认】本课无网络训练，收集经验仍有成本
估计与推理成本 轨迹存储、回报扫描、计数表；实际调用/等待/恢复/验证 【待确认】端到端资源，长 episode 不免费
非 RL 对照 同日志直接完整回报平均；固定流程、监督定位加流程、示范执行策略 【待确认】匹配任务、输入、底层模型、预算和判据

先核对回报计算和计数是否与直接列表平均一致，再检查样本是否代表拟评价任务。任务级起点均值、状态条件均值和真实成功率不是同一个指标；应保存原轨迹与版本，包含失败、取消和未完成尝试。旧策略日志不能无条件当作变更后策略的评价数据。

本课的 first-visit 增量均值本身不会改变 GUI 策略，也不证明使用 RL 改善了执行。一个可保留的研究假设是：在可信完整日志和明确抽样条件下，回报与覆盖统计能否帮助识别固定策略的失败环节？需要独立真实资料验证，状态为 未运行（NOT_RUN）。

SR 与模态路由只作条件筛查：普通一次 SR 重建先用监督质量指标评价，不为使用 MC 虚构多步轨迹；如果有真实早停/计算分配过程，再确认奖励与结束规则。独立单步路由可以统计所选行为结果，但真实输入、标签、合法分支与代价仍待确认；没有完整反馈的未选分支保持未知，不借本例成功率填标签。

7. 常见误解、失败条件和适用边界

误解或失败 本课纠正 复算或工程检查
一次 G 就是 Vπ G 是一次回报，Vπ 是期望 H2 有 8、0、−1，不等于都为 4.65
MC 也必须先有 p 本课更新只读取完整经验 教学核用于核对，不进入均值
把 009 的 π′ 或 6.2 混进来 本课固定旧 πα 保留数据策略和执行器版本
反向第一次 seen 就是 first-visit 首次按前向时间判定 X 重复例应接受 t=0 的 3
同页面就是同完整状态 主例还包含 h 不把不同预算合并成重复状态
未访问就补零、计数加一 没有样本不是零回报 E2 不改变 F1 的 N 和 V̂
每条 episode 只有全局一个 N 各状态覆盖不同 H2 的 N=4，F1 的 N=3
样本均值再乘环境概率更准确 普通样本均值不重复模型加权 [8,0,−1,8] 直接求平均
多一个样本必更接近期望 数值可能暂时远离，条件下才谈渐近收敛 不把样本波动写成策略退化
截断后 G=已知部分就算完整 未知未来不能补零 保留未完成台账与真实停止原因

8. 三道理解题：先独立作答

请先用约 8 分钟作答；前两题使用第 4 节的教学条件，答案放在文末。

题 1｜从轨迹到均值。 逐条算 E1～E4 中 H2、F1 的回报，写出各自最终 N 和 V̂。处理 E2 后 F1 的值和计数应怎样变化？为什么不能再乘环境路径概率，不能把样本估计等同于精确 4.65/8、009 的最优 6.2 或真实性能？H1、F2 没出现应记什么？

题 2｜首次访问与增量实现。 用 1/N 公式复算 H2 四次更新；主 GUI 例 first-visit 和 every-visit 是否不同？在分开的 X→X→z、奖励 1/2、γ=1 例中，两次回报各是多少，first-visit 与 every-visit 仅这条 episode 的估计分别是什么？为什么先向前标记、再向后算 G 不会把最后访问误当首次？不同 h 能否只按同页面合并？

题 3｜完整 GUI 日志够不够？ 一个团队只保留成功日志，把网络中断当结束并把未知未来置零；旧策略随后换了模型，仍把旧均值报成新策略性能，未访问状态也填 0。指出问题并补齐状态、动作、固定策略、真实奖励反馈、起止/重置、覆盖、指标、成本和非 RL 对照。方差随样本数缩小需要什么抽样条件，四条构造轨迹是否能证明算法无偏、收敛或真实改善？

参考答案（练习完成后再看）

题 1。 H2 的四次 G 为 8、0、−1、8，故 N=4、V̂=15/4=3.75；F1 的三次 G 为 10、0、10，故 N=3、V̂=20/3≈6.67。E2 没有访问 F1，因此其 N 仍为 1、V̂仍为 10，不能补一条 0。H1、F2 没有样本，保持 N=0、估计未知；终态后续为 0 是定义，不是对未访问非终态的学习结果。

MC 直接平均接受的实际回报，不再乘路径概率。精确 4.65/8 是旧 πα 在已知教学核中的目标；6.2 属于上一课另一策略的最优价值，不能混用。四条顺序由讲解指定，样本均值不同既不证明系统性偏差，也不构成收敛、真实随机实验或性能证据。

题 2。 H2 的均值依次为 8，8+(0−8)/2=4，4+(−1−4)/3=7/3，7/3+(8−7/3)/4=15/4。这里 N 是 H2 接受的回报数；F1 应用自己的计数。主例每个完整 (页面,h) 在单条 episode 中无重复，故 first-visit 与 every-visit 相同。

分开的 X 例中 G₀=1+2=3、G₁=2。first-visit 只接受前向 t=0，故为 3；every-visit 接受两个回报，均值 2.5。先记录 first_index[X]=0，再反向算出每个 G，就可在 t=0 更新；反向 seen 首次遇到 t=1 若直接接受 2，选的是最后访问。真实预算不同则完整状态不同，不能只凭页面相同合并。

题 3。 成功筛选改变任务样本；外部中断不是原任务真正终止，不能把未知后续置零；新策略不能无条件使用旧策略数据作为其表现；无覆盖状态未知。应明确输入与权限、完整状态键、合法动作、固定策略及模型/执行器版本、真实奖励和单位、独立持久状态验证、初态抽样与重置、任务期限和外部截断、完整失败/取消/未完成日志及覆盖。统计完整任务与完成子集、回报、成功率、各状态 N/均值/波动和缺失比例，分别核算采样反馈标注、估计存储扫描及实际执行成本。

计算上先和同日志直接完整回报平均核对，行为对照包括固定流程、监督定位加流程、示范策略；匹配任务、输入、底层模型、预算和成功判据。first-visit 的渐近与方差说明需固定策略、合适状态、独立同分布完整 episode、持续覆盖及有限回报方差等条件；同任务重复回报不自动独立。四条人为构造数据不满足“已经运行随机统计验证”的证据要求，不能据此证明无偏、收敛或业务改善；本课研究仍为 NOT_RUN。
