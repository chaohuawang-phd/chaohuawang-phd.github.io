## 3. 直觉、定义和必要公式

### 3.1 先分清任务描述、观测与状态

任务描述回答“要完成什么”；观测 o_t 是此时真正可获得的信息；状态是模型中对预测未来后果充分的表示。若两张相同截图背后的登录、焦点或加载状态不同，执行同一动作的后果可能不同，截图就不能直接被当成充分的 Markov 状态。

加入历史可能帮助表示隐藏信息，但不自动证明完整状态已知。实际 GUI 可以明确使用截图、合法历史与执行信息形成近似表示，并保留可观测性假设。

有限预算也必须讲清楚。沿用前课，h 是**剩余真实动作数**，不是交互历史；若 s 仅表示页面，教学模型的完整状态是 (s,h)。同一页面剩一步与剩两步时，能得到的未来并不相同。

| 建模对象 | 本周记号 | 自查问题 |
|---|---|---|
| 状态集合与合法动作 | S、A_h(s) | 哪些变量影响后果？此时能执行哪些动作？ |
| 初始分布 | ρ₀ | 起点怎样抽样或重置？ |
| 策略 | π(a｜s,h) | 给定决策信息，怎样选择动作？ |
| 联合环境核 | p(s′,r｜s,a) | 做了指定动作，下一状态与奖励可能是什么？ |
| 奖励与折扣 | r、γ | 当前反馈怎样计量，未来怎样加权？ |
| 终止与任务预算 | 终态、h=0 | 什么是真正结束，什么只是采集停止？ |

真实模型若有随时间变化的环境规律，应把时间条件写入核或完整状态。下文的 p 省略 h，只因为既有教学模型的页面转移和奖励在 h>0 时保持相同，预算另行确定地减 1。

### 3.2 π 选择动作，p 描述动作后的结果

\[
p(s',r\mid s,a)
=\Pr(S_{t+1}=s',R_{t+1}=r\mid S_t=s,A_t=a)
\]

- p：下一状态与奖励的联合概率，不把二者预先假定独立。
- s、a：当前状态分量与合法动作的取值；s′、r：下一状态和当前一步奖励的可能取值。
- S_t、A_t、R_(t+1)：状态、动作和奖励随机变量；S_(t+1) 是下一状态随机变量。
- Pr：概率；竖线表示给定条件。本课具体算例以页面作为 s，并另外明确 h。

每个当前状态—合法动作组的环境结果概率相加为 1；每个决策点的策略动作概率也相加为 1。两个“归一”针对不同的分布。

π(open｜H,h)=0.75 表示选择 open 的概率；p(z,10｜F,save)=0.8 表示已经执行 save 后环境返回成功奖励的概率。它们不能互换。确定策略也可以遇到随机环境；某个动作没被策略采过，不表示该动作失败。

模型分数还未必是实际行为概率：若输出分布后总取最大值，执行概率就不同于分数。合法动作屏蔽、阈值或回退规则也应计入真实行为定义。未执行动作的反事实结果保持未知，不能用一条失败日志替其他分支补标签。

### 3.3 一次奖励、一次回报和期望表现

继续约定：在 t 时刻执行 a_t，随后收到 r_(t+1)。有限、真正终止于 T 的轨迹满足：

\[
G_t=\sum_{k=0}^{T-t-1}\gamma^k r_{t+k+1}
=r_{t+1}+\gamma G_{t+1},\qquad G_T=0
\]

- G_t：这条轨迹从 t 开始的剩余回报；不等于所有轨迹的平均。
- r_(t+k+1)：向后第 k 步所收到的奖励；当前一步 k=0，不再额外折扣。
- γ：折扣因子，本课教学值为 0.9。
- T：真实任务终止时间；k 是从当前时刻向后数的步数。

总体目标为：

\[
J(\pi)=\mathbb E_{\tau\sim\pi}[G_0]
\]

π 是被评价的策略，τ 是它在给定环境和初态分布下产生的完整轨迹，E 是对可能轨迹取期望。单条成功路径不代表 J；只记录成功任务，也不能得到整个任务分布的期望。

V_h^π(s) 是从给定页面与剩余预算开始，当前及后续都按 π 执行的期望回报。Q_h^π(s,a) 则**先强制执行合法动作 a，再按 π 继续**，因此不再乘当前动作被 π 选中的概率。若 π 不选 a，模型中的 Q 仍可定义，原策略日志却可能没有支持其估计的数据。

这里的 Q 是回报单位，不是概率；可以为负，也可以大于 1。一次实际回报与期望 Q 不相等，也不矛盾。有限时域、策略版本、奖励与 γ 都是价值目标的条件。

### 3.4 Bellman 关系连接当前与后续

对尚未终止、h≥1 的合法决策点，复习前课的有限时域写法：

\[
Q_h^\pi(s,a)=\sum_{s',r}p(s',r\mid s,a)
\left[r+\gamma V_{h-1}^\pi(s')\right]
\]

先固定动作，再对环境的下一状态与奖励平均。V_(h−1)^π(s′) 汇总了后续策略的期望回报，不是只挑一条成功轨迹。

\[
V_h^\pi(s)=\sum_{a\in A_h(s)}\pi(a\mid s,h)Q_h^\pi(s,a)
\]

V 的首动作也按 π 选择，所以还需要动作平均。A_h(s) 是当前合法动作集合，下一预算是 h−1。终态 z 或预算耗尽后：

\[
V_h^\pi(z)=0,\qquad V_0^\pi(s)=0
\]

这只把终止之后的未来设为零，不抹去导致终止那一步的奖励。外部采集截断不是自动的真实终止，也不能把新一次重置后的观测接到旧任务轨迹上。

最优价值的关系是：

\[
V_h^*(s)=\max_{a\in A_h(s)}Q_h^*(s,a)
\]

星号 * 表示在该任务允许的策略中最优，Q* 的后续也必须最优。max 选的是可控合法动作，环境结果仍按概率平均；不能选择“这次一定成功”。h=0 或已终止时没有真实动作，直接用边界，不对空动作集合求 max。

这些是价值的自洽关系。本课用已知小模型核对数值，**不推导迭代更新、TD 或 Q-learning 训练步骤**。第二周再具体学习如何计算或估计价值。基础定义与 Bellman 关系可核对 [官方 Spinning Up](https://spinningup.openai.com/en/latest/spinningup/rl_intro.html)及 [Sutton 与 Barto 第二版教材原稿](https://www.andrew.cmu.edu/course/10-703/textbook/BartoSutton.pdf)。

## 4. 手算复习：同一 GUI，完整路径与一步关系互相核对

### 4.1 把全部题目条件重新列出

**下列页面、概率、收益与成本都是教学假设。**完全沿用 RL-004～006 的新 GUI 模型，不修改 RL-002 的另一套环境，也不把它当作实际应用的数据。

页面为 H（主页）、F（准备好的表单）、z（任务终态），初态固定 (H,2)，所以初态概率为 1；γ=0.9。教学模型理想地认为页面与剩余预算足够描述后果。

| 页面与合法动作 | 下一页面 | 当前奖励 | 环境概率 |
|---|---|---:|---:|
| H, open | F | −1 | 1.00 |
| H, stop | z | 0 | 1.00 |
| F, save | z，成功 | 10 | 0.80 |
| F, save | z，失败 | 0 | 0.20 |
| F, cancel | z | 0 | 1.00 |

每个页面—动作组分别归一。每个真实动作消耗一步；save 不另扣成本，预算耗尽没有额外罚分或补发收益。进入 z 或 h=0 后没有真实动作，终止之后追加奖励为 0。

| 给定策略 | H：open / stop | F：save / cancel |
|---|---|---|
| πα | 0.75 / 0.25 | 1.00 / 0.00 |
| πβ | 0.75 / 0.25 | 0.50 / 0.50 |

这些概率用于 h>0 的合法决策点。策略并未因为现在看出某个动作好坏就自动改变。

### 4.2 从起点枚举实际完整路径

两种策略下，初始 stop 的回报为 0；open 后保存成功的奖励序列为 [−1,10]，G₀=−1+0.9×10=8；保存失败或 cancel 时回报都是 −1。

| 策略 | 完整结果 | 从初态开始的路径概率 | G₀ |
|---|---|---:|---:|
| πα | stop | 0.25 | 0 |
| πα | open → save 成功 | 0.75×1×0.80=0.60 | 8 |
| πα | open → save 失败 | 0.75×1×0.20=0.15 | −1 |
| πβ | stop | 0.25 | 0 |
| πβ | open → save 成功 | 0.75×0.50×0.80=0.30 | 8 |
| πβ | open → save 失败 | 0.75×0.50×0.20=0.075 | −1 |
| πβ | open → cancel | 0.75×0.50=0.375 | −1 |

每个策略的完整路径概率分别相加为 1。表中还隐含了初态概率 1 以及 open 到 F 的环境概率 1；它们没有改变数值。不能只乘保存成功率，而漏掉策略是否 open、是否 save 的概率。

\[
V_2^{\pi_\alpha}(H)=0.25(0)+0.60(8)+0.15(-1)=4.65
\]

\[
V_2^{\pi_\beta}(H)=0.25(0)+0.30(8)+0.075(-1)+0.375(-1)=1.95
\]

本例初态固定，因此 J(πα)=V₂πα(H)、J(πβ)=V₂πβ(H)。这只是当前初态分布的特例；一般 J 要对不同起点的 V 加权。两者差为 2.70 个**教学回报单位**，不是实际成功率或已验证收益。

### 4.3 强制首动作，再用一步关系核对

从 (F,1) 起，save 的期望为 0.8×10+0.2×0=8，cancel 为 0，所以 V₁πα(F)=8、V₁πβ(F)=4。

从 (H,2) 强制 open，第一步得到 −1，后续到 (F,1)：

\[
Q_2^{\pi_\alpha}(H,\mathrm{open})=-1+0.9(8)=6.2,
\qquad Q_2^{\pi_\beta}(H,\mathrm{open})=-1+0.9(4)=2.6
\]

Q 中不再乘 H 选择 open 的 0.75。若改回由策略决定第一步，V₂πα(H)=0.75×6.2=4.65，V₂πβ(H)=0.75×2.6=1.95，与完整枚举完全一致。

也可以在“已经强制 open”的条件下再枚举：πα 的成功/失败概率是 0.8/0.2；πβ 的成功/失败/取消概率是 0.4/0.1/0.5。它们与第 4.2 节包含首动作选择的无条件路径概率不同。条件一变，概率就不能直接照搬。

### 4.4 改变预算与改变目标，都会改变答案

从 (H,1) 强制 open，唯一预算用完，不能继续保存，因此两个 Q₁(H,open)=−1；原给定策略的 V₁(H)=0.75×(−1)+0.25×0=−0.75。

| 量或选择 | 教学模型中的结果 | 为什么 |
|---|---:|---|
| V₁*(H) | 0，选 stop | open 为 −1，stop 为 0 |
| V₁*(F) | 8，选 save | 仍要平均 0.8/0.2 的随机结果 |
| V₂*(H) | 6.2，选 open | 后续还有一步可最优保存 |
| V₂πα(H) | 4.65 | F 的续行已最优，但 H 仍有 0.25 概率 stop |

最优只针对这套模型、奖励、折扣、期限和合法动作；不是保证每条轨迹都成功。πα 的指定 open 的 Q₂ 与 Q₂* 相同，也不代表整个 πα 最优。

这个教学模型中的 stop 在剩一步时最优，暴露的是**既定目标与预算的后果**。真实系统是否允许放弃、怎样惩罚未完成、业务是否接受这个行为，均需另行确认，不能悄悄给本例增加罚分再比较前后价值。

## 5. 与前一种方法或概念的关系：第一周总结

本课把 RL-006 的任务合同与前五课的数学对象互相检查：合同不能只有术语，公式也不能替代真实条件。今天没有增加新的学习算法。

| 本周容易分开的两件事 | 现在怎样连起来 | 仍需承担的条件或成本 |
|---|---|---|
| 状态定义与行为规则 | 同一环境配上不同 π，产生不同轨迹和覆盖 | 要保留决策前信息、合法动作及真实行为版本 |
| 完整轨迹与局部价值 | 从路径回报求均值，与一步 Bellman 关系核对 | 概率、奖励和终止边界必须相同 |
| 给定策略与最优策略 | π 平均回答“按它做”；max 回答“允许的最好续行” | 不能把更高预算或额外信息混入方法比较 |
| 教学模型与实际任务 | 教学中能精算；真实问题要先补齐反馈和数据 | 真实转移、标签、成本和验证常仍未知 |

第一周建立的是“要评价或优化什么”。即使已经能精确手算，也还没有说明未知环境中怎样学到价值、怎样更新参数，或怎样证明研究方法带来收益。下一周从已知模型的策略评估开始补上计算与估计过程。

## 6. 主要应用复核：GUI 教学模型怎样映射到工程问题

本节属于**工程推断**，沿用 RL-006 的“按指令修改设置并确认持久保存”草案。选择 GUI 是为教学衔接，**不代表真实研究优先级或已经确认的业务定义**。第 4 节的两动作小模型没有模拟完整输入、编辑和验证流程，其参数不能直接填进实际工程合同。

| 自查字段 | 真实 GUI 应明确什么 | 当前事实边界 |
|---|---|---|
| 观测与输入来源 | 指令、截图、合法历史；是否有 DOM、可访问树或接口信息 | 【待确认】实际输入和权限，不提前用未来反馈 |
| 状态假设 | 登录、焦点、加载、页面进度和剩余预算是否影响后果 | 【待确认】哪些变量可见；截图不自动充分 |
| 合法动作 | 点击、输入、滚动、返回、取消、结束与参数语义 | 【待确认】执行接口、坐标/元素定义与失败反馈 |
| 奖励与单位 | 完成收益、过程/调用/错误代价、γ 及换算或约束 | 【待确认】真实目标；不套用教学收益 10 与成本 1 |
| 可信反馈 | 回读目标值或独立确认持久状态，必要时人工复核 | 【待确认】真实验证方式；保存提示不等于持久成功 |
| 多步与期限 | 动作是否改变后续信息、动作和成功机会；任务预算与结束规则 | 【待确认】真实任务期限，外部截断单列 |
| 初态与重置 | 任务如何抽样，初始设置和页面怎样恢复 | 【待确认】重置条件；重置后新观测不接入旧轨迹 |
| 数据与覆盖 | 决策前信息、动作、结果、预算、终止/截断、策略/执行器版本 | 【待确认】日志覆盖；失败、取消和未知反事实保留 |

**题 2。** πα 的完整路径为 stop（概率 0.25，G₀=0）、保存成功（0.75×1×0.8=0.60，G₀=8）、保存失败（0.75×1×0.2=0.15，G₀=−1）；所以 V₂πα(H)=0+4.8−0.15=4.65。πβ 为 stop（0.25，0）、保存成功（0.75×0.5×0.8=0.30，8）、保存失败（0.75×0.5×0.2=0.075，−1）、取消（0.75×0.5=0.375，−1）；所以 V₂πβ(H)=2.4−0.075−0.375=1.95。两组概率各自和为 1。

F 的 V₁πα(F)=8、V₁πβ(F)=4，故强制 open 后 Q₂πα=−1+0.9×8=6.2、Q₂πβ=−1+0.9×4=2.6。Q 已指定首动作，不再乘 0.75；按策略决定首动作的 V 才对 open、stop 平均。h=1 时 open 立即耗尽预算，Q₁(H,open)=−1，原给定策略 V₁(H)=−0.75；stop 为 0，所以 V₁*(H)=0，选 stop。h=2 时最优 open 后 save，V₂*(H)=6.2，选 open。πα 的 F 续行最优，所以其指定 open 的 Q₂ 与最优 Q₂ 相同，但 H 仍有 0.25 概率 stop，V₂πα(H)=4.65，因此并非最优策略。以上都是教学模型下的精算。
