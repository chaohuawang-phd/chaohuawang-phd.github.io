## 1. 今天解决什么问题，与前面哪些单元有关

RL-010 等到任务真正结束，用完整回报 G 更新固定策略的价值估计。若任务还在继续，但已经观察到一步奖励和实际后继状态，能否先修正当前预测？

TD(0)，即一步时序差分预测，在收到这一次转移后，就用“当前奖励 + 后继状态的当前价值估计”形成目标。它不等完整 G，却也没有提前知道真实未来；目标的一部分来自已有估计，这就是 **bootstrap（自举）**。

本课仍评价固定旧 πα：H 的 open/stop 为 0.75/0.25，F 必定 save。我们更新状态价值，不更新策略，不求最优动作，不引入动作价值或新的控制算法。使用与 RL-010 相同的四条人为构造轨迹，但**重新声明初始化和步长**，不把上一课的 MC 均值或未覆盖状态当作已知真值。

## 2. 学习目标

学完后，应当能够：

1. 写出一步 TD 的目标、误差和更新，逐项说明实际奖励、后继估计、真正终止标记与步长分别做什么。
2. 按转移顺序复算七次固定策略更新，明确当前写入前的值、目标和写入后的值，解释为何后续变化不会自动回改先前状态。
3. 区分真终止、原任务继续时的外部截断及缺失后继，说明初始化、覆盖、反馈与非 RL 对照的真实边界。

## 3. 直觉、定义和必要公式

### 3.1 一步信息：真实观察与现有估计组合成目标

令 x_t=(页面,h) 为本课完整教学状态，h 是剩余真实动作数。在 t 时刻按固定 π 执行动作，观察 r_(t+1) 和实际 x_(t+1)。用 d_(t+1)=1 表示这次转移导致**真正任务终止**，否则为 0：

\[
y_t=r_{t+1}+\gamma(1-d_{t+1})V_{\mathrm{pre}}(x_{t+1})
\]

- y_t：这次一步 TD 目标，不是已经观察到的完整未来回报。
- r_(t+1)：当前动作之后实际收到的一步奖励；γ 是未来折扣。
- d_(t+1)：真终止标记，不把任意“采集结束”都记作 1。
- V_pre：本次更新写入之前的当前价值表；其中的后继价值仍可能不准确。
- x_(t+1)：同一任务中这次动作的真实后继，不能替换成自动重置后的新初态。

真终止时，目标就是当前 r，进入终态的奖励照常保留；没有之后的未来项。实现应直接分支计算，不必先读取无效终态对象再做“0×未知”。未终止且后继有效时，才读取 V_pre(x_(t+1))。

这里没有环境核 p 的全部结果求和，也没有对动作求 max。本课从固定策略的样本转移做预测，不需要显式 p；教学核只是用来核对轨迹与精确目标。样本动作已经发生，不再额外乘一次 π 选择它的概率。

### 3.2 TD 误差与一步写入

\[
\delta_t=y_t-V_{\mathrm{pre}}(x_t)
\]

\[
V_{\mathrm{post}}(x_t)=
V_{\mathrm{pre}}(x_t)+\eta_t\delta_t
\]

δ_t 是本次目标与当前预测的差，单位仍是回报，不是真实价值误差 Vπ−V，也不是分类是否正确的标签。它要等 r_(t+1) 和后继信息到达后才能计算。

η_t 是步长；本课用 η，教材通常用 α，避免与既有策略名称 πα 的下标混淆。取 0<η_t≤1 时，更新把当前数值向这次目标移动一部分；η=0.5 表示移动差值的一半，不表示“学会了一半真实价值”。

先读取本次当前值和后继值、完整算好 y 与 δ，再只写当前状态。其他状态暂不变。下一条转移读取的是此后最新的表；pre/post 是**当前这一次写入前后**，不是 RL-008 那种整轮同步 old/new。记录每个状态更新次数可供核查，但固定 η=0.5 不等于上一课的 1/N 普通均值。

### 3.3 bootstrap 与 MC：未来项的信息来源不同

MC 的目标是这条完整轨迹实际发生的 G_t；TD(0) 的目标 y_t 在未终止时使用现有 V_pre(x_(t+1))。因此 TD 可以在下一时刻更新，而 MC 要等相应完整回报已知。

这里的 bootstrap 是“借已有估计构造新目标”，不是先知道真实未来，也不是用任意猜测补齐一条完整 MC 轨迹。RL-010 的倒序 G 递推只汇总实际奖励；这次 TD 才真正把估计值放入目标。TD 更新不是把未来还没发生的奖励伪装成已观察到。

后继估计可能积累其他经验，也可能还只是初始化。它让信息逐步传播，同时引入对当前表质量、状态表示和数据顺序的依赖。本课不由此断言 TD 总比 MC 更准确；偏差、方差与公平学习曲线比较留给下一单元。

标准一步更新、逐转移伪代码、bootstrap 和 δ 的含义，可核对 [Sutton 与 Barto 第二版原稿 §6.1，册页 119～121，式 (6.2)、(6.5)](https://www.andrew.cmu.edu/course/10-703/textbook/BartoSutton.pdf)。[Sutton（1988）原始论文](https://jmvidal.cse.sc.edu/library/sutton88a.pdf)讨论相邻预测变化与增量预测；其中理论针对特定设置，不是本课四条数据或所有 GUI 任务的效果保证。

### 3.4 初始化可供计算，不等于已经知道价值

TD 的后继估计必须有数值才能参加运算，因此本课把全部非终止状态初始化为 0；终态和 h=0 的零则来自任务边界。二者数值相同，意义不同：未访问非终态的 0 是计算起点，真实价值仍未确定。

这不与 RL-010 的“没样本保持未知”矛盾。MC 当时没有可平均的回报；本课允许初始化值参与自举，但记录仍应标明“初始化、尚未更新”，不能展示成验证过的价值。

本课固定 η=0.5 仅为可手算。有限几条序列、一次 δ 较小或某个值恰好接近教学真值，都不能证明收敛。一般保证还需要固定策略、合适的 Markov 状态、足够覆盖、奖励与步长等条件；常数教学步长不是一般精确收敛承诺，也不能把表格预测的条件直接推广到任意神经网络。

### 3.5 真终止与外部截断：先确定原任务是否还有未来

| 这次转移的情况 | 本课目标怎样处理 | 需要保留什么 |
|---|---|---|
| 真正进入终态，或预定义任务预算 h=0 | d=1，y=r | 终止原因与进入时奖励 |
| 仅外部采集停止，原任务仍继续，真实后继可用 | d=0，可按该后继估计计算 y=r+γV_pre(后继) | 最后真实观测、剩余预算与截断原因 |
| 真终止判据不明，或非终止转移的后继缺失/无效 | 暂存、标缺失，不编造这次 TD 目标 | 原始记录与缺失原因，后续补齐或明确评价范围 |
| 接口返回自动重置后的新初态 | 不把新初态作为旧转移后继 | 分开保存旧任务末观测与新任务起点 |

外部截断不自动意味着 d=0 或 d=1；必须先判断所评价的原任务是否真正结束，再检查同任务后继是否有效。任务本身的有限期限与外部停录是不同条件。也不能无说明只留下成功或观测齐全的转移，就声称代表整个任务分布；缺失、失败与截断要留在总台账中。

## 4. 手算与更新过程：固定策略、重新初始化、逐条写入

### 4.1 环境、数据与初值完整列出

**全部数字与顺序都是教学构造，没有随机采集、模拟统计实验或真实 GUI 执行。**沿用前课 H、F、z 与完整状态 (页面,h)，γ=0.9，初态 H2=(H,2)：

| 页面与合法动作 | 下一页面 | 当前奖励 | 环境概率 |
|---|---|---:|---:|
| H, open | F | −1 | 1.00 |
| H, stop | z | 0 | 1.00 |
| F, save | z，成功 | 10 | 0.80 |
| F, save | z，失败 | 0 | 0.20 |
| F, cancel | z | 0 | 1.00 |

每个真实动作消耗一步，save 不另扣成本；进入 z 或 h=0 后结束，无额外期限罚分或补发收益。固定旧 πα 在 H 以 .75/.25 选择 open/stop，在 F 必 save。不是 RL-009 的优化策略 π′。

本次从 fresh 零表开始：V(H2)=V(F2)=V(H1)=V(F1)=0，各状态更新计数 N=0；终态与 h=0 恒为 0。**不承接 RL-010 的 3.75、20/3，也不把它们当真值。**每次步长 η=1/2；表跨任务保留，环境每次任务按原条件重置。

四条完整教学 episode 顺序不变：

| episode | 指定的转移序列 |
|---|---|
| E1 成功 | H2 —open,−1→ F1 —save,10→ z |
| E2 停止 | H2 —stop,0→ z |
| E3 失败 | H2 —open,−1→ F1 —save,0→ z |
| E4 成功 | H2 —open,−1→ F1 —save,10→ z |

它们在 πα 下可能发生，但这里的先后是人为指定的。已知核下 Vπα(H2)=4.65、Vπα(F1)=8 只作教学目标参考，不作为更新输入。

### 4.2 七次转移：先算目标，再写当前值

表中的“后继 pre”是真终止时的零未来边界，或非终止时实际读取的旧数值。每一行只更新该行当前状态：

| 步/episode | 转移与 r，真终止 d | 当前 pre | 后继 pre | y | δ=y−当前 pre | 当前 post |
|---|---|---:|---:|---:|---:|---:|
| 1 / E1 | H2→F1，r=−1，d=0 | 0 | 0 | −1 | −1 | −1/2 |
| 2 / E1 | F1→z，r=10，d=1 | 0 | 0 | 10 | 10 | 5 |
| 3 / E2 | H2→z，r=0，d=1 | −1/2 | 0 | 0 | 1/2 | −1/4 |
| 4 / E3 | H2→F1，r=−1，d=0 | −1/4 | 5 | 7/2 | 15/4 | 13/8 |
| 5 / E3 | F1→z，r=0，d=1 | 5 | 0 | 0 | −5 | 5/2 |
| 6 / E4 | H2→F1，r=−1，d=0 | 13/8 | 5/2 | 5/4 | −3/8 | 23/16 |
| 7 / E4 | F1→z，r=10，d=1 | 5/2 | 0 | 10 | 15/2 | 25/4 |

例如第 4 步：y=−1+.9×5=3.5；δ=3.5−(−.25)=3.75；V_post(H2)=−.25+.5×3.75=1.625=13/8。第 6 步则 y=−1+.9×2.5=1.25，δ=1.25−1.625=−.375，所以 H2 下降到 1.4375=23/16，虽然这一整条 E4 最终成功。

### 4.3 发生在后面的结果，不自动回改之前那一步

E1 第一步更新 H2 时，F1 仍只是初始化 0，因此目标为 −1，H2 先变为 −.5。等 F1 成功更新为 5，H2 不会自动重算。

E3 的第一步用了当时的 F1=5，尽管这条轨迹后来实际保存失败、完整 G(H2)=−1，它当时的 TD 目标仍是 3.5。下一步把 F1 改成 2.5 后，也不回溯覆盖刚才的 H2=13/8。若要再次利用先前转移，那是额外的处理安排，不能把它算成本课已经执行过的一步。

最终表与更新次数为：

| 完整状态 | 本次处理后的数值 | 更新次数 N | 能说明什么 |
|---|---:|---:|---|
| H2 | 23/16=1.4375 | 4 | 这七次顺序更新的结果，非精确真值 |
| F1 | 25/4=6.25 | 3 | 同上，尚不能据此确认收敛 |
| H1 | 0 | 0 | 仅保留初始化，真实价值未学得 |
| F2 | 0 | 0 | 仅保留初始化，真实价值未学得 |
| z 或 h=0 | 0 | 不更新 | 任务结束后的边界定义 |

RL-010 对同四条记录作普通 MC 平均得到 H2=3.75、F1=20/3。这里不仅目标与更新时机不同，步长也从 1/N 变为固定 .5；不能把两组数值的远近单独归因于 TD，不能用四条构造数据宣布谁性能更好。固定策略始终没有被改进。

### 4.4 单独的截断反例：不是给主序列再加一步

取一个与第 4 步相同的独立教学快照：V_pre(H2)=−1/4、V_pre(F1)=5，观察到 H2 —open,−1→ F1。若仅采集器此时停录，原任务还可保存，且 F1 是未重置的真实后继，则 d=0，y=7/2，按 η=.5 得 H2_new=13/8。

若误把这个外部截断记成真终止，则 y=−1，会把 H2 更新为 −1/4+.5×[−1−(−1/4)]=−5/8。两者计算目标已不同。这不是修改主序列的第 4 步，也不是新增一次数据更新。

相反，从 H1 open 后预算真的耗尽，后继是 F0，已没有保存机会，d=1、目标就是 −1；不能拿 F1=5 来多给一步未来。真实后继缺失时，也不能把自动 reset 后的 H2 填进旧转移。

### 4.5 每次转移的短伪代码

```text
initialize numeric V[x] explicitly; N[x] = 0
keep V[terminal or h=0] = 0
for each transition from the same fixed_pi in recorded order:
    validate current state, reward and original task-end semantics
    if missing/ambiguous:
        retain_and_flag_record(); continue
    old_current = V[x]
    if true_terminal:
        target = r
    else:
        if not valid_same_task_successor:
            retain_and_flag_record(); continue
        old_next = V[x_next]           # pre-update estimate
        target = r + gamma * old_next
    delta = target - old_current
    V[x] = old_current + eta * delta
    N[x] = N[x] + 1
    keep terminal/truncation/reset and policy-version records separate
```

GUI 的 x 使用完整 (页面,h) 键；按真实转移先后读取和写入，不使用 MC 的 first-visit 筛选，也不等整条 episode 结束。真终止不用读取后继估计；纯外截断是否能使用该转移，按原任务继续与真实后继有效性判断。缺失记录仍留台账，排除后不能无说明声称剩余转移代表全部任务。

## 5. 与前一种方法的关系

| 比较项 | RL-010 的普通 first-visit MC | 本课表格 TD(0) |
|---|---|---|
| 目标 | 实际完整回报 G | 实际一步 r 加后继当前估计 |
| 最早更新时间 | 完整回报已知后 | 一次有效转移及奖励到达后 |
| 表的依赖 | 目标不使用其他状态的估计值 | 未终止目标依赖后继表值，即 bootstrap |
| 本例步长 | 每状态 1/N 普通平均 | 固定 η=.5，非普通样本平均 |
| 覆盖与初始化 | 没有回报则没有可平均样本 | 可用显式初始化计算，但不称其为学得真值 |

两者都可从固定策略经验学习，不需要显式 p 表，估计的目标仍是 Vπα，而不是最优 V*。TD 把更新分散到过程之中，但不意味着真实状态、可信奖励、后继观测与覆盖可以省略；不准确的后继估计会影响当前目标。

本课只解释机制与顺序，不比较偏差、方差的完整理论，也不从教学数值推出采样效率或真实业务提升。下一课再设计统一目标、初始化、预算和评价协议下的比较。

## 6. 主要应用：GUI 过程中的固定策略价值预测

本节为**工程推断**。若真实 GUI 有固定策略的可靠逐步日志，可以在过程中奖励与后继可用后更新当前状态的价值预测。它本身不改变按钮选择，不把单次定位分数自动变成长期价值，也不保证预测模型对实际环境正确。

| 项目 | 真实系统需要明确什么 | 当前事实边界 |
|---|---|---|
| 观测与状态 | 指令、截图、合法历史、预算及可用接口，是否足以表述未来 | 【待确认】输入权限与状态充分性，截图不自动 Markov |
| 合法动作 | 点击、输入、滚动、结束、参数与执行反馈 | 【待确认】动作语义和失败处理 |
| 固定数据策略 | 行为概率、屏蔽、回退、底层模型与执行器版本 | 【待确认】不混版本后声称在评估同一个新策略 |
| 奖励与单位 | 完成收益、调用/操作/错误代价、γ 与成本换算 | 【待确认】真实目标，不套用教学 10 与 −1 |
| 可信反馈 | 独立持久状态或目标回读、逐步奖励核验 | 【待确认】保存提示与定位命中不代替任务完成 |
| 后继与时间边界 | 真终止、任务预算、外截断、最后有效后继与自动重置 | 【待确认】不能混用 done，也不接新任务观测 |
| 初态与重置 | 任务抽样、初始配置、状态/环境重置和任务隔离 | 【待确认】真实分布，不混淆表保留与环境重置 |
| 数据与覆盖 | 逐转移顺序、完整键、r/后继/标记、失败/取消/缺失及版本 | 【待确认】未访问只标初始化，未选分支未知 |
| 评价指标 | 独立价值误差与任务回报、成功率、覆盖/更新数、截断/缺失比例 | 【待确认】δ 小不作为真实价值准确或业务改善证明 |
| 采样/训练成本 | 执行、重置、反馈标注、估计更新和步长选择 | 【待确认】本课不训练真实网络，经验获取仍有成本 |
| 推理与存储成本 | 表/日志与状态表示、价值读取；实际调用/等待/恢复/验证 | 【待确认】端到端资源，不把逐步更新称为免费 |
| 方法与非RL对照 | 方法对照：同日志 MC 完整回报；非 RL 行为：固定流程、监督定位加流程、示范策略 | 【待确认】匹配目标、输入、底层模型、预算与判据 |

## 7. 常见误解、失败条件和适用边界

| 误解或失败 | 本课纠正 | 一个复核点 |
|---|---|---|
| 不等终止就意味着知道真实未来 | TD 使用现有估计自举 | 第 1 步后继只是初始化 0 |
| 目标 y 就是完整 G | 信息来源不同 | E3 首步 y=3.5，整条实际 G=−1 |
| δ 是相对真值的误差 | 它是相对这次目标的差 | δ 小不证明 V 已准确 |
| 后继更新后，前驱自动跟着变 | 本课每次只写当前状态 | 第 5 步不回改第 4 步 H2 |
| 所有更新都用最终表重算 | 顺序和当时 pre 值是算法一部分 | 第 4 步读取 F1=5，第 6 步读取 2.5 |
| 数值 0 都表示已知道价值为零 | 初始化与终态定义不同 | H1/F2 的 N=0 |
| η=.5 等于 1/N 样本均值 | 这是固定步长，不是按计数平均 | 不把两种结果远近当算法优劣 |
| done 同时表示终止和截断，直接全掩码 | 原任务边界需分别确认 | 有效外截断反例 target3.5 与 −1 不同 |
| reset 后初态就是旧转移后继 | 任务已经切换 | 保存旧 final observation，丢失就标缺失 |
| value 更新就是策略改进 | 固定 πα 没变 | 本课无动作最大化或控制更新 |

## 参考答案（练习完成后再看）

**题 1。** y=r+γ(1−d)V_pre(后继)，δ=y−V_pre(当前)，V_post(当前)=V_pre(当前)+ηδ；实际观察的是 r 和真实转移/边界，未终止续值是当前估计。第 1 步 V_pre(H2)=V_pre(F1)=0，故 y=−1、δ=−1、H2_new=−.5。第 2 步只把 F1 从 0 更新为 5，H2 仍为 −.5。

bootstrap 用现有估计构造目标；MC 的倒序 G 只汇总完整发生的奖励。η=.5 只是向本次目标移动差的一半，不是掌握真值的一半；δ 小不保证价值准确。未访非终态的初始 0 是计算约定，不能称已学得真实零价值，终态零则是任务边界定义。

**题 2。** 七步按（当前 pre，后继 pre，y，δ，当前 post）排列，终止行的后继 pre 表示零未来边界：

1. (0, 0, −1, −1, −1/2)。
2. (0, 0, 10, 10, 5)。
3. (−1/2, 0, 0, 1/2, −1/4)。
4. (−1/4, 5, 7/2, 15/4, 13/8)。
5. (5, 0, 0, −5, 5/2)。
6. (13/8, 5/2, 5/4, −3/8, 23/16)。
7. (5/2, 0, 10, 15/2, 25/4)。

最终 H2=23/16=1.4375，更新 4 次；F1=25/4=6.25，更新 3 次。第 4 步使用当时 F1=5，得到 y=3.5；第 5 步失败后才把 F1 改为 2.5，不回改 H2；第 6 步再遇到 H2，才用 2.5 得 y=1.25。E3 实际完整 G=−1 不会把先前 y 回溯替换。MC 目标、时机和 1/N 步长与本课不同，四条构造序列不能判性能。H1/F2 仍为初始化 0、N=0，真实价值未学得。

**题 3。** 仅外部截断、原任务继续且 F1 是有效真实后继时 d=0：y=−1+.9×5=7/2，δ=7/2−(−1/4)=15/4，H2_new=−1/4+.5×15/4=13/8。误设 d=1，则 y=−1，δ=−3/4，H2_new=−5/8。从 H1 open 后任务预算真耗尽，后继 F0 无保存未来，d=1、目标 −1；后继缺失或被 reset 观测替代时，应保存并标缺失，不拿新初态编旧目标。

真实应用还需明确输入/状态、合法动作、固定策略及执行器版本、奖励单位和独立持久反馈、真终止/截断/重置、完整顺序与失败/取消/缺失台账、覆盖和初始化、评价指标、采样训练与推理成本。计算核对各步目标/写入；方法对照为同日志 MC，非 RL 行为对照为固定流程、监督定位加流程、示范策略，统一任务、输入、底层模型、预算及成功判据。不能从 δ 小、固定步长七次更新或成功子集推断真实效果；本课研究仍为 NOT_RUN。
