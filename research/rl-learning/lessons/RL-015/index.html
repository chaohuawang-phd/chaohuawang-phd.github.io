1. 今天解决什么问题，与前面哪些单元有关

上一周一直在问：持续按某个固定策略行动，这个状态的预期回报是多少？今天多问一步：在同一个状态里，选不同动作会怎样，学到的表又怎样改变之后的动作选择？

SARSA 将一步 TD 的对象从状态价值 V 换成动作价值 Q。它用“当前状态、当前动作、奖励、下一状态、下一动作”组成的转移更新一个状态动作对。下一动作来自正在使用的行为策略，并且会成为下一步真正执行的动作。这条联系是本课最需要掌握的机制：先按行为策略选定下一动作，使用它的更新前 Q 值构造目标，再把同一个动作带到下一次执行。

本课沿用旧 GUI 环境的状态、动作和奖励核，便于比较机制；行为策略从这里开始改为随 Q 变化的 ε-greedy。它既不是前面固定的旧策略 π_alpha，也不是 RL-009 中用精确模型改进得到的 π′。旧环境相同，不代表数据策略和待估计对象也相同。

建议安排：用约 8 分钟读定义和 ε 概率，约 12 分钟手算两次写入，约 8 分钟检查终止、动作携带和控制边界，余下时间完成三题并核对应用合同。今天不学习另一种控制算法，也不运行探索实验。

2. 学习目标

  1. 能解释固定策略下 q_pi 的含义、当前估计表 Q 与真实动作价值的区别，以及 SARSA 中的下一动作为什么必须与实际行为一致。
  2. 能根据合法动作、ε、平局规则和更新前 Q，算出动作概率、一步目标、TD 误差和更新后的一个表项，并准确执行同一个下一动作。
  3. 能判断真实终止、外部截断、reset 和缺失后继是否允许当前更新；能为 GUI 控制列出必要反馈、数据和对照，而不把手算结果当作性能证据。

3. 直觉、定义和必要公式

3.1 从固定策略的 q_pi 到控制中的 Q

对一个固定策略 π，q_pi(x,a) 表示：从完整状态 x 出发，先执行合法动作 a，之后持续按 π 行动，所得折扣回报的期望。它是一个期望目标，单条轨迹的回报 G 只是一次实现。表 Q(x,a) 是学习者当前的估计，初始化的数也可以只是猜测。

在预测任务中，可以把 π 固定，逐步估计 q_pi。在控制任务中，算法一边更新 Q，一边用 Q 改变行为策略。此时“当前表在追随当前策略”不表示每一次写入后，整张 Q 都已经等于新策略的真实 q_pi。策略、访问分布和估计会相互影响；不能直接搬用固定策略预测的全部保证。

动作价值的状态键仍要完整。教学 GUI 使用 x=(page,h)，其中 h 是剩余动作预算；H2 和 H1 不是同一个状态。动作表还要按合法动作分别索引，Q(H2,open) 与 Q(H2,stop) 是两个表项。即使某个表项没有样本，也可以有显式初始化值，但这不表示它已经被数据验证。

3.2 ε-greedy：先定义动作集合，再算概率

设已知的非空合法动作集合为 A(x)，大小为 k；当前 Q 最大的动作集合为 B(x)，大小为 b。这里 ε∈[0,1]；k 是合法动作数量，与前课 DP 的迭代轮次 k 用途不同。本课约定：以概率 1−ε 在 B(x) 内均匀选；以概率 ε 在全部合法动作中均匀选。探索分支也可能再次选到贪心动作。因此：

πQ(a∣x)=εk+1−εb 1{a∈B(x)},a∈A(x).\pi_Q(a\mid x)=\frac{\varepsilon}{k}+\frac{1-\varepsilon}{b}\,\mathbf{1}\{a\in B(x)\},\qquad a\in A(x).πQ​(a∣x)=kε​+b1−ε​1{a∈B(x)},a∈A(x).

式中的指示量 𝟙{a∈B(x)} 在 a 属于 B(x) 时取 1，否则取 0。非法动作概率为 0。本课 ε=0.2，两个合法动作且只有一个最大值时，贪心动作概率是 0.8+0.2/2=0.9，另一个是 0.1；不能把它们写成 0.8 和 0.2。若两个动作并列最大，按本课平局规则各为 0.5；若只剩一个合法动作，它的概率为 1。

平局如何处理是明确约定，不能在正文、代码和日志里各用一种。这里采用均匀平局规则；RL-009 中为讨论策略改进而采用的稳定平局约定，不会自动成为本课的新实现。ε=0 时也不会因为写了“贪心”就保证所有状态动作都获得访问。

如果合法 mask 未知，或非终止状态的合法动作集为空，当前没有足够合同来抽动作：应保留异常并解决观测或动作定义，不能对空集合做 argmax、擅自添加动作，或为了让代码继续就把状态改标为终止。ε 只在已允许的动作集合中分配概率，不能代替动作许可和试验范围的定义。教材 §2.2 的贪心与 ε-greedy 定义支持这个概率计算。

3.3 五个事件与一次写入

一条非终止 SARSA 更新包含 x_t、a_t、r_(t+1)、x_(t+1)、a_(t+1)。其中 a_t 已经被执行；a_(t+1) 已按行为策略选定，将在下一次环境交互中执行。更新当前表项时，不需要等待下一动作的奖励出现。

令 Q_pre 是本次写入前的表，α 是步长，γ 是奖励折扣；d_(t+1)=1 表示原任务真正终止，否则为 0。在具备有效后继及下一动作的非终止分支，使用：

yt={rt+1,dt+1=1,rt+1+γQpre(xt+1,at+1),dt+1=0,δt=yt−Qpre(xt,at).y_t=\begin{cases} r_{t+1}, & d_{t+1}=1,\\ r_{t+1}+\gamma Q_{\mathrm{pre}}(x_{t+1},a_{t+1}), & d_{t+1}=0, \end{cases} \qquad \delta_t=y_t-Q_{\mathrm{pre}}(x_t,a_t).yt​={rt+1​,rt+1​+γQpre​(xt+1​,at+1​),​dt+1​=1,dt+1​=0,​δt​=yt​−Qpre​(xt​,at​).
Qpost(xt,at)=Qpre(xt,at)+αδt.Q_{\mathrm{post}}(x_t,a_t)=Q_{\mathrm{pre}}(x_t,a_t)+\alpha\delta_t.Qpost​(xt​,at​)=Qpre​(xt​,at​)+αδt​.

本次只写入当前这一个状态动作对，其他表项保持原值。目标和误差都先从更新前快照算好，再写入；即便一般任务出现同一表项作为当前项与后继项，也不能把尚在构造的 post 值混入同一次目标。

这里的自举来自后继动作价值估计。δ 是当前估计与一个含估计量的目标之间的差，不是 Q 与真实 q_pi 的误差；δ 很小也不证明任务成功、价值已准确或策略已最优。α=0.5 是今天的教学步长，不是访问次数的倒数，也不是收敛结论。

真正终止时，目标直接等于进入终止的奖励，不再抽 a_(t+1)，也不对终止状态访问空动作表。把终止后续回报约定为 0，不等于把进入终止的奖励抹掉。教材 §6.4 的式 6.7 和 SARSA 伪代码给出了动作价值更新及下一动作的携带。

3.4 On-policy 的关键：目标中的动作会被沿用

本课的“同策略”指目标中的下一动作按当前行为策略产生，并与下一次执行一致。对一次非终止转移，顺序是：执行已选 a，观察 r 和 x′；用更新前 Q 与合法 mask 选一次 a′；用 Q_pre(x′,a′) 更新 Q(x,a)；然后把 (x′,a′) 作为下一循环的当前状态和动作。

这里不能在更新 Q 后重新抽一次下一动作，却仍保留按旧 a′ 构造的目标；也不能把目标中的 a′ 擅自改为贪心动作，而实际执行别的动作。行为策略随 Q 变化是控制的机制，不能因此破坏已经选定的这一条动作链。

3.5 真终止、外部截断与 reset

下表是更新前的数据检查，不是另一种算法：

情况 本课如何处理
到达原任务终止 z，或任务本身规定 h=0 即结束 d=1，目标为实际 r，不抽下一动作；保存终止原因
采集器停止，但原任务继续，且保有有效、未 reset 的真实 x′、合法 mask 和按同一行为策略选定的 a′ 不能仅因采集停止设 d=1；可按 d=0 构造目标，并保存待执行的 (x′,a′)，续接时沿用
后继图像或状态缺失，mask 不确定，下一动作未有效选定，或是否终止不清楚 保留记录、缺失原因和待处理状态；不补一个虚构动作或未来值来完成本次更新
reset 后得到另一个任务的初始画面 它不是上一条转移的 x′；不能接到旧目标中，也不能用它的动作替换旧 a′

非终止目标需要的是已有效选定的下一动作，不需要它的未来奖励。但若恢复时 UI 已变化使待执行动作失效，应重新核查状态和轨迹一致性，保留这一变化；不能把旧目标和另一条实际动作拼成同一 SARSA 转移。任务自身的时间或预算终止，必须在任务定义里事先给清楚，不能与外部采集故障混在一个 done 标志里。失败、取消和截断记录都要保留；不能只留下成功或完整轨迹，再无条件称为对同一目标的无偏评价。

4. 手算例子或更新过程

4.1 相同环境核，新的行为策略和初始表

以下全部是人为构造的教学条件。没有抽随机数，没有采集 GUI，没有训练模型。沿用 H（主页）、F（表单页）、z（终止）与完整状态 (page,h)，h≤2；每个动作消耗一次预算，到 h=0 真终止。教学核如下：

页面与合法动作 后继与即时奖励
H：open 奖励 −1；若预算尚可继续则进入 F，预算用完则终止
H：stop 奖励 0，终止
F：save 以概率 0.8 得奖励 10、以概率 0.2 得奖励 0；均终止
F：cancel 奖励 0，终止

没有额外 save 成本、终止奖励或预算补偿。今日 γ=0.9、α=0.5、ε=0.2。这些含义不同：γ 缩放未来奖励，α 控制一次表项写入的幅度，ε 定义合法动作内的探索概率。

本课从下面的全新假设 Q 表和零计数开始，不继承 RL-011 的 V，不把模型真值或前课训练结果塞进来：

状态 动作 初始 Q 已执行并更新次数 N
H2 open 1 0
H2 stop 0 0
F1 save 4 0
F1 cancel −2 0

其他合法的 H1、F2 表项可显式初始化为 0、N=0，本条轨迹不访问它们，不能称已经学到了它们的价值。N 在这里用于记录覆盖，不用于改变固定步长 α。环境的 save 成功概率仍是核的条件概率，不是 ε 的动作概率；本条轨迹选择 cancel，所以不会使用 save 的随机结果。

4.2 第一次写入：先选 cancel，再更新 open

在 H2，open 的初始 Q=1 大于 stop 的 0，因此行为概率为 open 0.9、stop 0.1。我们人为指定本条教学轨迹选 open，观察 r=−1 并进入 F1。F1 的更新前 Q 为 save 4、cancel −2，因此 save 概率 0.9、cancel 概率 0.1。

现在人为指定下一动作 a′=cancel。它有正的行为概率，但这不是一次随机采样实验。cancel 先被选定并保存，尚未执行；当前就可以用它的 Q_pre=−2 构造 open 的目标。

第 1 条转移的量 计算与数值
当前状态动作、当前项 pre (H2,open)，Q_pre=1
奖励、后继、真终止 −1，F1，d=0
已选下一动作与后继项 pre cancel，Q_pre(F1,cancel)=−2
目标 y −1+0.9×(−2)=−2.8
TD 误差 δ −2.8−1=−3.8
当前项 post 1+0.5×(−3.8)=−0.9

本次只把 Q(H2,open) 写成 −0.9，并把它的计数增为 1；F1 两个动作值都尚未更新。随后当前状态变成 F1，当前动作变成刚刚选中的 cancel。不能此时再抽一个动作，或因为 save 的 Q 更大就换成 save。

4.3 第二次写入：执行同一个 cancel，终止直接用奖励

继续这条手工指定的轨迹：执行保存下来的 cancel，得到 r=0 并进入 z。真实终止，不抽新的 a′：

第 2 条转移的量 计算与数值
当前状态动作、当前项 pre (F1,cancel)，Q_pre=−2
奖励、后继、真终止 0，z，d=1
下一动作 不存在，不抽取
目标 y 0
TD 误差 δ 0−(−2)=2
当前项 post −2+0.5×2=−1

−2 变为 −1，是该项在朝这次终止目标 0 移动，并不是“cancel 得到了 −1 奖励”。最终表与覆盖为：

状态动作 最终 Q N
(H2,open) −0.9 1
(H2,stop) 0 0
(F1,save) 4 0
(F1,cancel) −1 1

第二次写入后不会自动回到第一条记录，把 H2 的目标重算一遍。第一步使用的确实是当时的 F1,cancel 更新前值 −2。SARSA 的这两次顺序写入不是对整张表同步求解，也没有额外回放。

这条完整轨迹的实际奖励依次为 −1、0，故从 H2 的回报 G=−1+0.9×0=−1，从 F1 的回报 G=0。第一个 TD 目标 −2.8 含有初始化估计的影响，不等于该轨迹的完整回报，更不是业务实测的回报下降。

若之后重新访问 H2，当前 Q 会令 stop 成为唯一贪心动作，其 ε-greedy 概率为 stop 0.9、open 0.1。这说明 Q 写入可能改变后续行为；我们没有生成或执行这个新任务，也没有证明真实成功率或期望回报提高。未访问的 stop 仍只有初始化 0，不能把它当成已验证的优胜动作。

4.4 独立反事实：若当时选的是 save

仅为比较“下一动作”这个输入，回到第 1 次写入前同一张初始表，假设 F1 选定的 a′ 是 save：目标为 −1+0.9×4=2.6；δ=2.6−1=1.6；H2,open 的 post 为 1+0.5×1.6=1.8。

这不是主轨迹中的一次额外写入，不把 1.8 加回上面的最终表，也没有假设 save 实际成功或失败。它只说明，SARSA 使用被行为策略选中的下一动作值；选中 cancel 与选中 save，在相同 pre 表下会得到不同目标。

4.5 最短可检查伪代码

下面仅展示表格型 SARSA 的动作顺序，未运行（NOT_RUN）。输入为明确初始化的 Q、α、ε、γ、任务定义及合法 mask；输出是顺序更新后的 Q 和包含未完成记录的日志。动作执行是伪代码中的概念步骤，并未调用真实 GUI。

初始化每个合法状态动作的 Q 和计数 N=0
每个新任务：观察完整 x，确认不是终止且 mask 已知非空
    a = epsilon_greedy(Q, x)             # 初始动作只选一次
    重复：
        执行当前 a，观察 r、真实 x_next 和 true_terminal
        old_current = Q[x,a]
        若 true_terminal：
            target = r                  # 不选择下一动作
            Q[x,a] = old_current + alpha*(target-old_current)
            N[x,a] += 1；保存日志；结束本任务
        若后继或合法 mask 无效/未知：保存缺失原因并暂停处理
        a_next = epsilon_greedy(Q, x_next)  # 使用写入前的表，选一次
        old_next = Q[x_next,a_next]
        target = r + gamma*old_next
        Q[x,a] = old_current + alpha*(target-old_current)
        N[x,a] += 1；保存 pre、target、post、mask、策略版本、a_next
        x = x_next；a = a_next           # 沿用所选动作，不重新抽样
        若采集器暂停：保存待执行的 (x,a)，原任务不因此标成终止

恢复待执行动作前需确认它仍对应同一任务和状态；若合同已失效，应保留异常并重新核对，不能暗中替换动作而继续使用旧的 SARSA 记录。新任务 reset 与已有 Q 是否继续保留是两个不同选择：控制训练通常跨任务保留 Q，本课的 fresh 初始化只发生在算例开始时，不是每做一步或每 reset 就重新清空。

5. 与前一种方法的关系

RL-011 的一步 TD 用固定策略产生转移，更新 V(x)，后继项是 V(x′)。今天用行为策略产生状态动作链，更新 Q(x,a)，后继项是已选下一动作的 Q(x′,a′)。两者都能在原任务未结束时更新，也都依赖 bootstrap；今天新增的是动作维度与根据 Q 改变后续行为的控制环。

比较项 前一阶段固定策略价值预测 今日 SARSA 控制
学什么 固定 π 的状态价值 V 或动作价值 q_pi 用当前 Q 追随行为策略的动作价值，并改变后续动作分布
一次经验需包含什么 状态、奖励、后继及终止定义等 还要包含当前动作、有效选定的下一动作、合法 mask 和行为策略信息
谁决定后续行动 外部给定固定 π 本课由当前 Q 的 ε-greedy 行为策略决定
新的代价 数据与目标条件已需核查 动作空间、探索交互、策略变化、覆盖和安全合法动作合同更复杂

RL-009 的策略改进基于已知模型和精确旧策略价值，具备相应条件时才有模型内的改进结论。今天的 Q 是初始化加两次采样式写入，不能用“新动作 Q 比另一项大”替代那套前提，宣布每次改策略都使真实回报更好。

也不能拿前面固定旧 π_alpha 的任意日志，直接称为本课新 ε-greedy 策略的数据。例如旧策略在 F 固定 save，而今天选中了 cancel；两个策略不同。把跨版本数据混成同一个固定策略估计，需要另行定义方法与目标，今天不展开。既有 MC、TD 预测的算术结果可作为机制理解的对照；若研究控制性能，还需要真正匹配控制目标和数据条件的比较设计。

6. 一个主要研究应用

主应用选择允许多步操作、能核验任务后果的 GUI 任务控制。这比仅给截图返回一次坐标更接近本课机制：当前动作会改变之后的页面和可行动作，策略需要权衡后续回报。但若任务只有独立单次定位、没有后续状态和延迟反馈，应先建立监督定位或固定流程基线；不能为了使用 SARSA 人造多步奖励。

下面把教学机制映射为研究前必须补齐的 12 项真实合同；真实字段当前均为【待确认】，不是已建好的数据或已完成的实验：

合同项 必须给出的真实定义与检查
1. 观测与完整状态 【待确认】指令、当前画面、可用结构信息、必要历史、剩余预算如何组成状态；仅截图是否足以决定后果，不能未经验证假定 Markov
2. 动作与合法范围 【待确认】点击、输入等如何离散成合法动作，mask 如何产生，禁用/未知动作、空集合及待执行动作失效如何处理；探索只在已允许集合内
3. 行为策略 【待确认】Q 版本、ε、平局规则、动作概率和下一动作携带如何记录；采集与更新是否使用同一个已声明策略规则
4. 奖励与折扣 【待确认】真实成功、失败、取消、步骤与时间成本的单位、权重、γ；不能直接照搬教学的 10、0、−1
5. 反馈来源 【待确认】谁核验任务后果、何时可用、有无延迟和缺失；按钮出现、点击命中或“保存成功”提示是否能证明业务结果
6. 时间与结束规则 【待确认】任务自身终止、预算耗尽、外部采集停止、reset 的独立标志；是否保留有效最终观测、mask 与待执行下一动作
7. 初始任务与重置 【待确认】任务分布、可复现初始状态、重置成本、Q 在任务间如何保留；原任务与新任务的边界怎样核验
8. 数据与覆盖 【待确认】按时间保存状态动作奖励后继下一动作、pre/post、策略版本、失败取消截断与缺失原因；统计状态动作访问次数，不能只报轨迹总数
9. 指标与评价策略 【待确认】任务成功率、折扣回报、错误操作、取消、步骤和时间；使用探索策略还是另行冻结贪心策略评价，要分别标注；δ 小不是效果指标
10. 采集与训练成本 【待确认】环境交互、标注/核验、重复任务、调参和训练开销；表格更新便宜也不等于获得反馈便宜
11. 推理与执行成本 【待确认】视觉编码、候选动作、Q 查询、mask、交互等待、失败恢复与结果核验的延迟和资源成本
12. 方法与非 RL 对照 【待确认】方法核查先验证动作链与算术；非 RL 行为对照可用固定流程、监督定位加流程、示范策略。在相同任务、输入、动作权限、预算和成功判据下比较，并计入各自成本

若将来评估控制，需先锁定训练与评价任务划分、调参预算、初值与 ε/α 计划；对比每种行为产生的交互成本和覆盖，保留失败及截断原因，再使用独立重复报告不确定性。学习曲线的横轴应注明环境交互、更新还是计算成本；评价时变更 ε 也会变更被评价策略。不能把这两条手工轨迹的值表或不同评价策略混成真实提升曲线。本课没有运行这个计划，也不提供经验曲线。

SR 只有在确有连续决策、状态变化、后续质量或成本反馈时，才可能适合这种控制建模；单次监督重建先用对应的监督和固定处理基线。模态路由若只是一次选择并立即得到结果，先判断单步决策是否已足够；只有选择会影响后续观测、成本与任务回报，且数据能记录这些依赖时，再讨论多步控制。不能把教学的 H/F 操作名替换成业务名，就声称算法已适用于三条研究线。

7. 常见误解、失败条件和适用边界

误解或失败 本课的核查办法
“ε=0.2 就是贪心 0.8、另一个 0.2” 写出探索也会选中贪心动作；两合法唯一最大是 0.9/0.1，平局和单合法另算
“下一动作只是临时计算用，更新后可以再抽” 对照日志中的 a′ 与下一条实际动作；不一致就破坏本课的动作链定义
“本条第一个目标 −2.8 就是拿到的回报” 奖励序列只有 −1、0，完整 G 是 −1；目标包含假设 Q(F1,cancel)=−2
“F 的 Q 改了，H 应自动跟着改” 检查是否另有一次明确更新或回放；主例只有两个表项各写一次，不自动回写
“stop 的 0 高于 open 的 −0.9，说明 stop 已学得更好” stop 的 N=0，它只是未被数据验证的初值；行为变化不等于真实改进证据
“单条轨迹、固定 ε 和 α 足以保证最优” 覆盖、步长、策略趋向贪心及表格/近似条件都要另查；这里没有证明收敛
“截断都 done；reset 图可以当后继” 分开真终止与采集边界，核验原任务的有效后继、动作及续接，不接入新任务

教材讨论的表格型 on-policy 控制收敛需要相应条件，例如状态动作被充分反复访问、合适步长条件，以及策略在极限趋向贪心等；不能只写一个算法名就省掉前提。本课固定 α=0.5、ε=0.2 的两步手算既不满足一个完整渐近证明，也不提供神经网络近似的保证。固定 ε 保留探索概率，不会自动变成纯贪心最优策略；ε=0 又不自动保障覆盖。教材 §6.4 对 SARSA 控制及收敛条件的讨论是这些限定的来源。

8. 三道理解题

题 1｜动作概率与同策略。 两个合法动作的 Q 分别为 4 和 −2，ε=0.2，按本课规则各以多大概率被选？若先选了非贪心动作构造目标，更新 Q 后又重抽一个动作执行，会出现什么问题？两个 Q 并列最大或仅有一个合法动作时又如何？

题 2｜两次写入与独立反事实。 从本课 fresh 表出发，顺序为 H2 执行 open、r=−1 到 F1，已选下一动作 cancel；随后执行同一 cancel、r=0 真终止。请列两步的 pre、y、δ、post、最终四个 Q 与 N，并算实际 G。第二步是否回改 H？再回到同一个原始 pre 表，若当时 a′=save，第一步结果是多少，能否写进主轨迹的最终表？

题 3｜GUI 日志是否能用。 一个采集器在非终止 F 页停止，随后 reset 到另一任务；日志只留了新画面，没有原任务合法 mask 和已选下一动作。能否用 reset 图或一个新抽动作补齐旧 SARSA 目标？若采集器保留了原任务真实后继、有效 mask 与已选 a′ 并能续接，又应怎样处理？为真实研究补充至少四项合同、一个非 RL 行为对照，并说明当前能声称什么证据。

参考答案（练习完成后再看）

题 1 参考答案。 唯一贪心动作得到利用分支 0.8，加上探索分支的 0.2/2，所以为 0.9；另一个为 0.1。若两个动作都是最大值，利用分支均分 0.8，各再加 0.1，最终各 0.5；只有一个合法动作时两个分支都选它，概率为 1。若合法 mask 未知或非终止时为空，不能套公式硬抽动作，应保留异常并补合同。

SARSA 的 a′ 来自当前行为策略，并会作为下一次实际动作。先用某个 a′ 的 Q 构造目标，再重抽一个可能不同的动作执行，使目标中的下一动作与实际动作链脱节。应在写入前选一次 a′、记录 Q_pre 与策略信息、完成当前写入，再沿用同一个 a′。一般控制中的 Q 和策略会随更新变化，这不等于当前表已精确评估新策略，也不授权临时换掉已选动作。

题 2 参考答案。 第一步 pre_current=1，已选后继项 pre_next=−2，d=0；y=−1+0.9×(−2)=−2.8，δ=−2.8−1=−3.8，post_Hopen=1+0.5×(−3.8)=−0.9，N_Hopen=1。F 的两项未被这一步写入，接下来必须执行同一 cancel。

第二步 pre_Fcancel=−2，r=0 真终止，不抽 a′；y=0，δ=0−(−2)=2，post_Fcancel=−2+0.5×2=−1，N_Fcancel=1。它朝终止目标 0 移动；−1 是更新后的估计，不是即时奖励。H 不自动回改。最终依次为 Q(H2,open)=−0.9、Q(H2,stop)=0、Q(F1,save)=4、Q(F1,cancel)=−1，N 依次为 1、0、0、1。其余未访问表项仍是初始化，不称已掌握真实价值。

实际奖励 −1、0，故 G_H=−1，G_F=0。第一个 y=−2.8 来自含初始估计的自举，既不等于完整 G，也不证明算法效果。如果之后重新访问 H2，当前表令 stop 概率为 0.9、open 为 0.1；这只是当前选择规则的推论，没有额外轨迹或真实性能。

独立反事实必须回到相同原始 pre 表：若 a′=save，则 y=−1+0.9×4=2.6，δ=2.6−1=1.6，post_Hopen=1+0.5×1.6=1.8。这个分支没有执行，不含 save 的实际奖励，不能合并到 cancel 主轨迹的最终表。

题 3 参考答案。 不能用 reset 后新任务的图替换旧 x′，也不能凭空新抽一个动作来补上本来未知的旧 a′；这会把不同任务、状态或行为链拼在一起。应保留截断、缺失原因和原日志，暂不伪造本次目标。若原任务确实继续，保有有效未 reset 的真实 x′、合法 mask、按同一行为规则已经选定的 a′，则不能因为采集器暂停就改成真终止；可使用 d=0 的目标，并保存待执行 (x′,a′)，续接时沿用，核验状态和动作仍有效。若任务自身预算 h=0，则是真终止，目标直接为 r，不选下一动作。两类情况必须在合同中分开。

可补齐的真实合同包括完整状态及预算、合法动作和许可范围、ε/平局与策略版本、奖励与结果核验、真终止/截断/reset、顺序转移与覆盖、指标及成本。非 RL 行为对照可以是固定流程或监督定位加流程，按相同任务、输入、动作权限、预算和成功判据比较；MC、TD 的预测算术不是这里的非 RL 行为对照。还需区分探索行为评价与冻结贪心策略评价。当前只有教材机制、教学算术和拟议合同，真实训练、GUI 执行和性能均为 NOT_RUN，不能声称成功率提高、已收敛或实际业务已经适用。
