1. 今天解决什么问题，与前面哪些单元有关

RL-008 计算了固定 πα 的价值：从 (H,2) 出发，Vπα=4.65。数值算准以后，策略却仍以 0.25 的概率直接 stop。今天问：能否利用这个价值表改变动作选择；如果不想每次把一个策略完整评估完，又怎样计算最优价值？

本课区分四件事：策略评估计算指定行为的价值；策略改进依据旧策略价值产生新行为；策略迭代交替做评估和改进；价值迭代直接反复更新最优价值的近似表。它们都使用已知模型，不会自动学出真实转移，也不代表已经验证业务效果。

继续使用页面与剩余真实动作数 (s,h) 作为教学状态。h 是任务预算，k 是价值表计算轮次；增加 k 不会增加 h。今天改变的是计算目标与行为规则，环境的奖励、概率、期限和成本保持前课原样。

2. 学习目标

学完后，应当能够：

  1. 区分评估、改进、策略迭代与价值迭代，解释精确旧价值、贪心选择和新策略价值之间的关系及保证条件。
  2. 在同一 GUI 模型上手算一次贪心改进和两轮同步价值迭代，检查 k/h、old/new、终止、平局与停止原因。
  3. 判断模型内规划结果能说明什么，列出真实 GUI 模型、反馈、资源与非 RL 对照缺口，不把教学回报变化当作实际性能提升。

3. 直觉、定义和必要公式

3.1 先确定本次究竟更新什么

计算 输入与主要操作 目标或输出
策略评估 固定 π，按 π 对动作平均 该策略的 Vπ
策略改进 已有旧 Vπ，比较合法动作的期望续行 相对旧 Vπ 贪心的新策略 π′
策略迭代 评估当前策略 → 改进 → 再评估 在相应条件下找到最优策略与 V*
价值迭代 对旧近似表做合法动作最大化的期望更新 逼近 V*，再从表中提取策略

评估时的动作平均与规划时的动作最大化不同。两者都必须对环境的随机结果平均：可以选择 save，不能选择“本次必定保存成功”。

3.2 策略改进：先用旧策略的价值给动作评分

对尚未终止、h≥1 的合法状态，已知旧策略的精确价值后：

Qhπ(s,a)=∑s′,rp(s′,r∣s,a)[r+γVh−1π(s′)]Q_h^\pi(s,a)= \sum_{s',r}p(s',r\mid s,a) \left[r+\gamma V_{h-1}^\pi(s')\right]Qhπ​(s,a)=s′,r∑​p(s′,r∣s,a)[r+γVh−1π​(s′)]
π′(s,h)∈arg⁡max⁡a∈Ah(s)Qhπ(s,a)\pi'(s,h)\in\arg\max_{a\in A_h(s)}Q_h^\pi(s,a)π′(s,h)∈arga∈Ah​(s)max​Qhπ​(s,a)
  • s、s′ 是当前和下一页面；完整状态另含剩余预算 h。
  • A_h(s) 是当前合法动作集合，a 是其中的动作；p 是下一页面与奖励 r 的联合概率，不要求两者独立。
  • r 是当前这一步的奖励；γ 是未来折扣；V_(h−1)^π 是旧策略在下一预算层的价值。
  • Q_h^π 先指定首动作 a，后续才按旧 π，所以不再乘旧策略选择 a 的概率。
  • arg max 返回达到最大值的动作，max 返回最大数值；π′ 是这里选出的确定性新策略。旧 π 可以是随机策略。

“一步前瞻”不是只看即时奖励：评分中的旧 Vπ 已汇总了旧策略的后续回报。但改进后的 π′ 会在后续状态也重新选择动作，因此一般不能把 max Qπ 直接当作完整的新价值 Vπ′，更不能自动当成 V*。

并列最优时需要稳定规则。本课约定：若旧确定动作仍在最大项中就保留；否则按预先固定的动作顺序选一个最大项。由随机旧策略首次转为确定策略时，也按固定顺序打破平局。理论上可在最大项之间分配概率，但若实现不断在等价动作间切换，只看“策略是否改变”的停止判据可能一直不结束。真实浮点近似平局还要说明数值容差，不能把近似相等直接冒充精确相等。

3.3 改进保证依赖什么？

精确 Vπ 下，合法动作最大值至少不小于旧策略对同一组 Qπ 的平均：

Qhπ(s,π′(s,h))≥∑a∈Ah(s)π(a∣s,h)Qhπ(s,a)=Vhπ(s)Q_h^\pi(s,\pi'(s,h)) \ge \sum_{a\in A_h(s)}\pi(a\mid s,h)Q_h^\pi(s,a) =V_h^\pi(s)Qhπ​(s,π′(s,h))≥a∈Ah​(s)∑​π(a∣s,h)Qhπ​(s,a)=Vhπ​(s)

在同一个有限预算模型中，从 h=0 的共同零边界向上归纳：若新策略在更小预算层不差，那么以新续值替换旧续值不会降低期望；再接上上式，就得到 V_h^π′(s)≥V_h^π(s)。这里使用相同模型、合法动作、奖励、期限、精确旧价值和非负 γ。它保证各状态不差，不要求每个状态都严格变好，也不保证一次改进就全局最优。

不能把这个精确结论直接套在任意近似表上。例如未评估的全零表会把 H2 的 open 评分算成 −1、stop 算成 0，贪心便选 stop；其真实模型内起点价值为 0，反而低于旧 πα 的 4.65。这个反例针对不准确的改进依据，不表示后面价值迭代的中间表应当被当作旧策略精确价值，也不表示价值迭代无效。

上述动作评分、策略改进定理及随机旧策略的扩展，可核对 Sutton 与 Barto 第二版原稿 §4.2册页 78～80。

3.4 策略迭代：改完后还要重新评价

策略迭代反复执行“当前 π → 评估得到 Vπ → 按它贪心产生 π′ → 重新评估 π′”。评估阶段的策略保持不变，不能一边声称评价旧 π，一边悄悄换动作概率。

在有限状态、有限动作、有界奖励、0≤γ<1、精确评估和稳定平局处理下，进入确定性策略集合后，非最优策略的贪心改进会在至少某处严格改善；有限个确定性策略使理想策略迭代能在有限次策略改进后停止。当前有限预算模型也可依其零边界与分层结构论证。任意持续任务的 γ=1 不自动具有同样保证。

这些条件不表示计算机上的任意小阈值评估都“已经精确”。用近似 V、提前停止或错误模型时，要另外分析误差；一次近似策略未变化，也不能自动证明已求得真实最优策略。教材的相关过程在 §4.3，册页 80～82，其中册页 82 的练习明确提醒等价策略切换可能影响终止。

3.5 价值迭代：把最优关系直接变成更新

策略迭代可能在每次改策略前花很多轮评估。价值迭代把改进与截断的价值计算结合起来；同步版本为：

vk+1(s,h)=max⁡a∈Ah(s)∑s′,rp(s′,r∣s,a)[r+γvk(s′,h−1)]v_{k+1}(s,h)= \max_{a\in A_h(s)} \sum_{s',r}p(s',r\mid s,a) \left[r+\gamma v_k(s',h-1)\right]vk+1​(s,h)=a∈Ah​(s)max​s′,r∑​p(s′,r∣s,a)[r+γvk​(s′,h−1)]

小写 v_k 是第 k 轮近似表，目标为 V*，不再声称它是某个固定策略的精确价值。k 从初始化 0 开始；本轮所有状态只读 old=v_k，整轮结束才提交 new=v_(k+1)。即时奖励只计一次，后继读取 h−1，不额外赠送动作预算。

每轮都固定 v_k(s,0)=0、v_k(z,h)=0；终态或无预算时直接取边界，不对空动作集合求 max。导致终止的当步奖励仍保留。h 每次减 1 是本教学核的约定，真实动作预算消耗不同或时间规律变化时，必须改变完整状态与核。

计算结束后，用最终表 v_K重新做一次上式右侧的动作评分，按 arg max 提取策略。记录所用的 K，不能把生成某轮 new 时基于 old 的动作记录，与基于最终表重新评分的策略混为一谈。更新规则可核对 教材 §4.4，册页 82～84，式 (4.10)。

3.6 收敛与停止：有限预算和一般折扣分别说明

对有限状态/动作、有界奖励、固定且概率归一的模型与 0≤γ<1，最优期望更新 T* 对两张表的最大差异至多乘 γ：概率平均不会放大最大差异，对同一组动作取 max 也不会超过动作评分的最大差异。因此同步价值迭代从任意有限初表趋近该模型的 V*。这只是模型内计算结论；γ 接近 1 时可能需要更多轮，表规模与结果枚举也有成本。

γ=1 时没有同样的严格折扣收缩，需另核对终止等条件。本课 h≤2、固定零边界且每步减 1，最多两层后继影响；即使内部初表不是零，经过两轮也能消除初始化误差。这来自有限深度，不能推广为一般算法两轮收敛。按 h 从小到大直接回代也是合法的有限时域安排，但不等于一次全表同步 sweep；原地法也不能被一概判错。

仍用 Δ_k=max|v_k−v_(k−1)|监测全表数值变化。正阈值 θ 的单位是回报，另设计算上限 K_max；达到上限与观察到 Δ_k<θ 是不同停止原因。Δ 小不直接证明模型可信、提取策略已精确最优或真实业务误差小。本课不把 Δ 当作未经证明的业务性能界。

4. 手算与更新过程：同一 GUI，先改策略再比较价值迭代

4.1 条件原样保留

以下页面、概率、奖励与策略都是教学假设。完全沿用 RL-004～008 的新 GUI 模型，不混入 RL-002 的另一套参数。

页面与合法动作 下一页面 当前奖励 环境概率
H, open F −1 1.00
H, stop z 0 1.00
F, save z，成功 10 0.80
F, save z，失败 0 0.20
F, cancel z 0 1.00

γ=0.9，初态 (H,2)，h≤2。每个真实动作消耗一步，save 不另扣成本；进入 z 或 h=0 后结束，无额外未完成罚分或补发收益。每个页面—动作组分别归一；页面与预算充分是教学理想，不证明真实截图是 Markov 状态。

旧 πα 在 H 以 0.75/0.25 选择 open/stop，在 F 必定 save；适用于 h>0 的合法决策点。它的精确价值来自前课：H2=4.65，H1=−0.75，F1=F2=8，零预算和终态为 0。F2 不从当前初态 H2 到达，但在完整计算域里合法。

4.2 对精确旧价值做一次贪心改进

完整状态 旧 Qπα 的合法动作评分 新 π′ 旧 Vπα 重新评价的新 Vπ′
(H,2) open：−1+0.9×8=6.2；stop：0 open 4.65 6.2
(F,2) save：0.8×10+0.2×0=8；cancel：0 save 8 8
(H,1) open：−1+0.9×0=−1；stop：0 stop −0.75 0
(F,1) save：8；cancel：0 save 8 8

新策略在 F 保存，在 H 根据预算决定；只按页面 H 固定一个动作不足以表达它。这个模型没有并列最大项，但实现仍应保留稳定平局规则。

重新评价 π′：从 H2 必定 open，之后 save，成功/失败完整路径概率为 0.8/0.2，路径回报分别为 −1+0.9×10=8 与 −1，因此 V₂π′(H)=0.8×8+0.2×(−1)=6.2。H1 选择 stop 得 0，F 仍得期望 8。各状态均不差，F 并未严格变好。

这里一次改进恰好得到 V*：下一层 F 已选最优 save，H1 与 H2 也分别选到各自最优动作。这是本模型的特殊结构，不是“一步前瞻永远一步求全局最优”的一般定理。再用新价值做贪心，策略保持不变；这展示了“评估 → 改进 → 再评估 → 检查稳定”的策略迭代流程。

H2 从 4.65 到 6.2，相差 1.55 个教学回报单位。它不是实际成功率提升、百分点、训练结果或研究效果证据。

4.3 价值迭代：同样从零表出发，但使用 max

第一轮 H2 的候选值是 open=−1+0.9v₀(F,1)=−1、stop=0，所以 v₁(H,2)=0；不能读取本轮刚写出的 new(F,1)=8。F 的即时保存期望为 8；H1 也在 −1 与 0 中选 0。

第二轮 H2 才读取 old(F,1)=v₁(F,1)=8，得到 max{−1+0.9×8,0}=6.2：

价值表位置 v₀ v₁：第 1 轮 v₂：第 2 轮 v₃：停止核查
(H,2) 0 0 6.2 6.2
(F,2) 0 8 8 8
(H,1) 0 0 0 0
(F,1) 0 8 8 8
h=0 或 z 0 0 0 0

Δ₁=8，Δ₂=6.2，Δ₃=0。与 RL-008 的 Δ₂=5.4 不同，因为这次采用最优更新，目标与表格已改变。第二轮已是本例精确 V*，第三轮才在数值上观察到不变；第三轮不是 GUI 新动作。

若 θ=0.000001、K_max≥3，第三轮观察到阈值满足；若 K_max=2，返回表虽恰好精确，但停止原因仍为 iteration_limit。基于最终 v₂ 提取的策略为 H2 open、H1 stop、F save。

4.4 同步价值迭代的短伪代码

input: states, legal_actions, model_p, gamma, theta>0, K_max>=1
v = zero_table(states)                 # boundary entries always zero
reason = "iteration_limit"
for k in 1..K_max:
    old = copy(v)
    new = zero_table(states)
    for each nonterminal (s,h) with h>=1:
        score[a] = sum_(s_next,r) model_p[s_next,r|s,a] *
                   (r + gamma * old[s_next,h-1])   # legal a only
        new[s,h] = max_a score[a]
    delta = max_abs_difference(new, old)
    v = new                           # commit after the full sweep
    if delta < theta:
        reason = "tolerance_reached"
        break
policy = greedy_with_stable_ties(v, model_p)        # recompute using v_k
return v, policy, k, delta, reason

states 包含所需后继和固定零边界。score 是当前合法动作的模型期望，不是模型输出的置信分数；policy 提取时还使用相同的合法动作、γ、h−1 与终止规则。循环结束后的 v 就是 v_k，必须重新基于它评分，不复用最后一轮基于 old 的 score。这里的规划计算没有采集真实环境数据或训练网络。

5. 与前一种方法的关系

与 RL-008 比较 本课改变了什么 代价与限制
固定 π 的期望更新 策略改进产生新行为，再重新评价 精确改进保证不能直接套近似或错误价值
只问指定行为怎样 策略迭代交替评估和改进 每次评估可能需要许多轮，平局要稳定
表的目标为 Vπ 价值迭代用最优更新逼近 V* 枚举全部合法动作与模型结果，仍需可信模型
一个计算方案的数值结果 区分模型内更优与真实任务有效 模型核验、资源与实际对照不能省略

策略迭代与价值迭代不是两种新的奖励，也不是两套 GUI 环境。它们在相同模型和目标下组织价值计算与动作选择。有限预算时还可直接从零边界分层回代；一般问题中谁更省时，应按状态、动作、模型结果数、评估精度和实际轮数判断，不保证某方法始终最快。

6. 主要应用：可信 GUI 模型上的预算规划

本节为工程推断。若已有可信、可计算的 GUI 转移与奖励模型，可以在相同输入权限和动作预算内规划一个执行策略。真实 GUI 的单次定位不自动成为这个规划问题；任务必须包含动作如何改变后续信息、合法选择和完成机会。

项目 实际需要明确什么 当前事实边界
观测与状态 指令、截图、合法历史、DOM/接口权限及状态充分性 【待确认】真实输入；截图不自动是完整状态
合法动作 点击、输入、滚动、取消、结束、参数和执行反馈 【待确认】动作接口及失败语义，不默认可撤销
模型与时间依赖 p 的来源、覆盖、异步/失败建模、每动作预算消耗 【待确认】真实核；教学 .8 不是实测成功率
策略与约束 允许动作、动作屏蔽、停止规则、执行器版本 【待确认】可部署行为，不移植教学 stop 的业务含义
奖励与单位 可信完成收益、过程/调用/错误代价、γ 或约束 【待确认】业务目标与成本，不套收益 10、成本 1
反馈来源 独立回读持久状态或目标值，必要时人工核查 【待确认】真实成功判据；保存提示不是持久成功
初态与起止 任务抽样、重置、真正终止、任务期限、外部截断 【待确认】实际分布和预算；重置不接旧轨迹
数据与模型核验 完整后果记录、失败/取消、模型/策略版本、独立留出核验 【待确认】覆盖和模型偏差，未观测反事实保持未知
评价指标 模型内价值/残差、独立真实任务成功率/回报、步骤/错误/成本 【待确认】真实协议；模型内最大值不替代实际结果
建模/训练成本 数据、标注、估计转移与奖励、模型验证及计算 【待确认】实际预算；给定模型后的 DP 不等于免费建模
规划与执行成本 表内存、动作/结果求和、轮数；执行调用、等待、恢复和验证 【待确认】端到端资源；搜索更多也要计费
非 RL 对照 同模型枚举/有限时域回代或规划；固定规则、监督定位加流程、示范策略 【待确认】实现，匹配任务、输入、底层模型和预算

先用同模型枚举或分层回代核对规划是否正确，再用独立真实任务检查模型与执行效果。优化器可能偏爱模型错误地高估的分支；把错误模型里的 max 算得更准，并不会修复模型偏差。只有更换算法而同时增加 DOM、底层模型能力或重试预算时，不能把效果差异全部归因于规划算法。

一个可检验的研究假设是：真实模型、反馈和资源条件明确后，预算感知的模型规划能否比匹配条件的固定流程更好完成完整任务？还需独立数据和实际对照；本课状态为 未运行（NOT_RUN），没有采集或执行真实 GUI。

SR 与模态路由只作条件筛查：普通一次 SR 重建先比较监督映射；若存在实际早停/计算分配动作，才补状态、质量—成本和固定预算基线，不能使用部署时不可得的 HR 真值误差。独立单步路由先确认真实输入、标签、合法分支与反馈；全动作可信结果可支持成本敏感监督，只有所选反馈时再判断 Bandit 结构。没有后续决策就不强行套本课多步规划，真实资料均待确认。

7. 常见误解、失败条件和适用边界

误解或失败 本课纠正 一个可复核点
把固定 π 的动作平均改成 max 仍叫评价原 π 更新目标已经改变 分清 RL-008 的 −0.75 与本课 v₁(H2)=0
一步前瞻只看一步奖励 还使用旧策略的后续价值 精确 Qπα(H2,open)=6.2
贪心一次必得 V* 一般只保证不差，仍要重评估 本例 F 续行已最优才恰好一次到最优
对任意近似表贪心也有同一保证 精确旧 Vπ 条件缺失 未评估零表让 H2 选 stop，模型内价值 0
max 可以挑成功的环境结果 max 只选可控合法动作 save 仍按 .8/.2 平均，不拿成功收益 10 当期望
同轮先算 F 就可让 H 读取新值 那是另一种计算安排 本课 H2 第一轮只读 old(F1)=0
多算一轮就多一步预算 k 与 h 是两种计数 H1 无法再获得保存机会
策略来回切换就是不断变好 并列最优可能只有动作变化 保留最大项中的旧动作，或固定平局规则
γ=1 仍有无条件严格收缩 一般折扣条件不成立 单独使用本例有限 h 的层数论证
算出 6.2 就验证了 GUI 改善 只验证教学模型中的规划计算 真实反馈、模型与匹配基线仍待确认

8. 三道理解题：先独立作答

请先用约 8 分钟作答，数值均使用第 4.1 节同一教学模型，答案统一放在文末。

题 1｜评估、改进与保证。 对精确旧 Vπα，列出 H2、H1、F 的 Qπα 动作评分，给出一次贪心策略 π′，并重新评价各状态。为什么旧 πα 的 Q(H2,open)=6.2 仍不表示旧策略最优？一般一次改进是否必得 V*、每个状态是否必严格改善？若把未评估的全零表当成改进依据，H2 会怎样选择，为什么精确改进保证不能照搬？

题 2｜价值迭代的两种编号与停止。 从 v₀=0 写出 H2/F2/H1/F1 和零边界的 v₁、v₂、v₃，说明为什么 H2 第一轮为 0 而不是 6.2；核对 Δ₁、Δ₂、Δ₃。θ=0.000001、K_max=2 时返回什么停止原因？用最终 v₂ 提取什么策略？它与策略迭代“先评估固定 π 再改进”的组织方式有什么区别？

题 3｜真实规划证据与条件。 某 GUI 团队直接采用教学 .8，把保存提示当成功；规划结果为 6.2，真实模型覆盖、输入权限与成本未知，且程序在等价动作间来回切换。它能否报告真实业务改善或已求得真实最优策略？应补哪些任务、反馈、数据、资源与非 RL 对照？如何处理平局与近似评价的条件，γ=1 又为何不能直接套一般折扣结论？

参考答案（练习完成后再看）

题 1。 H2 的 open=−1+0.9×8=6.2、stop=0；H1 的 open=−1、stop=0；F1/F2 的 save=8、cancel=0。贪心 π′ 在 H2 open、H1 stop、F save。重新评价得 Vπ′=(6.2,8,0,8)，按 H2/F2/H1/F1 排列。H2 的完整成功/失败概率为 .8/.2，回报 8/−1，期望为 .8×8+.2×(−1)=6.2。旧 πα 在 H2 仍有 .25 概率 stop，故旧 V=4.65，不因某个指定动作 Q 已达 6.2 就最优。

精确旧价值下新策略各状态不差，F 在本例不变；一般不保证一次最优。此例 F 旧续行已最优，H 也按预算选对，才一次得到 V*。未评估零表把 H2 的 open 评分算成 −1、stop 算成 0，于是选 stop，其模型内价值为 0；缺失精确 Vπα 条件，不能套原改进保证。这不否定价值迭代作为另一种最优价值计算过程。起点 4.65→6.2 的差 1.55 只是教学回报单位。

题 2。 按 H2/F2/H1/F1/零边界排列，v₀=(0,0,0,0,0)，v₁=(0,8,0,8,0)，v₂=(6.2,8,0,8,0)，v₃=v₂。第一轮 H2 只读 old(F1)=0，在 −1 和 0 中取最大；本轮 new(F1)=8 不能提前使用。第二轮才读 v₁(F1)=8。Δ₁=8、Δ₂=6.2、Δ₃=0，k 只是计算轮次，h 不增加。K_max=2 返回 iteration_limit，不能虚构已观察到第三轮；用最终 v₂ 重新评分得 H2 open、H1 stop、F save。

策略迭代先评估当前固定 π，再依据该 Vπ 改策略并重评估；价值迭代每轮直接对近似表做最优期望更新，不声称每轮表就是某个固定 π 的精确价值。两者都对环境结果平均，只有合法动作选择采用最大化；稳定策略还需要明确平局规则。

题 3。 不能。教学 .8、模型内价值 6.2、保存提示都不是独立真实任务证据；计算最优不证明模型正确。应明确输入权限与历史、状态充分性、合法动作及后果、p 来源和覆盖、奖励与单位、独立持久回读、初态重置、真实期限与外部截断、完整失败/取消日志及模型/策略版本；未知项标【待确认】，未执行分支保持未知。分别统计建模/训练、规划计算和真实执行成本。

先以同模型枚举或有限时域回代核对规划，再与固定规则、监督定位加流程、示范策略等匹配任务、输入、底层模型、动作预算和成功判据，独立评价完整结果。平局时保留仍为最大项的旧确定动作，否则用固定顺序；浮点容差另行说明。精确策略改进与有限终止的理想条件不能直接套近似评价或策略未变。γ=1 不具一般严格折扣收缩，本课可用有限预算分层论证；一般持续任务需额外条件。当前真实研究实验仍为 NOT_RUN。
