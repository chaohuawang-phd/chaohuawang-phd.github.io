1. 今天解决什么问题，与前面哪些单元有关

这一周已经学会了几种表格控制目标。应用时首先要解决的却是：哪些动作真的允许尝试？进入确认页算不算成功？收集器停止后，旧任务还在不在？一个“安全探索”的名字，不能替代这些定义。

本课用一个两步、完全有限的 GUI 教学任务，串起先确定允许范围，再选择行为，记录真实后果，按各自目标更新，最后独立评价的工作链。今天不新增算法，也不提出 Safe RL 定理。“安全”仅指在给定教学先验下约束探索范围；范围内仍有失败风险，更不等于真实业务已获安全保证。

RL-015～016 提供同一转移的两种目标；RL-017 提醒我们，页面内动作有概率不等于路径已覆盖；RL-018 说明改变估计目标不会产生缺失反馈；RL-019 限定了长期表格结论的前提。今天将它们落到一份能检查的任务说明，而不把有限手算当作收敛或效果实验。

2. 学习目标

  1. 能完整说明小导航 MDP 的状态、合法动作、转移奖励、任务内预算、初态、结束和 reset，指出哪些是先验约束。
  2. 能从独立的同一 pre 表复算 SARSA 与 Q-learning 的两次更新，分清规则流程、估计目标、实际下一动作与模型内最优参照。
  3. 能为真实 GUI 写出可执行前必须补齐的反馈、数据、指标、成本和非 RL 基线，并判断外部截断、mask 缺失和成功提示不足时应保留什么记录。

3. 直觉、定义和必要公式

3.1 先定义一个闭合的小任务

以下环境重新命名、重新定义：N 是导航菜单，C 是提交确认页，z 是任务终止。它不是旧 H/F 保存任务的修订，也不是 RL-017、019 中冻结 X/Y 的采集反例；下面的新成功概率与奖励不覆盖前课定义。

有限状态集合只有 N2、C1、z：N2 表示菜单与剩余动作预算 h=2，C1 表示确认页与 h=1。初态分布全部在 N2。每个实际任务动作消耗一次预算；到 h=0 是任务定义内的真正结束。任务也可提前退出。不包含 N1、C2 等额外状态；下表对从初态出发的全部合法转移闭合。

完整状态 已允许动作 后继与即时奖励 概率 真终止及结果
N2 review：打开确认页 C1，r=−1 1 否；仅完成导航
N2 exit：退出任务 z，r=0 1 是；退出，非成功
C1 confirm：确认提交 z，r=8 0.9 是；独立核验持久成功
C1 confirm：确认提交 z，r=−4 0.1 是；独立核验失败
C1 cancel：取消 z，r=0 1 是；取消，非成功

每个合法状态动作的概率和为 1。折扣 γ=0.9。奖励是人为给定的无量纲效用：review 的 −1 已包含这次导航成本；confirm 成功为 8、失败为 −4，不再另扣一次步骤成本，没有终止加分或预算补偿。失败虽有负效用，仍是本教学许可范围内可能出现的后果。

若用环境联合核记号，例如：

p(C1,−1∣N2,review)=1,p(z,8∣C1,confirm)=0.9,p(z,−4∣C1,confirm)=0.1.p(C1,-1\mid N2,\mathrm{review})=1,\qquad p(z,8\mid C1,\mathrm{confirm})=0.9,\qquad p(z,-4\mid C1,\mathrm{confirm})=0.1.p(C1,−1∣N2,review)=1,p(z,8∣C1,confirm)=0.9,p(z,−4∣C1,confirm)=0.1.

p(x′,r|x,a) 是给定完整状态 x、执行动作 a 后，后继 x′ 与奖励 r 的联合条件概率；竖线表示“给定”。其余非零项已在表中列全，其他项为 0。P 通常表示转移概率，R 表示奖励或期望奖励；本课直接用联合核与实际 r，避免混用一次奖励和奖励期望。γ 决定跨一步未来奖励的折扣。

z 的后续回报约定为 0，不再选择动作或查询空动作表。进入 z 的奖励仍保留，包括 8 或 −4；同一 z 可伴随不同进入奖励和结果标志，因为终止后都没有未来决策。任务终止原因与成功标志另外记录，不能因都进入 z 就把退出和成功混为一类。

教学中观测直接给出完整 N2/C1 和可信 mask，单次 confirm 转移包含等待独立核验的过程，核验完成后才返回结果与奖励。真实截图并不自动具备这个完整状态条件；若核验仍待定，不能先补一个成功标签。

3.2 mask 先于探索和最大化

本任务先验允许集合为 A(N2)={review,exit}、A(C1)={confirm,cancel}。界面即使还有 delete 之类候选，也不在本次任务许可内；它没有纳入这个受限 MDP 的合法 Q 表或转移核。这个限制由教学设计者事先提供，不是 SARSA 或 Q-learning 学出来的风险识别能力。

例如，mask 前的原始候选评分器若给 delete 打出 99，这个 99 只是 MDP 外候选评分，不能进入合法动作概率、argmax 或 bootstrap。规则、SARSA、Q-learning 都使用同一许可范围；不能只给某一个方法屏蔽风险，再比较成算法优势。移除允许动作也会改变所求问题：本课最优值只属于这个事先定义的受限任务，不代表更大真实任务的全局最优。

对当前 pre 表，在 k 个合法动作中有 m 个并列最大，本课沿用“利用时在最大集合均匀选，探索时在全部合法集合均匀选”：

b(a∣x)=εk+1−εm1{a 在合法最大集合中},a∈A(x).b(a\mid x)=\frac{\varepsilon}{k} +\frac{1-\varepsilon}{m}\mathbf{1}\{a\text{ 在合法最大集合中}\}, \qquad a\in A(x).b(a∣x)=kε​+m1−ε​1{a 在合法最大集合中},a∈A(x).

b 是实际行为策略；ε 为探索分支概率；k、m 分别是合法动作数与最大动作数；指示量在条件成立时为 1，否则为 0。非法候选的概率为 0。ε=0.2、两合法且唯一最大时是 0.9/0.1；两个合法都最大则各 0.5；只剩一个合法动作则概率 1。mask 改变后必须按新的合法数量与排序重算，不能仍除以 mask 前候选数。

合法不等于没有后果风险：confirm 仍有 0.1 的教学失败概率。低 ε、正奖励或负惩罚都不能代替实际权限与结果核验。教材 §2.2 支持全动作均匀探索定义；Gymnasium 官方 mask 教程说明探索、利用及后继 max 都要过滤动作，本课不采用该教程的实验结果或整段训练代码。

3.3 更新目标与任务边界

对已执行 x,a，观察即时奖励 r、原任务真实后继 x′；d=1 表示真正终止，否则为 0。Q_pre、Q_post 是本次写入前后估计；α 是步长，本课 0.5。SARSA 的 a′ 是写入前按行为策略选定、随后应沿用执行的下一动作；Q-learning 的 u 只遍历后继合法集合：

ySARSA={r,d=1,r+γQpre(x′,a′),d=0,yQL={r,d=1,r+γmax⁡u∈A(x′)Qpre(x′,u),d=0.y_{\mathrm{SARSA}}= \begin{cases}r,&d=1,\\r+\gamma Q_{\mathrm{pre}}(x',a'),&d=0,\end{cases} \qquad y_{\mathrm{QL}}= \begin{cases}r,&d=1,\\r+\gamma\max_{u\in A(x')}Q_{\mathrm{pre}}(x',u),&d=0.\end{cases}ySARSA​={r,r+γQpre​(x′,a′),​d=1,d=0,​yQL​={r,r+γmaxu∈A(x′)​Qpre​(x′,u),​d=1,d=0.​
δ=y−Qpre(x,a),Qpost(x,a)=Qpre(x,a)+αδ.\delta=y-Q_{\mathrm{pre}}(x,a),\qquad Q_{\mathrm{post}}(x,a)=Q_{\mathrm{pre}}(x,a)+\alpha\delta.δ=y−Qpre​(x,a),Qpost​(x,a)=Qpre​(x,a)+αδ.

y 是各自的一步目标，QL 缩写 Q-learning；δ 是目标减当前估计，不是真实价值误差。本次只写当前一项，其他项不动。Q-learning 不需要 a′ 来构造当前目标；SARSA 需要有效选定的 a′，且不能在写入后重新抽一个替换它。定义与动作顺序见教材 §6.4～6.5。

边界 本任务或采集协议的含义
真终止 exit、cancel、confirm 后均到 z；最后一动作使 h=0 也是任务内结束，y=r，不查未来
外部截断 如采集器在 review 后停机，原任务仍为 C1；不因停机改 d=1。有有效旧 C1 与 mask，QL 可构目标；SARSA 还需有效选定且可沿用的 a′，否则保留待核、不补动作
reset 只在任务间准备新 N2；新初态不属于上一条转移的 x′。外部停止后若选择放弃续接，也必须保留旧边界，不能把 reset 图接入旧目标

本教学 reset 不产生任务内奖励，也不消耗下一任务的 h；若将来真的采集，应在总资源成本中单独记录重置时间与费用。训练协议可跨任务保留 Q，reset 环境不等于重置表。本课 fresh Q 只在独立对照开始时初始化一次。有限期限需要保留剩余预算，与外部停止的区别可见 Gymnasium 官方时间限制说明；这不是本机安装或运行了 Gymnasium 的声明。

4. 手算例子或更新过程

4.1 两份相同 pre 表，规则流程单列

下面全部人为指定，不抽随机数、不执行 GUI、不训练。SARSA 与 Q-learning 各用一份相同初始表，所有有效写入计数 N=0：

合法状态动作 两方法共同 fresh Q_pre N
N2,review 1 0
N2,exit 0 0
C1,confirm 4 0
C1,cancel −2 0

这些是估计初值，不是环境真值或前课最终表。γ=0.9、α=0.5、ε=0.2。初始 N2 的 review/exit 概率为 0.9/0.1，C1 的 confirm/cancel 概率也为 0.9/0.1。

非 RL 规则流程另外声明为“review 后 confirm”，知道任务设计者给出的流程先验，不使用 Q 更新；其动作概率为 1、1。所有方法共享同一环境、许可范围、奖励、初态和两步预算，但规则的先验信息必须披露。不能把这个规则伪装成与学习方法相同的探索行为，或暗称它经历了下面的 cancel 轨迹。

4.2 相同 review 转移，不同后继目标

两份学习表的人为轨迹都先执行 review，观察 r=−1、到 C1、d=0。SARSA 在当前写入前选定 a′=cancel，并保存待执行动作；在这份 pre 表下它有 0.1 概率。Q-learning 的行为也人为指定下一步实际选 cancel，当前目标本身不需要它。第一步只改 N2,review，不改 C1，因此两种动作选择时机在本例后继行为概率一致。

第一步的量 SARSA 独立副本 Q-learning 独立副本
当前 pre 1 1
后继读取 已选 cancel 的 −2 max(4,−2)=4
y −1+0.9×(−2)=−2.8 −1+0.9×4=2.6
δ −2.8−1=−3.8 2.6−1=1.6
N2,review 的 post 1+0.5×(−3.8)=−0.9 1+0.5×1.6=1.8

两列不能顺序写入同一张表。4 只是 confirm 的估计，不是期望奖励 6.8，更不是已经观察到成功奖励 8；实际未执行 confirm，不编造它的反馈。delete 的原始候选评分 99 也不能参与 max。

4.3 实际沿用 cancel，保留终止奖励

接下来两条学习轨迹都执行 cancel；SARSA 必须沿用刚才选定的同一个动作。观察 r=0、到 z、d=1。两份表此时的 C1,cancel 都仍为 −2，所以 y=0、δ=2、post=−2+0.5×2=−1。没有下一动作，不取空集 max，也不再次改第一步。

两条实际奖励都是 −1、0，完整折扣回报 G=−1+0.9×0=−1，成功标志为否。−0.9、1.8 是含初值与自举的估计，−1 是这条完整轨迹的 G；不能按两个 post 大小宣称算法优劣。未访问的 exit 和 confirm 仍只有初值，不算已学准。

4.4 已知小模型的规则与最优参照

现在另做已知模型计算，不修改上面两份 Q。C1 的 confirm 期望即时奖励为 0.9×8+0.1×(−4)=6.8，大于 cancel 的 0；N2 的 review 在之后选 confirm 时，其期望回报为：

V∗(C1)=6.8,Q∗(N2,review)=−1+0.9×6.8=5.12,V∗(N2)=max⁡(5.12,0)=5.12.V^*(C1)=6.8,\qquad Q^*(N2,\mathrm{review})=-1+0.9\times6.8=5.12, \qquad V^*(N2)=\max(5.12,0)=5.12.V∗(C1)=6.8,Q∗(N2,review)=−1+0.9×6.8=5.12,V∗(N2)=max(5.12,0)=5.12.

星号表示这个受限教学 MDP 的最优期望值。V* 是最佳续行的状态价值，Q* 是先强制执行指定动作、之后最佳续行的动作价值；它们不是当前 fresh Q。按表完整比较，最优规则为 review→confirm。不是取环境分支里最大的奖励 8、忽略 0.1 失败；最大化选的是合法动作，随机后果仍需平均。

该规则成功路径的 G=−1+0.9×8=6.2，失败路径的 G=−1+0.9×(−4)=−4.6；以概率 0.9、0.1 加权，得到 5.12。5.12 不是某条成功路径的回报。规则在模型内成功概率为 0.9，仍非零失败风险；每任务两动作，不含独立核验的时间成本。

这些精确参照可以检查奖励与任务合同是否一致。它们不证明规则、SARSA 或 Q-learning 的真实成功率，也不是对两个学习方法的训练后评价。若以后比较性能，应冻结各自评价策略、匹配交互与调参预算，记录先验信息和全部成本；不能把已知模型规则与两次初始化写入的不同信息条件包装成学习优势。

RL-019 讨论长期充分条件；本课把它落实为有限预算内能交付什么：实际覆盖表、有效目标、失败和缺失、边界标志、许可版本与独立结果。对禁止的 delete，不应为了“全动作覆盖”而执行；本课结论只针对已明确的受限 MDP。更大真实任务的未建模动作与后果仍未知。

这个教学任务只有四个合法状态动作，初态下均有到达或选择机会；本次人为轨迹却只写了其中两个。正机会不等于有限日志全覆盖，mask 也不能把 RL-017 的稀有路径问题自动消除。旧 H2 任务不可达的 H1/F2、冻结 X/Y 退火反例仍保持原定义，不能把它们的计数合并进新 N2/C1。

6. 一个主要研究应用：可核验的小型 GUI 导航

本课主要应用是在明确许可范围内，为多步 GUI 导航设计采集与控制合同。选择它是为了连接本周前置，不代表真实业务已经被定义，也不代表它是三条研究线的实际优先级。若任务只是给一张截图返回控件坐标，先建立监督定位基线；多步执行需同时评估后续页面与持久业务结果，单次定位正确不能代替任务成功。

真实研究尚缺下面的资料，所有字段保持【待确认】。这份表可以填写后再设计实验，不能直接拿教学核替代真实成功率。

合同项 真实任务必须补齐的定义与检查

3. 先验与方法信息 【待确认】固定流程知道什么、学习方法知道什么，是否使用模型；规则先验、监督定位和示范来源都应披露
4. 行为与更新协议 【待确认】ε、平局、合法分母、Q 快照、α/按对计数、SARSA a′ 与 carry；目标与实际动作分开记录
5. 奖励与代价 【待确认】成功/失败/取消、误操作、步骤、时间的单位和权重，γ；不能照搬 8、−4、−1 或把惩罚当权限
6. 独立持久反馈 【待确认】谁、何时验证真实目标记录/文件/配置已持久改变，失败和核验缺失如何返回；成功提示、控件命中或页面跳转不足以单独证明完成
7. 结束与外部停止 【待确认】任务终止原因、内在预算、外部截断分开标注，保留原任务后继与 mask；核验待定不能改成成功或失败终止
8. 初态、reset 与恢复 【待确认】初始任务分布、隔离的测试副本、重置是否恢复完整状态及成本，是否仍能续接已选动作；Q 是否跨任务保留单独约定
9. 数据与覆盖 【待确认】真实 x,a,r,x′、结果标志、版本、mask、行为概率、pre/y/post、a′/carry、访问与有效写入计数；失败、取消、截断和缺失均保留
10. 评价指标 【待确认】独立持久成功率、回报、许可违规、错误后果、取消、步数/时延、reset/核验成本、覆盖空缺与不确定性，不能只报平均回报
11. 采集与训练成本 【待确认】环境交互、标注核验、任务重置、失败恢复、调参及重复训练；表格计算便宜不代表反馈便宜
12. 推理与执行成本 【待确认】视觉编码、候选生成、mask 校验、Q 查询/抽样、交互等待、结果读取和恢复；按完整任务统计资源与时延
13. 基线与比较协议 【待确认】固定流程、监督定位加流程、示范策略等非 RL 对照；匹配任务、输入、权限、预算、成功判据与信息，分开训练/调参/测试及探索/冻结评价策略

最小研究顺序是先验证状态、许可和反馈，再在可恢复的任务副本里验证日志协议，最后才讨论是否需要学习控制。不能通过删掉失败样本、把外部停止改成成功结束，或事后移除未覆盖动作来制造表面提升。方法分别产生真实交互时，也需分别计其探索成本；相同两条教学记录仅用于目标核对，不是公平训练试验。

可提出一个尚未验证的研究假设：在相同真实任务与资源条件下，显式记录许可、持久核验和边界，是否帮助区分“点击正确但任务未完成”与真正成功，并识别缺失反馈？先与固定流程、监督定位加流程等对照，再决定是否值得学习策略。当前没有实际数据或训练结果，NOT_RUN。

模态路由的真实输入来源、标签语义、合法动作与业务错误成本仍【待确认】，不移植别的任务标签。单步有完整标签时先比较监督/成本敏感选择，只有所选动作反馈时先考虑相应单步反馈；若动作改变后续观测和多步结果再研究控制。SR 同样先确认早停、迭代处理或计算分配等真实动作与质量—成本目标；普通单次重建先用监督与固定处理基线。

7. 常见误解、失败条件和适用边界

误解或失败 本课的检查方式
“有 mask 就已解决安全 RL” 说明许可先验和受限任务；confirm 仍有教学失败风险，真实 mask 也可能错
“delete 评分 99，应在探索或 max 中试一次” 它不是这个 MDP 的合法 Q 项；行为、目标和对照都应过滤
“SARSA 目标较低，所以它已经更安全” 两份实际行为都 cancel，G 都 −1；目标含初值，不是风险实测
“QL 目标取 confirm，就得补一条 confirm 成功” 只读估计 4，没有该动作反馈；不能偷换 6.8 或奖励 8
“规则参照 5.12 比两个 post 高，证明规则胜出” 对象与信息不同；模型期望、当前估计和实际轨迹不能这样排名
“到确认页、看到成功提示就是完成” 需要独立持久结果与失败/待核标志，定位与执行分别评估
“采集器停或 reset 就将旧目标当真终止” 区分任务内 h=0、外部截断和新任务，保留原后继与动作链
“两步表、固定 ε/α 和四个候选足以保证最优” 合法只有四对，本次只更新两对；有限数据不证明长期条件

负奖励是目标的一部分，并不禁止行为；动作许可是先验约束，也不是学习到的安全证明。若真实系统的隐藏状态、权限、反馈或转移发生变化，应先检查是否仍是同一个问题。本文没有验证实际风险上限、约束满足率、收敛或有限样本性能，不外推到神经网络控制。

8. 三道理解题

题 1｜任务与许可。 写出 N2/C1/z 的完整状态含义、两个合法动作集合与 confirm 的反馈分支。C1 的合法 pre 为 confirm=4、cancel=−2，ε=0.2，mask 外 delete 原始评分为 99：三个候选实际概率分别是多少？为什么不能用 99 构造目标，也不能因有 mask 就宣称零失败风险？

题 2｜同 pre 更新与不同参照。 用第 4.1 节两份相同初表，分别计算人为 review、r=−1 到 C1、下一实际 cancel 的 SARSA 与 Q-learning 第一步 y、δ、post；再实际执行 cancel、r=0 到 z，给出最终四个 Q、有效写入计数与完整 G。第一步是否要按模型期望 6.8 替换估计 4？另算规则 review→confirm 的两条 G 及其期望，能否按 5.12、−0.9、1.8 排名真实性能？

题 3｜外部停止与真实合同。 采集器在 review 后停机，持有旧 C1、有效 mask，但没有已选 a′，随后 reset 到新 N2。QL 与 SARSA 各能否补当前非终止目标？若 SARSA 已有效选 cancel 且能在旧任务继续，怎样处理 carry？为真实 GUI 列至少四项待确认合同、一个独立成功判据、一个非 RL 基线和两项成本；本次手算能否证明真实安全或收敛？

参考答案（练习完成后再看）

题 1 参考答案。 有限非终止域只有 N2（导航菜单，h=2）、C1（提交确认，h=1），初态 N2；终止 z 无后续。A(N2)={review,exit}，A(C1)={confirm,cancel}。review 确定奖励 −1 到 C1；exit、cancel 为 0 并终止；confirm 以 0.9 得 8、0.1 得 −4，均终止，分别由独立持久核验标为成功或失败。每动作耗一预算，C1 动作后到 h=0；提前退出不必用完预算。

C1 在 mask 后 k=2、m=1，confirm 概率 0.8+0.2/2=0.9，cancel 为 0.1，delete 为 0。99 是许可外原始评分，不是合法 Q 项，没有资格进入探索、利用或后继 max。若 mask 改变需重新归一化，不对原始三个候选除以 3；未知/非终止空 mask 应保留异常。mask 是教学先验，confirm 仍有 0.1 的失败分支，不能推出零风险或真实业务安全。

题 2 参考答案。 第一步当前 pre=1，r=−1、d=0。SARSA 已选 a′=cancel，读取 −2：y=−2.8、δ=−3.8、post=−0.9，并 carry cancel。QL 读取合法 max(4,−2)=4：y=2.6、δ=1.6、post=1.8；实际下一步仍可 cancel，不需要伪造 confirm 结果。两列是相同初表的独立副本，不串写，不把奖励期望 6.8 或成功奖励 8 替换为目标中的估计 4。

第二步两者实际 cancel，当前 pre=−2，r=0、d=1，y=0、δ=2、post=−1，不再选动作。按 Nreview、Nexit、Cconfirm、Ccancel 排列，最终 SARSA 为 (−0.9,0,4,−1)，QL 为 (1.8,0,4,−1)，各自 N=(1,0,0,1)。第一步不自动回写，未访问两项仍是初值；实际奖励 −1、0，故两者 G=−1，均非成功。

另起已知模型计算，规则 review→confirm 的成功 G=6.2、失败 G=−4.6，期望 0.9×6.2+0.1×(−4.6)=5.12，成功概率 0.9。confirm 期望 6.8 优于 cancel 的 0，review 期望 5.12 优于 exit 的 0，所以该规则在这个明确受限模型中最优。它使用先验流程与已知核；5.12 是期望，−0.9/1.8 是初始化加一次更新后的估计，不能直接排名真实性能，也不能称训练得到了最优策略。

题 3 参考答案。 停机是外部截断，原 C1 不是真终止；新 reset N2 不是旧后继。若旧 C1 与 mask 完整有效且属于同一任务定义，QL 可以用旧 pre 最大值构造当前一步目标，不需 a′ 或真实续接；SARSA 缺少有效选定的下一动作时保留待核，不用新任务动作补算。如果当时已按行为规则有效选 cancel，并能保持旧状态和许可继续，应保存并沿用同一 cancel；恢复前再核查任务/状态/许可未失效，不能重抽后仍称同一动作链。若资料缺失，保留原因并跳过无法核实的写入，不增加有效更新计数。

真实合同可选状态/历史与预算、权限及 mask 版本、行为/目标与 Q 快照、奖励单位、终止/截断、初态/reset、逐对覆盖、评价协议等。独立成功判据应核实业务目标对应的持久记录或输出，而非只看按钮命中/成功提示；具体接口与定义【待确认】。非 RL 基线可用固定流程或监督定位加流程，同任务、输入、权限、预算及成功判据比较，并披露先验。成本至少包含环境交互/重置/核验，以及视觉编码、动作选择、等待与失败恢复。当前只有已发表机制、教学算术与拟议合同；研究为 NOT_RUN，不证明真实安全、收敛或性能提升。
