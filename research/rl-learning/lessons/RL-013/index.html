1. 今天解决什么问题，与前面哪些单元有关

前几课分别讲过 DP 的模型期望、MC 的完整回报和 TD 的一步自举。RL-012 提醒：目标统计、一次估计与学习曲线不同。今天把这些条件写成一个能复算的小任务比较合同：同一个旧策略、同一个初值、同一组既有记录，在每个环境步骤之后，方法究竟知道什么、更新了什么？

主方法是 MC 的逐状态 1/N 平均与 TD(0) 的 η=.5；再加 MC η=.5，检查步长差异这个混杂因素。完整已知模型的 DP 单独作模型内参考，不能把它的信息优势藏进“同样只看七条经验”。本课不优化行为，不运行随机实验，不用一组指定轨迹宣布总体胜负。

2. 学习目标

学完后，应当能够：

  1. 写清 DP、MC、TD 的输入信息、目标、更新时间、初始化和预算单位，区分计算轮数 k、环境步骤 m、任务预算 h 与状态计数 N。
  2. 按七条固定转移复算每个检查点的三种估计，核对 MC 的完成时机、相同步长对照和固定记录平方误差，说明其证据边界。
  3. 把协议具体化为独立配对数据流、验证/测试隔离、覆盖、指标和成本记录，并列出真实 GUI 仍待确认的反馈与公平基线。

3. 直觉、定义和必要公式

3.1 四个编号与两层信息

符号或层级 本课约定 不要混淆
x=(页面,h) 完整教学状态，h 为剩余真实动作数 同页面不同 h 不是同状态
m 从本组记录开始累计收到的环境转移数，m=0 为初值 不等于 episode 数或状态更新数
N_A(x) 方法 A 已对状态 x 接受的更新数 各方法在途中可能不同，每个状态也不同
k DP 完成的全表同步计算轮数 不是 GUI 新动作，不进入经验方法的 m 轴
经验层 只按顺序读已到达的状态、动作、奖励、真终止与后继 不读未来记录、完整概率表或精确价值
模型参考层 已知完整 p、旧 πα 与终止/预算规律 DP 参考有额外模型信息与建模成本

所有方法预测同一固定旧 πα，不做动作最大化。经验层的初值统一为数值0，N=0；对 MC 来说，首次完整回报前的0只是初始化预测，不是已经有样本的平均。H1/F2 未访问时仍标 N=0、初始化，不能称为学得真实零价值；终态与 h=0 的零是任务边界。

3.2 两种 MC：目标与等待条件相同，步长不同

完整回报 G 到达后，对本 episode 中该完整状态的首次访问更新：

N(x)←N(x)+1,V(x)←V(x)+η [G−V(x)],η=1/N(x) 或 1/2N(x)\leftarrow N(x)+1, \qquad V(x)\leftarrow V(x)+\eta\,[G-V(x)], \quad \eta=1/N(x)\ \text{或}\ 1/2N(x)←N(x)+1,V(x)←V(x)+η[G−V(x)],η=1/N(x) 或 1/2

MC 1/N 是普通回报平均，第一次 N=1 就把初值替换为 G；MC η=.5 是固定步长加权更新，不再是普通均值。二者都必须等原任务真正完整结束。本 fixture 每个完整状态每条 episode 只出现一次，first-visit 与 every-visit 在这里一致，不需要删掉状态键中的 h 来制造重复。

一条任务没有访问 F1，就不给 F1 加计数，也不补一个0回报。样本回报不再额外乘策略或路径概率。固定步长 MC 的原始形式可核对 教材 §6.1，册页119式(6.1)，完整平均与首次访问见同书 §5.1、册页92～93。

3.3 TD(0)：收到这条有效转移，就只写当前状态

y=r+γ(1−d)Vpre(x′),δ=y−Vpre(x),Vpost(x)=Vpre(x)+12δy=r+\gamma(1-d)V_{\mathrm{pre}}(x'), \quad \delta=y-V_{\mathrm{pre}}(x), \quad V_{\mathrm{post}}(x)=V_{\mathrm{pre}}(x)+\tfrac12\deltay=r+γ(1−d)Vpre​(x′),δ=y−Vpre​(x),Vpost​(x)=Vpre​(x)+21​δ

r 是动作后真实一步奖励；d=1 只表示原任务真正终止。未终止时 x′ 必须是有效的同任务真实后继，V_pre 是这一次写入前的当前表。真终止直接 y=r，不读无效终态对象再乘0。先算好 y、δ，再写当前状态；下一转移读更新后的表。后继后来改变，不自动回写之前的前驱。

η=.5 是教学步长，不满足任意任务都精确收敛的保证，也不是1/N。δ 是目标差，不是真实价值误差。标准形式与逐转移处理见 教材 §6.1，册页120～121式(6.2)、(6.5)。

3.4 DP 参考：同一个预测目标，更强的信息条件

已知核下，任意 h>0 的 F 在旧策略下期望奖励为8；H1 只有一步，价值−.75；H2 可以 open 后保存，固定策略价值为 .75×(−1+.9×8)=4.65。这里没有把 H2 的动作改成必 open，也没有混入 RL-009 的最优6.2。

沿 RL-008 的全零初表和全表同步计算，按 H2/F2/H1/F1 排列：

DP 轮数 k H2 F2 H1 F1 全表改变量 Δ_k
0：初表 0 0 0 0 不适用
1 −.75 8 −.75 8 8
2 4.65 8 −.75 8 5.4
3：停止核查 4.65 8 −.75 8 0

每轮只读上一整张表；本模型最多两层后继影响，第二轮已经精确，第三轮才观察到不变。不是所有 DP 都只需两轮，也不是第三次 GUI 交互。θ=10⁻⁶、K_max=2 时仍返回 iteration_limit，不能编造第三轮停止证据。已知模型期望与两数组区分见 教材 §4.1，册页74～75。

这个 DP 真值参考不属于相同经验预算的竞赛；“不用采这七条记录”不等于免费获得模型。若以后改为从同日志估计 p，再做模型评估，需要另列模型估计、覆盖、偏差与费用，不能继续声称用了完整真实核。

4. 手算与更新过程：固定七转移逐检查点核对

4.1 条件不变，记录顺序提前给定

fixture 指一组已指定的教学测试记录，本次没有随机生成它。H/open 确定到 F、奖励−1；H/stop 到 z、奖励0；F/save 以 .8 得10、.2 得0并终止；F/cancel 到 z、奖励0。旧 πα 在 H 的 open/stop 为 .75/.25、F 必 save。γ=.9，每动作消耗一步；save 不另扣成本，进入 z 或 h=0 后无额外奖罚。

每次任务从 H2 开始，值表跨任务保留。所有方法重新声明 V₀=0、N=0，不承接前课学得的表。E1 成功、E2 停止、E3 失败、E4 成功，是人为给定顺序：

环境步 m episode 新到达的转移、动作与奖励 真终止 d
1 E1 H2 —open,−1→ F1 0
2 E1 F1 —save,10→ z 1
3 E2 H2 —stop,0→ z 1
4 E3 H2 —open,−1→ F1 0
5 E3 F1 —save,0→ z 1
6 E4 H2 —open,−1→ F1 0
7 E4 F1 —save,10→ z 1

四条完整 H2 回报为8、0、−1、8；F1 只收到10、0、10，E2未访问F1。本次原始环境转移总共7条，不因三个方法分别读取而称为21条独立经验。

每个检查点先处理截至 m 的全部允许更新，再读值；同一步末不发生额外环境交互。MC 仅在 m=2、3、5、7 真实完成后更新该 episode 访问的状态：

m=1、4、6 时已有新的 open 转移，但完整 G 尚不可用，所以 MC 保留旧表。已知 fixture 后面怎么写，不等于方法在当时能读取未来。m=3 的 stop 是完整 G=0，但只更新 H2；它不是 F1 保存失败样本。

MC η=.5 的 H2 只在任务结束时按0→4→2→1/2→17/4变化：例如 E3 完整失败回报−1使2+.5(−1−2)=.5，E4成功再使.5+.5(8−.5)=4.25。F1 是0→5→2.5→6.25，E2仍不动。

TD 的七个目标依次为−1、10、0、7/2、0、5/4、10。m=4用当时F1=5，y=3.5，H2从−.25变13/8；m=5失败把F1降到2.5，H2不会自动重算；m=6才用新F1，y=1.25，H2降为23/16。即使E4后来成功，也不回溯改成完整G。

最终三个方法的更新计数都为 H2=4、F1=3，但中途不同。例如 m=4，TD 的 N 为3,1，两个MC都是2,1。相同终点计数不表示更新时机相同；也不能把同一个N同时当环境步数、任务数和状态覆盖。

相同 η 的 MC 对照排除了本次“一个用1/N、另一个用.5”这个参数差异，但仍同时有完整目标/自举目标、等待条件和信息传播的差异。它不是只改变一个机制的万能消融，更不证明固定 .5 是各方法的最佳参数。

4.4 固定记录的平方误差，不是统计 MSE

预先只评价从 H2 起始可访问的 H2/F1，各权重1/2；已知模型参考为4.65、8。定义这一个固定 fixture 在 m 处的平方误差：

Lm=12[Vm(H2)−4.65]2+12[Vm(F1)−8]2,Rm=LmL_m=\tfrac12[V_m(H2)-4.65]^2 +\tfrac12[V_m(F1)-8]^2, \qquad R_m=\sqrt{L_m}Lm​=21​[Vm​(H2)−4.65]2+21​[Vm​(F1)−8]2,Rm​=Lm​​

L 的单位是回报平方，R 是相应的状态加权 RMSE、单位为回报。这里没有对随机训练数据取期望，因此L_m 不是跨随机数据分布的统计 MSE，也不是目标方差。H1/F2 不从本初态到达，预先不纳入这张指标，但仍报告 N=0、初始化；不能看到结果后删难状态。

m=7 的方法 H2,F1 最终值 固定 fixture 平方误差 L₇
MC 1/N 15/4,20/3 2329/1800≈1.293889
MC η=.5 17/4,25/4 1289/800=1.61125
TD η=.5 23/16,25/4 85649/12800=6.691328125

例如 MC 1/N 的 H2 误差为−.9、F1误差为−4/3，L₇=.5×[.81+16/9]=2329/1800。只看 H2 时，MC η=.5 比 MC 1/N 更靠近4.65，但它的 F1 更远，按预定权重所得L₇反而较大，说明指标范围也会影响比较。

表中确有这组固定数字的大小关系，但不能据此宣布 MC 总优于 TD、已验证无偏/低方差/收敛，或真实策略被改进。四条记录是人为构造，不是独立重复随机实验；本课不把这些点画成声称有统计代表性的经验学习曲线，也不伪造误差条。

4.5 最小调度伪代码：阻止未来信息提前进入

initialize separate V=0 and per-state N=0 for each method
for m, transition in the seven fixed records, in order:
    validate full state, reward, true task end and same-task successor
    TD_half: read pre values; compute target; write current state only
    append this transition to the current episode buffer
    if this is verified true task end:
        compute full returns from this buffer
        mark first visits by forward time for full (page,h) keys
        update MC_1N and MC_half using their own per-state counts
        clear only this episode buffer; keep all value tables
    snapshot all method values and counts at this same m

这段代码描述固定记录的处理安排，不调用环境、随机数或训练服务。终止后清空的是 episode 缓冲，不是价值表；MC 真正得到新G前不能更新。缺失或边界含混的真实记录应保留并标记，不套本 fixture 全部合法的简化假设。

5. 与前一种方法的关系：从手算合同到拟议比较

RL-012 定义“要比较什么”，今天具体规定“哪条信息在第几步可用”。本课已做的是确定性记录和分数算术，不是把预案写成已经运行的研究。

比较 能检查什么 不能直接推出什么
MC1/N 对 TD.5 两个明确方案在同一记录、同环境步下的处理差异 不单独归因于 bootstrap，步长也不同
MC.5 对 TD.5 排除这一个固定步长数值的不同 完整目标、更新时间仍不同，不是所有因素均匹配
MC1/N 对 MC.5 同一完整回报与更新时间下的步长影响 不能由一个fixture选择通用最佳η
DP 模型参考对经验估计 核对同一旧π目标和模型内误差 不能称同日志、同信息、同成本比赛

以下是尚未执行的具体比较预案，用于之后满足条件的任务；不在本课运行随机采样：

协议项目 提前固定的设置
任务与三方案 仍固定旧πα、H2起点、同核/γ、V₀=0；MC1/N、MC.5、TD.5分开命名与记录
测试数据预算 拟议 K=20 条彼此独立的测试运行流，每流最多200个环境转移；同一流内三个方法读取完全相同的有序记录，形成配对
检查点 固定 m={0,25,50,100,200}；按截至该m的允许更新后读表。任务中途到200也不强行终止或补G，MC保留已完整任务造成的表并保留未完缓冲
复现与隔离 运行前登记互不重叠的验证/测试种子、策略/环境/代码版本与流标识；本课尚无已生成的随机流或实际种子清单
参数与验证 主三方案参数固定。若额外比较调优版，两个常步长方案均只在独立验证流上按同一η候选集合{.1,.25,.5}和预算选择，测试流封存；MC1/N没有待选常数η，不用测试再挑变体
评价范围 同样 S_eval={H2,F1}、各权重1/2与正确模型真值；每次先算R_j(m)=√L_j(m)，再跨运行取平均，不把平均L开根号混名
误差条与差异 如用均值±1SE，SE为20次独立运行的R标准差除√20；不是95%CI。比较方法先取同流差异，再跨独立流汇总，状态和检查点不算额外重复
覆盖与质量 每方法逐状态N、初始化/未覆盖、完成/失败/取消、截断/缺失比例；不能只留成功或事后改评价状态
成本与保存 另记episode数、价值写入、数据重用遍数、缓冲/表内存、计算耗时、采样/重置/反馈与推理执行成本；保存每次原始日志与参数
模型参考 DP单独记录模型来源、模型验证成本、计算域、k与停止原因；精确价值只供评价器读取，不喂给经验更新

这里的“测试运行流”用于预先固定方案、遵守信息时序的在线学习评价：方法可按既定规则读取已经发生的奖励并更新。“封存”指不用于选参或修改方案，不是禁止按已发生前缀学习；评价真值仍不进入经验更新。

20次是拟议重复数量，不保证精度足够；应根据实际波动和预定精度要求另行评估，不把“有误差条”当成结论可靠。上述K、m和η设置都是预先设计，不是已运行结果，研究状态仍为 NOT_RUN。

真实 GUI 若没有可靠 Vπ 真值，独立测试完整回报的预测损失还含回报随机噪声，不能直接标成精确价值误差；训练目标差和δ也不能代替独立测试。若模型近似，其DP结果也只是近似模型内参考，必须另检查模型与真实任务的差距。

6. 主要应用：GUI 价值预测比较需要的真实合同

本节为工程推断。有可靠过程日志和完整任务反馈时，才可考虑预测方法比较；这不等于改变了GUI执行策略，也不把单次定位正确率替代为任务回报。

合法动作 点击、输入、滚动、结束、参数与失败语义 【待确认】真实可执行接口
固定数据策略 行为概率、屏蔽、回退、底层模型和执行器版本 【待确认】不混版本冒充同一目标策略
奖励与单位 完成收益、调用/操作/错误代价、γ与成本换算 【待确认】不把教学10和−1移植为业务奖励
可信反馈 独立持久状态回读、逐步奖励与完整完成核查 【待确认】保存提示与定位命中不等于完成
后继与时间边界 任务真实期限、真终止、外截断、最后真实后继与reset 【待确认】不补未知未来，不接新任务观测
初态与重置 任务分布、初始配置、隔离与重复单位 【待确认】表保留与环境重置分开
数据与覆盖 有序转移、完整任务、失败/取消/缺失、N与版本 【待确认】未访问仅初始化/未知，未选分支不编造
评价指标 独立预测损失、真实任务回报/成功率、覆盖、横轴和误差条 【待确认】无真值时不称精确Vπ误差
数据/训练与模型成本 采样、重置、反馈核查、估计更新、验证调参、模型获取 【待确认】DP信息优势与建模费用另列
推理/存储与计算成本 轨迹缓冲、表或模型、更新和调用等待/恢复/回读 【待确认】相同环境步不等于相同资源
方法与非RL对照 方法为MC1/N、MC.5、TD.5，DP为模型参考；非RL行为为固定流程、监督定位加流程、示范策略 【待确认】匹配任务、输入、底层模型、预算与成功判据

外部停录不能自动算真终止。MC缺完整后续就保留未完记录、不补0；TD仅在原任务继续且真实未reset后继有效时可用该转移，否则暂存标缺失。任务本身h=0则是真边界。仅丢掉截断/失败再称代表全任务，也可能产生选择偏差。

真实价值预测误差小，仍不自动提高任务成功率。一个研究假设是：在反馈、目标和资源合同完整后，这些比较能否帮助选择更适合固定执行器的风险预测机制？需要独立数据与检验，本课为未运行（NOT_RUN），没有真实GUI、GPU/服务器或网络训练。

SR与模态路由只作条件筛查。普通单次SR重建先按监督质量指标比较；真实迭代、早停或计算分配才继续定义状态、动作和反馈。独立单步路由的真实输入、标签、分支与错误成本仍待确认，未选分支结果未知；不为套用MC/TD虚构多步过程，也不拿教学概率补业务标签。

8. 三道理解题：先独立作答

请先用约8分钟作答，使用第4节同一固定记录，答案统一在文末。

题1｜信息与更新时间。 DP为什么可得到H1/F2的模型内价值，三个经验方法为何不能把它们写成已学得？m=1时MC0与TD−.5各表示什么？m=3的stop怎样影响H2/F1计数？解释k、m、h、N，以及为什么DP不能与七转移方法作同信息预算排名。

题2｜复算与相同步长对照。 核对m=2、5、7处的三种(H2,F1)；复算MC.5的H2四次更新、TD在m=4～6的目标与先后关系，以及三个方法最终计数。按预定两状态权重求三个L₇，解释为何MC.5的H2更近但总L较大；这能否证明总体优劣，相同η又排除了什么、没排除什么？

题3｜把预案当结果的问题。 一个团队把本fixture重复20遍当20次独立运行，把MC按episode更新与TD逐转移更新都标成横轴“更新次数”，给DP标0成本，并只留成功日志、在测试数据挑步长后宣布GUI改善。逐项修正数据、检查点、配对与独立性、初值/调参、评价范围、模型信息、终止/截断、反馈、成本和非RL行为基线；说明目前什么已核算、什么仍NOT_RUN。

参考答案（练习完成后再看）

题1。 DP已知完整模型，可计算合法但当前初态不可达的H1/F2，旧策略下分别−.75与8。经验方法本组N=0，保持初始化0并标未学得，不能读取DP答案填表。m=1时MC等待完整G，0只是初始化；TD已看到Hopen奖励−1和仍为0的F1估计，y=−1，H2写−.5。m=3的E2只给H2一个G=0，MC的H计数从1到2，F仍1且值不变；TD同样只更新H2。k是DP全表轮数，m是环境转移累计，h是剩余真实动作，N是方法对状态的更新计数；互不替代。DP有额外全模型信息和获取/计算成本，不是同日志竞争者。

题2。 m=2时MC1/N=(8,10)、MC.5=(4,5)、TD.5=(−1/2,5)；m=5时分别(7/3,5)、(1/2,5/2)、(13/8,5/2)；m=7时分别(15/4,20/3)、(17/4,25/4)、(23/16,25/4)。MC.5的H序列0→4→2→.5→4.25，各次目标8、0、−1、8。

TD m=4：preH=−1/4、preF=5，y=7/2、δ=15/4，postH=13/8；m=5：preF=5，真终止y=0，postF=5/2，H不回改；m=6：preH=13/8、preF=5/2，y=5/4、δ=−3/8，postH=23/16。最终三个方法N(H2)=4、N(F1)=3，未访H1/F2为0。

三个固定L₇分别为.5[(−9/10)²+(−4/3)²]=2329/1800；.5[(−2/5)²+(−7/4)²]=1289/800；.5[(−257/80)²+(−7/4)²]=85649/12800。MC.5在H2更近，但F1更远，预设两状态权重下L反而比MC1/N大。相同η只控制这个步长值差异，MC与TD目标、可用时机和传播机制仍不同；本fixture的L不是随机数据统计MSE或通用算法排名。

题3。 重复同fixture只是数据重用，不是独立采样，也不能把每次重放清零就称独立随机实验。主横轴用环境转移m，另报episode、状态写入、重用和计算；检查点只用已到信息，MC等待真实完整G。DP单列全模型来源、覆盖、费用、k和停止原因，不以0采样冒充0成本。统一旧π、完整状态、奖励/γ、初值、流顺序和评价范围；同运行方法配对，不同运行独立，预先保存种子/配置。验证数据选参数且资源对称，测试封存，不在测试挑最好版本。

完整保存失败、取消、截断与缺失；MC未知未来不补0，TD需原任务继续且真实同任务后继有效，reset初态不接旧转移。按每次运行固定状态权重算RMSE，再跨独立运行汇总，明确K和SD/SE/CI；1SE不等于95%CI，无真值时测试回报损失含噪声，不称精确价值误差。补齐第6节12合同、独立持久反馈与端到端成本；预测方法对照与固定流程、监督定位加流程、示范策略这些非RL行为基线分开。已核算的只有固定记录、计数、更新和L，随机比较、经验曲线及真实GUI研究均NOT_RUN，不能宣布业务改善。
