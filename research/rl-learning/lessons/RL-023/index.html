1. 今天解决什么问题，与前面哪些单元有关

上一课用一条转移做了一次参数更新。若每次只紧跟最新交互来更新，相邻画面与动作常常相似，获得反馈的成本又可能远高于一次计算。能否保存已经发生的转移，稍后打散顺序、再次用于优化？

经验回放（experience replay）把“获得环境经验”和“使用经验更新参数”分开：真实交互产生记录 → 存入 replay buffer → 按声明的规则抽取 minibatch → 构造目标并更新。同一记录可以被再次使用，但不会因此多出一次环境访问、一个独立奖励样本或未选动作的反馈。

今天只讲均匀转移回放、批量均值和历史数据的范围。沿用 RL-022 的固定目标接口，不深入下一课的目标网络维护，也不展开 Double、Dueling 或新的优先采样算法。一个可复算的小缓冲区不是完整 DQN 训练实验。

2. 学习目标

  1. 能解释缓冲区容量、当前有效记录数、逐记录均匀抽样与批大小，区分按转移均匀和按任务均匀、有放回和无放回。
  2. 能在同一 pre 参数与目标快照下，计算两条记录的目标、损失、梯度均值和一次参数写入，不误写成两次顺序 SGD。
  3. 能说明回放对相关性、覆盖和历史分布能做什么、不能做什么，为真实 GUI 明确版本、反馈、指标、成本与非 RL 基线。

3. 直觉、定义和必要公式

3.1 buffer 保存经验，不保存新的世界

一条基础记录可写作 e_i=(s_i,a_i,r_i,s′_i,d_i)，其中 s_i 为动作前完整状态，a_i 是已执行动作，r_i 为即时奖励，s′_i 是原任务真实后继，d_i=1 表示真终止。下标 i 是记录 ID，不是当前训练迭代。真实应用还需保存任务/时间、许可 mask、结束原因、反馈与版本等元数据。

令当前可用缓冲区为 D={e_1,…,e_N}，N 是当前有效记录数；容量 C 是最多保留多少条，N≤C。容量、已收集的历史总条数和当前 N 是不同数量。常见有限队列只保留最近 C 条，满后新记录替换最旧记录；保留范围是明确的数据选择，会影响稀有路径和旧版本占比。原始 DQN 在有限 replay memory 中保存近期转移并随机取样，见 2013 第 4～5 页与 2015 Methods。

buffer 保存的是实际转移及其反馈，不把某次 y 当作永久真实标签。训练使用某条旧记录时，可以按本次声明的目标参数重新构造 y；反馈 r 与结束事实不能为了让目标好看而重写。需要改变任务或奖励语义时，应另记版本和转换依据，而不是悄改原始记录。

3.2 均匀的单位是存储记录

逐记录均匀意味着一次单条抽取时，每个记录 ID 的概率是 1/N；不意味着每个状态动作、任务、成功类别或当前策略都得到相同权重。同一状态动作若有更多真实记录，会占更多概率质量。

本课指定批大小 B、批内无放回，且 B≤N；每个 B 元子集等概率。于是任一记录被纳入本批的概率为：

Pr⁡(ei∈B)=BN.\Pr(e_i\in\mathcal B)=\frac{B}{N}.Pr(ei​∈B)=NB​.

𝓑 表示抽到的批次集合，Pr 表示在此抽样规则下的概率。单次抽取概率 1/N 与整批纳入概率 B/N 不是同一个分母。无放回时批内记录 ID 不重复，抽取之间也不是独立的；下一次更新可再次抽到以前用过的 ID。

有放回也是一种可声明的实现选择，同一批可能重复 ID，其纳入概率要另算。原论文的“随机 minibatch”不替我们规定所有实现细节；本课无放回是教学约定。N<B 时应等待足够有效数据或另行定义协议，不补造记录凑批。

打散抽取能降低紧跟时间相邻记录更新的倾向，但不保证任意一批都没有相邻转移，更不会把已收集的相关轨迹变成独立环境样本。缓冲区可能仍有重复画面、稀有路径空缺和历史偏向。

3.3 从单条损失到批量均值

延续 RL-022，θ 是本次优化前的当前参数，bar θ 是本步固定目标快照，γ 为折扣；A(s′_i) 是原任务后继的合法动作集合。对每条有效记录：

yi={ri,di=1,ri+γmax⁡u∈A(si′)Q(si′,u;θˉ),di=0,ℓi(θ)=12(Q(si,ai;θ)−SG⁡[yi])2.y_i=\begin{cases} r_i,&d_i=1,\\ r_i+\gamma\max_{u\in A(s'_i)}Q(s'_i,u;\bar\theta),&d_i=0, \end{cases} \qquad \ell_i(\theta)=\frac12\big(Q(s_i,a_i;\theta)-\operatorname{SG}[y_i]\big)^2.yi​={ri​,ri​+γmaxu∈A(si′​)​Q(si′​,u;θˉ),​di​=1,di​=0,​ℓi​(θ)=21​(Q(si​,ai​;θ)−SG[yi​])2.

u 是候选合法动作；Q 是价值估计，不是动作概率。SG 为停止梯度：前向用 y_i，反向不对目标求导。真终止的目标直接取进入终态的 r_i，不查询终止空动作表；外部采集停止不自动等于真终止，reset 后新状态不能补旧 s′。

L_𝓑 是本课的批量半平方损失均值；∇_θ 为参数梯度，η 是优化步长。所有 y、当前预测与梯度先读取同一 pre 快照，最后只写一次参数。不是先用 e_1 更新 θ，再用新 θ 计算 e_2；也不是把平均误差当成每个不同特征的梯度。损失用 sum 或 mean 会改变尺度，本课必须除以 B。本课的半平方系数与均值写法明确声明，回放和 minibatch 的基础机制见 2015 Algorithm 1。

固定缓冲区、θ、bar θ、所有目标和本课抽样规则时，对可能批次求期望，批均值梯度等于全缓冲区经验目标的梯度。这是对已存记录的条件采样性质，不是无偏估计真实 Q*、当前策略价值或原环境总体的保证；后者还取决于收集、覆盖、反馈和任务条件。

4.5 重复使用、容量与覆盖的计数

以后若再次抽到 e_1 或 e_2，增加的是抽取/损失使用次数、优化次数；环境记录 ID、奖励事实和 confirm 覆盖不会因此增加。目标可在未来优化时按明确快照协议重算，不意味着环境给了新奖励，也不意味着永久固定本次 2.6。

如果再假设发生第四条新事件 e_4：任务 C 的 Nreview、−1 到 C1，容量为 3 的先进先出队列会从 (e_1,e_2,e_3) 变为 (e_2,e_3,e_4)。历史总事件变为 4，当前存储仍为 3；e_4 与 e_1 内容相同也属于不同事件，需不同 ID。这个数据结构说明不参与上面的更新，也没有实际采集第四条记录。稀有记录若被淘汰，后续回放不再提供它的机会。

5. 与前一种方法的关系

RL-022 给定一条记录，解释如何构造固定目标并更新共享参数。本课增加的是经验选择与复用：训练样本不必总是最新一条，同一条也能多次用于优化。改变的是更新的数据来源和权重，不是凭空改变任务核或获得更多独立反馈。

维度 紧跟新记录更新 均匀经验回放
数据选择 跟随采集时间顺序 从当前存储记录抽取
相关性 可能持续看到邻近状态 可降低相邻更新的倾向，但有限 buffer 和批仍可能相关
使用次数 常见一次或少量 可重复使用，不增加环境记录
目标数据范围 近期行为产生的经验 多个历史行为的混合，非当前策略的天然均匀分布
新成本 交互、前后向计算 再加存储、读取、采样与更多更新计算

行为策略变化不必然意味着环境本身变了。对同一平稳任务、相同状态动作奖励语义，off-policy 的 Q-learning 目标允许使用与当前行为不同的数据；但这不提供任意离线数据的覆盖保证。

若奖励、界面/后端规律、动作编号、许可或状态编码版本发生变化，旧转移可能不再代表当前问题。需要核查版本、隔离不兼容记录，或明确有依据的重建方案；不能改一下标签就说历史经验已校正。均匀抽旧数据既不自动消除这种漂移，也不自动代表最新流量。上述边界与 RL-019 的“覆盖、样本和问题定义”相接。

完整 2015 DQN 包含回放与目标网络；当前只给定固定目标快照，目标维护留 RL-024。也不能将 2013 与 2015 的目标网络配置混成同一版本，更不以一个 batch 算例宣称稳定训练定理。

6. 一个主要研究应用：GUI 旧操作日志能否用于训练

主应用是在明确任务与许可下，复用多步 GUI 转移日志。若只是独立截图定位，先建立监督定位；若操作改变后续状态和持久结果，再判断是否需要长期价值控制。现有业务资料未给全，下列各项都是【待确认】，不是已经可训练的数据集：

合同项 必须补齐的真实定义与检查
观测与状态 【待确认】指令、截图/结构、必要历史、焦点登录与预算；历史表示是否能重建，截图不自动等于完整状态
动作、权限与 mask 【待确认】稳定 ID/控件语义、许可版本、旧后继合法集合；未知、失效或空 mask 如何留待核，不用新页面候选替代
奖励与独立反馈 【待确认】成功失败/取消及时间/误操作代价的单位、γ；谁何时核验持久输出，缺失/延迟反馈不能补成成功提示
多步与结束 【待确认】任务内预算、真终止、外部截断、reset 和原后继的独立标志，轨迹拼接是否真实
初态与恢复 【待确认】任务分布、可达性、隔离副本、重置/恢复成本；环境 reset 与模型参数保存分开
记录与版本 【待确认】唯一事件 ID、任务/步骤/时间、状态动作奖励后继、结果/缺失、行为和环境/奖励/编码/许可版本；不只保留成功
回放协议 【待确认】容量、有效 N、淘汰规则、按什么单位抽、放回方式、B、数据不足处理、去除重复入库与记录使用计数
目标与优化 【待确认】本批 pre/目标快照、stop-gradient、mean/sum、η、更新次数与新交互数的比值，不把回放使用数当样本增长
覆盖与评价 【待确认】逐状态动作实际事件数、当前 buffer/历史覆盖空缺、持久成功率/回报、错误后果、步数时延及不确定性；探索与冻结评价分开
采集与训练成本 【待确认】交互/核验/标注、reset、调参和重复；图像存储、读取、解码/编码、前后向、内存/显存与更新耗时
推理与执行成本 【待确认】历史/视觉编码、候选与 mask、模型前向、等待、恢复和持久结果核验；训练用回放不等于部署每步也要抽历史样本
非 RL 基线与公平性 【待确认】固定流程、监督定位加流程或示范策略；匹配任务、输入、权限、先验、交互/计算预算和成功判据，训练/调参/测试按独立任务划分

同一任务的相邻转移或重复使用记录若跨训练与测试，会造成泄漏；应先按独立任务及场景划分再设计 buffer，具体边界依真实数据确定。比较回放方案时同时报告独立环境事件、更新次数、读取/计算与核验成本；只匹配“更新一万次”不能说明用了同样的数据预算。

一个待检验的研究假设是：在有限真实交互预算下，版本一致且可核验的旧 GUI 日志能否减少额外交互需求，同时避免重复放大历史偏向？它需要非 RL 对照、独立评价与真实成本记录，本课尚未验证，NOT_RUN。

模态路由的实际输入、标签语义、动作和错误成本仍待确认，不移植其他任务标签；单次路由先匹配监督或单步反馈基线。SR 先明确迭代、早停或计算分配等真实决策与质量—成本目标，普通单次重建先用监督及固定处理基线，不强套经验回放控制。

7. 常见误解、失败条件和适用边界

误解或失败 本课检查
“每条均匀就等于每个任务/动作均匀” 核抽样单位与记录频率，本例 A 占 2/3，不是任务各半
“无放回也可当批内 IID，回放保证独立环境样本” 区分索引抽样与原轨迹相关性，主批还含相邻 e_1/e_2
“用过 100 次就是 100 条新经验” 按事件 ID、环境步、使用数、更新数分别计数
“两条误差求均值就等于批梯度” 各自乘预测梯度，再同 pre 求均值并一次写入
“随机打散后一定覆盖成功或所有动作” 本 buffer 没有 confirm 结果，重放不会补出来
“batch mean 应等于 buffer mean，或能证明原环境无偏” 一次批可能偏离；条件期望只针对固定经验目标
“off-policy 所以任何旧版本都能混用” 分清行为变了与问题语义/反馈机制变了
“只选完整成功日志更干净” 它改变数据选择；失败、取消、截断和待核原因需保留

回放不是环境模型，不会重新生成未观察到的随机后果；抽到旧 confirm 记录也只能用那一次实际反馈，而非自动获得新的独立成功/失败样本。低训练损失、更多使用次数或更大的容量，都不是有限覆盖、当前效果、稳定性或表格收敛的证书。

8. 三道理解题

题 1｜抽样与计数。 D={e_1,e_2,e_3}，任务 A 有 e_1/e_2，任务 B 有 e_3。单条均匀概率、B=2 无放回时的三个子集概率、每条整批纳入概率各是什么？为何任务不是各半、每个批不一定去掉相邻性？重复取同一条记录会增加什么、不会增加什么？

题 2｜一次批更新。 按本课 θ₀、bar θ、η、k 与指定批 {e_1,e_2}，计算两条的 y、q、δ、半平方损失、预测梯度和损失梯度，再给批均值、θ₁、四个合法新预测及固定目标新批损失。为何不能先更新第一条再算第二条？全缓冲区经验梯度为何可与本次批不同？

题 3｜旧 GUI 数据能否直接训练。 有人把同一成功轨迹复制十份入库，混入旧动作 ID/旧奖励版本，再随机拆转移到训练与测试，声称均匀回放已获得新独立覆盖和当前策略保证。指出问题；列四项真实合同、一个独立持久成功判据、一个非 RL 基线及训练/推理各一项成本。外部截断后若只有 reset 新图，能否补旧目标？

参考答案（练习完成后再看）

题 1 参考答案。 单次每个 ID 为 1/3；三个无序二元批各 1/3，每条整批纳入概率为 2/3。有序的不同两 ID 序列各 1/6，不与子集概率互换。逐记录均匀给 A 的记录的概率质量 2/3、B 为 1/3，不是按任务各半。无放回使批内 ID 不重复，但抽取不是独立的；{e_1,e_2} 仍是相邻转移。回放可增加使用次数与更新计算，不增加三个唯一环境事件，不产生 confirm 反馈或新独立奖励；下一批仍可再次选旧 ID。

题 2 参考答案。 e_1 的 y=2.6、q=1、δ=1.6、ℓ=1.28，∇Q=(1,1)，损失梯度 (−1.6,−1.6)。e_2 真终止 y=0、q=−2、δ=2、ℓ=2，∇Q=(−2,1)，损失梯度 (4,−2)。批损失均值 1.64，梯度均值 (1.2,−1.8)，θ₁=(0.88,0.18)。按 Nreview、Nexit、Cconfirm、Ccancel，新预测 (1.06,0.18,3.7,−1.58)；后三项的变化不改变事件计数，confirm 仍 0 条反馈。

保持 y=(2.6,0)，新单条损失为 1.1858、1.2482，批均值 1.217。所有梯度先读同一 pre，再一次写入；顺序两次更新会在不同参数处算梯度，已换算法步骤。e_3 初始损失和梯度为 0，所以全 D 平均损失 82/75，梯度 (0.8,−1.2)。三个批梯度各按 1/3 平均才等于全 D 梯度；单批不必相等，这也不是对真实环境、当前策略价值或 Q* 的无条件无偏保证。损失下降只证明教学算术，不证明真实效果。

题 3 参考答案。 复制同一事件十份只是重复加权，不是十次独立交互；要保留唯一事件 ID 和使用计数，避免重复入库伪增数据。旧行为与当前行为不同可以是 off-policy 设定的一部分，但旧动作语义、奖励或环境版本不兼容不能自动混用，需核查并隔离或明确可验证转换。相邻转移或同一任务复制记录跨训练/测试会泄漏，应按独立任务/场景先划分。均匀抽样只均匀当前记录，不能校正所有偏向或补未见结果。

合同可列观测历史与预算、固定动作 ID/许可 mask、独立反馈与奖励单位、结束/reset、唯一事件与版本、容量/淘汰/抽样、覆盖评价和计算成本。持久成功应核目标记录或输出，不能只看提示；具体接口【待确认】。非 RL 基线可用固定流程或监督定位加流程，匹配信息、任务、权限、预算和成功判据。训练成本含交互核验、存储读取及反向更新；推理成本含编码、前向、等待与结果验证，不要求部署时也抽训练 buffer。只有 reset 新图不是真实旧后继，不能补旧非终止目标；保留截断与缺失原因，跳过无法核实的更新。当前真实研究仍 NOT_RUN。
