## 3. 直觉、定义和必要公式

### 3.1 先把四个对象分开

| 对象 | 回答的问题 | 本课中的例子 |
|---|---|---|
| 行为策略 b | 实际执行什么，从而得到哪些数据？ | 初始 ε-greedy；人工轨迹实际 review、cancel |
| 一步目标 y | 本次把当前估计朝哪里推？ | SARSA 的 −2.8、QL 的 2.6，含后继估计 |
| 当前估计 Q | 现在这张表存什么？ | 初始 Nreview=1，第一步之后为 −0.9 或 1.8 |
| 完整回报 G | 这条已完成轨迹实际累计什么？ | 奖励 −1、0，折扣后 G=−1 |

这里 Q 不等于指定策略真实动作价值 q_pi，更不等于真正最优动作价值 Q*。q_pi 是先做指定动作、之后持续按固定 π 续行的期望折扣回报；Q* 在之后选择最优续行。初始化与有限写入的 Q 可以尚未准确估计任何一个目标；y 和一条 G 也都不是自动可用的真实价值标签。

SARSA 的 on-policy 联系体现在：a′ 按行为策略选定，其 pre 值进入当前目标，然后携带到下一次实际执行。Q-learning 的 off-policy 联系体现在：目标按后继合法最大估计，行为仍可探索。**Off-policy 允许目标与行为不同，不等于任何日志都足以识别未访问动作。**

### 3.2 同一个写入骨架，不同的后继项

令 x,a 为已执行动作前的完整状态和合法动作，r 为这次即时奖励，x′ 为原任务真实后继；d=1 表示真终止，d=0 表示原任务继续。γ 是折扣，α 是步长，pre/post 是本次写入前后。对资料有效的记录：

\[
y_M=\begin{cases}
r,&d=1,\\
r+\gamma Z_M(x'),&d=0,
\end{cases}
\qquad
\delta_M=y_M-Q^M_{\mathrm{pre}}(x,a),
\qquad
Q^M_{\mathrm{post}}(x,a)=Q^M_{\mathrm{pre}}(x,a)+\alpha\delta_M.
\]

M 标识方法，Z_M 是该方法的后继估计项；上标 M 表示独立维护的表，不是幂。δ_M 是目标差，不能称为相对真实价值的误差。本次只写当前项，其他项不动。真终止时直接 y=r，保留进入终态的奖励，不查询终止空动作集合。

\[
Z_{\mathrm{SARSA}}(x')=Q^{\mathrm{SARSA}}_{\mathrm{pre}}(x',a'),
\qquad
Z_{\mathrm{QL}}(x')=\max_{u\in A(x')}Q^{\mathrm{QL}}_{\mathrm{pre}}(x',u).
\]

a′ 是 SARSA 在当前写入前有效选定的下一行为动作，之后应沿用；u 是最大化时遍历的合法候选，A(x′) 为已知非空合法集合。QL 是 Q-learning 的缩写。max 返回数值；真正执行哪个动作仍由行为决定。若 SARSA 恰好选到当前最大动作，这一次目标可相同；不能由此推广两算法的动作链、平局、更新顺序与后续访问全相同。[机制依据教材 §6.4～6.5，式 6.7、6.8。](https://www.andrew.cmu.edu/course/10-703/textbook/BartoSutton.pdf)

### 3.3 两种目标改进的复习范围

Expected SARSA（ES）给定目标策略 π，对后继合法动作估计加权。下面 π=b，只作 on-policy 的独立对照：

\[
Z_{\mathrm{ES}}(x')=
\sum_{u\in A(x')}\pi(u\mid x')Q^{\mathrm{ES}}_{\mathrm{pre}}(x',u).
\]

π(u|x′) 是给定后继后，目标策略选择 u 的概率，须在合法集合归一化；Σ 对合法动作求和。它不需要先抽 a′ 才能构造当前目标。固定 r、x′、Q_pre、π 时，它平均掉 SARSA 的下一动作抽样分量；没有平均掉未知环境后果、估计误差或整个训练过程。一般 ES 的目标 π 可以不同于行为 b，不是始终 on-policy。[教材 §6.6，式 6.9。](https://www.andrew.cmu.edu/course/10-703/textbook/BartoSutton.pdf)

Double Q 只回顾一个检查顺序：指定更新 A 支时，用 Q^A_pre 在合法动作中选最大动作索引，再用 Q^B_pre 评价**同一索引**，只写 A 的当前项；B 支对称。不要在另一表重选最大动作，不要一条转移两表一起写。分别维护两张表不自动统计独立，也不保证总无偏或补齐覆盖；这里不再增加一套双表数字。[教材 §6.7 的双估计机制与程序；原课详解见 RL-018。](../RL-018/)

## 4. 手算例子或更新过程

### 4.1 原封不动复用 RL-020 的有限合同

以下全是教学条件，未抽随机数、执行 GUI 或训练。状态只有 N2、C1、z：N2 为菜单且剩余动作 h=2，C1 为确认页且 h=1，初态全部在 N2；每动作消耗一预算，任务内 h=0 真终止，也可提前退出。不引入 N1/C2 等状态。

| 完整状态与合法动作 | 后继、奖励 | 概率 | 结果 |
|---|---|---:|---|
| N2：review | C1，r=−1 | 1 | 非终止，仅导航 |
| N2：exit | z，r=0 | 1 | 真终止，退出非成功 |
| C1：confirm | z，r=8 | 0.9 | 真终止，独立持久核验成功 |
| C1：confirm | z，r=−4 | 0.1 | 真终止，独立持久核验失败 |
| C1：cancel | z，r=0 | 1 | 真终止，取消非成功 |

γ=0.9。奖励是人为给定的无量纲效用；review 的 −1 已含其导航成本，confirm 不另扣步骤费，无额外终止加分或预算补偿。z 后续回报 0，不再选择动作，进入 z 的 8 或 −4 仍保留。教学观测提供完整状态与可信 mask，confirm 转移在独立持久核验完成后才返回结果；待核验不能擅填成功。

许可先验固定 A(N2)={review,exit}、A(C1)={confirm,cancel}。delete 即使有 mask 前原始候选评分 99，也不是合法 Q 项，不入行为或目标。规则与各方法共享相同 mask；这是任务设计者提供的约束，不是学出来的安全能力，confirm 仍可能失败。

reset 只在任务间准备新 N2，不产生任务内奖励、不扣新任务 h；真实重置时间与费用要另记。环境 reset 不自动清空 Q，也不能让新初态替代旧后继。若采集器在 review 后外部停止，原状态仍 C1，不能因此改成真终止；QL 有效旧后继加 mask 可构当前目标，SARSA 还需有效选定且可沿用的 a′，否则留待核、不补动作。[任务内期限和外部截断的区别见官方说明。](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)

### 4.2 两份相同 fresh pre，先核对实际动作

SARSA 与 Q-learning 各从下面独立副本开始，α=0.5、ε=0.2、有效写入计数 N 全为 0。不继承 RL-020 的最终表：

| 合法项 | fresh Q_pre | N |
|---|---:|---:|
| N2,review | 1 | 0 |
| N2,exit | 0 | 0 |
| C1,confirm | 4 | 0 |
| C1,cancel | −2 | 0 |

沿用全合法均匀探索与均匀最大平局。两个合法且唯一最大时，贪心概率 1−ε+ε/2=0.9，另一个 0.1；并列最大各 0.5，仅一合法为 1。未知或非终止空 mask 不硬抽动作。两份初表给 review/exit 为 0.9/0.1，C1 给 confirm/cancel 为 0.9/0.1；delete 为 0。[动作过滤必须同时作用于探索、利用和后继 max。](https://gymnasium.farama.org/tutorials/training_agents/action_masking_taxi/)

两条人工轨迹都先 review，看到 r=−1、C1、d=0。SARSA 先按行为规则选定 cancel，再构造当前目标并 carry；QL 当前目标不需 a′，但其下一实际动作也人为指定 cancel。第一步只写 N2，C1 未变，所以本例两种选动作时机的 C1 概率一致。这里没有真实抽到一次 0.1 事件。

### 4.3 同转移的两种目标，两步完成后的表

| 第一步 | SARSA 独立副本 | Q-learning 独立副本 |
|---|---:|---:|
| 当前项 pre | 1 | 1 |
| 后继项 | 已选 cancel 的 −2 | 合法 max(4,−2)=4 |
| y | −1+0.9×(−2)=−2.8 | −1+0.9×4=2.6 |
| δ | −3.8 | 1.6 |
| Nreview 的 post | −0.9 | 1.8 |

读取的 4 是 confirm 的估计，不是它的环境期望 6.8 或成功奖励 8。两列独立，不串写，也不因为目标读取 confirm 就补一条成功反馈。

第二步实际执行同一个 cancel，r=0、到 z、d=1。两表 Ccancel 的 pre 都仍 −2，y=0，δ=2，post=−2+0.5×2=−1，不再选下一动作，也不回改第一步。

| 两步后的合法项 | SARSA | Q-learning | 每份有效写入 N |
|---|---:|---:|---:|
| N2,review | −0.9 | 1.8 | 1 |
| N2,exit | 0 | 0 | 0 |
| C1,confirm | 4 | 4 | 0 |
| C1,cancel | −1 | −1 | 1 |

两条奖励都是 −1、0，所以完整 G=−1+0.9×0=−1，均非成功。post 不是回报，未写入两项仍是初值；此处不构成训练效果或风险排序。

### 4.4 第三份独立 ES 对照，只平均下一动作

再从同一**原始 pre**另开第三份表，固定相同 review 后继及 π=b=(confirm 0.9,cancel 0.1)：

| ES 对照量 | 计算与结果 |
|---|---|
| 后继动作均值 | 0.9×4+0.1×(−2)=3.4 |
| y_ES | −1+0.9×3.4=2.06 |
| δ_ES | 2.06−1=1.06 |
| Nreview 的 post | 1+0.5×1.06=1.53 |

1.53 不接在 −0.9 或 1.8 后继续写入。若仅随机下一动作，SARSA 的 y 以 0.9 为 2.6、0.1 为 −2.8，其条件均值恰为 2.06；ES 精确求这个动作平均。没有对全部后继、奖励分布或未知真实价值做求和，更没有宣称总误差为零或更好收敛。

ES 目标不需预抽 a′；若再人为续接实际 cancel，Ccancel 同样从 −2 到 −1，完整 G 仍 −1。此续接是独立教学对照，不加入两张主表，不表示求和中的 confirm 已被执行。

### 4.5 保留一个模型参照，避免把数字混在一起

RL-020 的先验规则流程是 review→confirm，不是上述 cancel 轨迹。已知核中 confirm 期望奖励为 0.9×8+0.1×(−4)=6.8；它优于 cancel 的 0，review 的期望 −1+0.9×6.8=5.12 优于 exit 的 0，所以这个规则是**该明确受限 MDP 内**的最优参照。

成功路径 G=6.2，失败路径 G=−4.6；模型期望为 0.9×6.2+0.1×(−4.6)=5.12，成功概率 0.9。最大化的是合法动作，不是挑最大奖励分支、忽略失败。5.12 既不是成功 G，也不是当前 Q、一次 TD 目标或真实 GUI 成功率。规则拥有流程先验，模型计算还知道概率；不得拿它和初始化加两次写入直接排名算法性能。

## 5. 与前一种方法的关系：本周机制如何连起来

| 方法/环节 | 取什么后继信息 | 改变了什么、未解决什么 |
|---|---|---|
| SARSA | 已选实际 a′ 的 pre 估计 | 把探索动作纳入当前目标，需有效动作链 |
| Q-learning | 后继合法估计 max | 目标按当前贪心后续，行为仍可探索并付代价 |
| Expected SARSA | 已知目标 π 的动作加权 | 消除指定条件下的下一动作抽样分量，增加求和与概率需求 |
| Double Q | 一表选索引、另一表评价 | 分离选择评价，增加独立维护与分支记录，不自动统计独立 |
| 探索与覆盖 | 初态、路径、mask、行为及实际计数 | 决定数据机会，目标公式不能创造未观测反馈 |
| 收敛与评价 | 问题、样本、步长、长期访问与独立测试 | 各有适用条件，短日志或较大目标不能替代 |

SARSA 的目标机制不构成所有 GUI 上的“安全保证”，QL 的最优目标也不构成当前探索行为最优。Expected 或 Double 处理估计的一部分问题，仍需状态、反馈、许可与成本合同。

复习经典边界时，先确认有限平稳完整表格、有界奖励、合适折扣与按对步长，再问所有合法对是否无限获得有效更新。SARSA 到最优值的常用 GLIE 条件还含极限贪心；ε→0 不能替代无限探索。QL 的行为不强制 GLIE，但覆盖与其余条件仍要满足。固定 α=0.5、有限两步不能调用一个完整 a.s. 最优保证；不满足这组充分条件也不等于所有运行必发散。详细命题回查 [RL-019](../RL-019/)，不把单表结论盖到所有方法或神经网络。

## 6. 一个主要研究应用：检查 GUI 控制比较是否成立

主要应用是**多步 GUI 中，区分策略学到了什么与任务真正完成了什么**。单张截图定位先比较监督定位；若动作改变后续画面、允许动作与持久结果，再判断是否需要多步控制。N2/C1 是教学完整状态，不替代真实截图、历史与隐藏状态分析。

研究资料仍未知，以下各项均**【待确认】**。复习课将字段压缩到一张合同表，不能靠缩写省掉必要信息：

| 合同项 | 真实任务需要填写并检查什么 |
|---|---|
| 观测与状态 | 【待确认】目标指令、画面/结构信息、历史、登录焦点与剩余预算，表示是否充分且版本稳定 |
| 动作、mask 与先验 | 【待确认】动作粒度、许可/权限依据及版本、规则流程知道什么、空/未知 mask 如何处理；所有方法同范围 |
| 行为与目标 | 【待确认】b/π、ε 与计时单位、平局、Q_pre、α/按对计数、SARSA a′/carry 或 Double 分支；实际动作与目标分别记录 |
| 奖励与独立反馈 | 【待确认】成功/失败/取消和时间/误操作代价、单位及 γ；由谁何时验证持久输出/记录，核验缺失或待定如何保存 |
| 多步与结束 | 【待确认】动作如何影响未来、任务内预算、真终止、外部截断的独立标志；保留有效原后继，不用新任务拼接 |
| 初态、reset 与恢复 | 【待确认】任务分布、可达性、隔离副本、恢复与重置成本，状态能否续接，Q 是否跨任务保留 |
| 数据与覆盖 | 【待确认】真实 x,a,r,x′、mask、结果、版本、行为概率、pre/y/post、各对访问/有效写入及分母；保留失败取消截断和缺失 |
| 指标与评价 | 【待确认】持久成功率、回报、许可违规/错误后果、取消、步数/时延、覆盖空缺与不确定性；训练探索与冻结评价分开 |

点击命中、控件定位正确或成功提示出现，都不能自动替代独立持久结果。比较方法时，目标更大、δ 更小、某次 post 更接近模型参照，也不能单独证明业务收益。需要记录真实行为成本和冻结评价协议，保留失败与缺失，而非只选成功完整轨迹。

一个可验证但**尚未运行的研究假设**是：完整区分行为、目标和持久反馈，能否帮助识别“数值在变化，但目标仍未完成”的 GUI 失败？它需要真实任务、非 RL 基线与独立评价；本课只有拟议检查方案，**NOT_RUN**。

模态路由的真实输入来源、标签语义、动作与错误成本仍【待确认】，不能借其他任务标签或把单次选择硬写成多步。SR 先明确早停、迭代或计算分配等真实决策与质量—成本目标；普通单次重建先用监督与固定处理基线。本周表格机制不自动证明三方向适配。
