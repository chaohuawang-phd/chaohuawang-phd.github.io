1. 今天解决什么问题，与前面哪些单元有关

同样从 N2 做 review，之后实际 cancel，为什么 SARSA 把前一动作估计写成 −0.9，Q-learning 却写成 1.8？因为两者的后继目标不同，不是两条轨迹收到了不同奖励，也不是它们已经知道哪个真实策略更好。

本课是第三周的固定总结。把六课串成一条线：行为产生数据 → 目标读取估计 → 写入改变表 → 表影响后续行为 → 覆盖、反馈与成本约束结论。这里不新增算法，不复制六篇长文，也不根据材料已生成推断任何读者已掌握。

本周单元与稳定回链 带走的一个关键问题 与下一环的关系
RL-015｜SARSA：沿当前行为策略学习动作价值 目标里的下一动作会不会真的执行？ 选定 a′，读 pre 值，更新后携带同一个动作
RL-016｜Q-learning：用贪心目标学习控制 实际探索时，目标能否按当前合法最大值？ max 目标与实际下一动作分开
RL-017｜探索策略：ε-greedy的代价与覆盖 状态内正概率是否等于路径有足够数据？ 探索改变机会与成本，不能只看 ε
RL-018｜Expected SARSA与Double Q：改进目标估计 求动作平均、分离选择评价各处理什么？ 改变估计机制，不补缺失反馈或覆盖
RL-019｜表格控制的边界：收敛条件与数据覆盖 哪些长期前提支持哪一种结论？ 有限记录不是无限访问、步长或 a.s. 最优证书

2. 学习目标

  1. 能用“行为、目标、估计、完整回报”四个对象，解释 SARSA 与 Q-learning 的差别及一次数值相同的适用范围。
  2. 能从独立同一 pre 表，复算两种主方法的两次写入，并独立核对 Expected SARSA 的动作平均；不串表、不编造未选动作反馈。
  3. 能据本周知识判断覆盖、收敛、mask、外部截断与持久成功的边界，为真实 GUI 补齐评价、成本和非 RL 对照。

3. 直觉、定义和必要公式

3.1 先把四个对象分开

对象 回答的问题 本课中的例子
行为策略 b 实际执行什么，从而得到哪些数据？ 初始 ε-greedy；人工轨迹实际 review、cancel
一步目标 y 本次把当前估计朝哪里推？ SARSA 的 −2.8、QL 的 2.6，含后继估计
当前估计 Q 现在这张表存什么？ 初始 Nreview=1，第一步之后为 −0.9 或 1.8
完整回报 G 这条已完成轨迹实际累计什么？ 奖励 −1、0，折扣后 G=−1

这里 Q 不等于指定策略真实动作价值 q_pi，更不等于真正最优动作价值 Q*。q_pi 是先做指定动作、之后持续按固定 π 续行的期望折扣回报；Q* 在之后选择最优续行。初始化与有限写入的 Q 可以尚未准确估计任何一个目标；y 和一条 G 也都不是自动可用的真实价值标签。

SARSA 的 on-policy 联系体现在：a′ 按行为策略选定，其 pre 值进入当前目标，然后携带到下一次实际执行。Q-learning 的 off-policy 联系体现在：目标按后继合法最大估计，行为仍可探索。Off-policy 允许目标与行为不同，不等于任何日志都足以识别未访问动作。

3.2 同一个写入骨架，不同的后继项

令 x,a 为已执行动作前的完整状态和合法动作，r 为这次即时奖励，x′ 为原任务真实后继；d=1 表示真终止，d=0 表示原任务继续。γ 是折扣，α 是步长，pre/post 是本次写入前后。对资料有效的记录：

yM={r,d=1,r+γZM(x′),d=0,δM=yM−QpreM(x,a),QpostM(x,a)=QpreM(x,a)+αδM.y_M=\begin{cases} r,&d=1,\\ r+\gamma Z_M(x'),&d=0, \end{cases} \qquad \delta_M=y_M-Q^M_{\mathrm{pre}}(x,a), \qquad Q^M_{\mathrm{post}}(x,a)=Q^M_{\mathrm{pre}}(x,a)+\alpha\delta_M.yM​={r,r+γZM​(x′),​d=1,d=0,​δM​=yM​−QpreM​(x,a),QpostM​(x,a)=QpreM​(x,a)+αδM​.

M 标识方法，Z_M 是该方法的后继估计项；上标 M 表示独立维护的表，不是幂。δ_M 是目标差，不能称为相对真实价值的误差。本次只写当前项，其他项不动。真终止时直接 y=r，保留进入终态的奖励，不查询终止空动作集合。

ZSARSA(x′)=QpreSARSA(x′,a′),ZQL(x′)=max⁡u∈A(x′)QpreQL(x′,u).Z_{\mathrm{SARSA}}(x')=Q^{\mathrm{SARSA}}_{\mathrm{pre}}(x',a'), \qquad Z_{\mathrm{QL}}(x')=\max_{u\in A(x')}Q^{\mathrm{QL}}_{\mathrm{pre}}(x',u).ZSARSA​(x′)=QpreSARSA​(x′,a′),ZQL​(x′)=u∈A(x′)max​QpreQL​(x′,u).

a′ 是 SARSA 在当前写入前有效选定的下一行为动作，之后应沿用；u 是最大化时遍历的合法候选，A(x′) 为已知非空合法集合。QL 是 Q-learning 的缩写。max 返回数值；真正执行哪个动作仍由行为决定。若 SARSA 恰好选到当前最大动作，这一次目标可相同；不能由此推广两算法的动作链、平局、更新顺序与后续访问全相同。机制依据教材 §6.4～6.5，式 6.7、6.8。

3.3 两种目标改进的复习范围

Expected SARSA（ES）给定目标策略 π，对后继合法动作估计加权。下面 π=b，只作 on-policy 的独立对照：

ZES(x′)=∑u∈A(x′)π(u∣x′)QpreES(x′,u).Z_{\mathrm{ES}}(x')= \sum_{u\in A(x')}\pi(u\mid x')Q^{\mathrm{ES}}_{\mathrm{pre}}(x',u).ZES​(x′)=u∈A(x′)∑​π(u∣x′)QpreES​(x′,u).

π(u|x′) 是给定后继后，目标策略选择 u 的概率，须在合法集合归一化；Σ 对合法动作求和。它不需要先抽 a′ 才能构造当前目标。固定 r、x′、Q_pre、π 时，它平均掉 SARSA 的下一动作抽样分量；没有平均掉未知环境后果、估计误差或整个训练过程。一般 ES 的目标 π 可以不同于行为 b，不是始终 on-policy。教材 §6.6，式 6.9。

Double Q 只回顾一个检查顺序：指定更新 A 支时，用 Q^A_pre 在合法动作中选最大动作索引，再用 Q^B_pre 评价同一索引，只写 A 的当前项；B 支对称。不要在另一表重选最大动作，不要一条转移两表一起写。分别维护两张表不自动统计独立，也不保证总无偏或补齐覆盖；这里不再增加一套双表数字。教材 §6.7 的双估计机制与程序；原课详解见 RL-018。

4. 手算例子或更新过程

4.1 原封不动复用 RL-020 的有限合同

以下全是教学条件，未抽随机数、执行 GUI 或训练。状态只有 N2、C1、z：N2 为菜单且剩余动作 h=2，C1 为确认页且 h=1，初态全部在 N2；每动作消耗一预算，任务内 h=0 真终止，也可提前退出。不引入 N1/C2 等状态。

完整状态与合法动作 后继、奖励 概率 结果
N2：review C1，r=−1 1 非终止，仅导航
N2：exit z，r=0 1 真终止，退出非成功
C1：confirm z，r=8 0.9 真终止，独立持久核验成功
C1：confirm z，r=−4 0.1 真终止，独立持久核验失败
C1：cancel z，r=0 1 真终止，取消非成功

γ=0.9。奖励是人为给定的无量纲效用；review 的 −1 已含其导航成本，confirm 不另扣步骤费，无额外终止加分或预算补偿。z 后续回报 0，不再选择动作，进入 z 的 8 或 −4 仍保留。教学观测提供完整状态与可信 mask，confirm 转移在独立持久核验完成后才返回结果；待核验不能擅填成功。

许可先验固定 A(N2)={review,exit}、A(C1)={confirm,cancel}。delete 即使有 mask 前原始候选评分 99，也不是合法 Q 项，不入行为或目标。规则与各方法共享相同 mask；这是任务设计者提供的约束，不是学出来的安全能力，confirm 仍可能失败。

reset 只在任务间准备新 N2，不产生任务内奖励、不扣新任务 h；真实重置时间与费用要另记。环境 reset 不自动清空 Q，也不能让新初态替代旧后继。若采集器在 review 后外部停止，原状态仍 C1，不能因此改成真终止；QL 有效旧后继加 mask 可构当前目标，SARSA 还需有效选定且可沿用的 a′，否则留待核、不补动作。任务内期限和外部截断的区别见官方说明。

4.2 两份相同 fresh pre，先核对实际动作

SARSA 与 Q-learning 各从下面独立副本开始，α=0.5、ε=0.2、有效写入计数 N 全为 0。不继承 RL-020 的最终表：

合法项 fresh Q_pre N
N2,review 1 0
N2,exit 0 0
C1,confirm 4 0
C1,cancel −2 0

沿用全合法均匀探索与均匀最大平局。两个合法且唯一最大时，贪心概率 1−ε+ε/2=0.9，另一个 0.1；并列最大各 0.5，仅一合法为 1。未知或非终止空 mask 不硬抽动作。两份初表给 review/exit 为 0.9/0.1，C1 给 confirm/cancel 为 0.9/0.1；delete 为 0。动作过滤必须同时作用于探索、利用和后继 max。

两条人工轨迹都先 review，看到 r=−1、C1、d=0。SARSA 先按行为规则选定 cancel，再构造当前目标并 carry；QL 当前目标不需 a′，但其下一实际动作也人为指定 cancel。第一步只写 N2，C1 未变，所以本例两种选动作时机的 C1 概率一致。这里没有真实抽到一次 0.1 事件。

第二步实际执行同一个 cancel，r=0、到 z、d=1。两表 Ccancel 的 pre 都仍 −2，y=0，δ=2，post=−2+0.5×2=−1，不再选下一动作，也不回改第一步。

4.4 第三份独立 ES 对照，只平均下一动作

再从同一原始 pre另开第三份表，固定相同 review 后继及 π=b=(confirm 0.9,cancel 0.1)：

ES 对照量 计算与结果
后继动作均值 0.9×4+0.1×(−2)=3.4
y_ES −1+0.9×3.4=2.06
δ_ES 2.06−1=1.06
Nreview 的 post 1+0.5×1.06=1.53

1.53 不接在 −0.9 或 1.8 后继续写入。若仅随机下一动作，SARSA 的 y 以 0.9 为 2.6、0.1 为 −2.8，其条件均值恰为 2.06；ES 精确求这个动作平均。没有对全部后继、奖励分布或未知真实价值做求和，更没有宣称总误差为零或更好收敛。

ES 目标不需预抽 a′；若再人为续接实际 cancel，Ccancel 同样从 −2 到 −1，完整 G 仍 −1。此续接是独立教学对照，不加入两张主表，不表示求和中的 confirm 已被执行。

4.5 保留一个模型参照，避免把数字混在一起

RL-020 的先验规则流程是 review→confirm，不是上述 cancel 轨迹。已知核中 confirm 期望奖励为 0.9×8+0.1×(−4)=6.8；它优于 cancel 的 0，review 的期望 −1+0.9×6.8=5.12 优于 exit 的 0，所以这个规则是该明确受限 MDP 内的最优参照。

成功路径 G=6.2，失败路径 G=−4.6；模型期望为 0.9×6.2+0.1×(−4.6)=5.12，成功概率 0.9。最大化的是合法动作，不是挑最大奖励分支、忽略失败。5.12 既不是成功 G，也不是当前 Q、一次 TD 目标或真实 GUI 成功率。规则拥有流程先验，模型计算还知道概率；不得拿它和初始化加两次写入直接排名算法性能。

5. 与前一种方法的关系：本周机制如何连起来

方法/环节 取什么后继信息 改变了什么、未解决什么
SARSA 已选实际 a′ 的 pre 估计 把探索动作纳入当前目标，需有效动作链
Q-learning 后继合法估计 max 目标按当前贪心后续，行为仍可探索并付代价
Expected SARSA 已知目标 π 的动作加权 消除指定条件下的下一动作抽样分量，增加求和与概率需求
Double Q 一表选索引、另一表评价 分离选择评价，增加独立维护与分支记录，不自动统计独立
探索与覆盖 初态、路径、mask、行为及实际计数 决定数据机会，目标公式不能创造未观测反馈
收敛与评价 问题、样本、步长、长期访问与独立测试 各有适用条件，短日志或较大目标不能替代

SARSA 的目标机制不构成所有 GUI 上的“安全保证”，QL 的最优目标也不构成当前探索行为最优。Expected 或 Double 处理估计的一部分问题，仍需状态、反馈、许可与成本合同。

复习经典边界时，先确认有限平稳完整表格、有界奖励、合适折扣与按对步长，再问所有合法对是否无限获得有效更新。SARSA 到最优值的常用 GLIE 条件还含极限贪心；ε→0 不能替代无限探索。QL 的行为不强制 GLIE，但覆盖与其余条件仍要满足。固定 α=0.5、有限两步不能调用一个完整 a.s. 最优保证；不满足这组充分条件也不等于所有运行必发散。详细命题回查 RL-019，不把单表结论盖到所有方法或神经网络。

6. 一个主要研究应用：检查 GUI 控制比较是否成立

主要应用是多步 GUI 中，区分策略学到了什么与任务真正完成了什么。单张截图定位先比较监督定位；若动作改变后续画面、允许动作与持久结果，再判断是否需要多步控制。N2/C1 是教学完整状态，不替代真实截图、历史与隐藏状态分析。

采集与训练成本 【待确认】交互、标注/反馈核验、重置、恢复、重复与调参训练，表格更新便宜不表示经验便宜
推理与执行成本 【待确认】视觉编码、候选生成、mask 校验、Q 查询/求和/双表、等待和结果核验的完整任务时延与资源
非 RL 基线与公平性 【待确认】固定流程、监督定位加流程、示范策略等；匹配任务/输入/权限/预算/成功判据并披露先验，分开训练、调参和测试

点击命中、控件定位正确或成功提示出现，都不能自动替代独立持久结果。比较方法时，目标更大、δ 更小、某次 post 更接近模型参照，也不能单独证明业务收益。需要记录真实行为成本和冻结评价协议，保留失败与缺失，而非只选成功完整轨迹。

一个可验证但尚未运行的研究假设是：完整区分行为、目标和持久反馈，能否帮助识别“数值在变化，但目标仍未完成”的 GUI 失败？它需要真实任务、非 RL 基线与独立评价；本课只有拟议检查方案，NOT_RUN。

模态路由的真实输入来源、标签语义、动作与错误成本仍【待确认】，不能借其他任务标签或把单次选择硬写成多步。SR 先明确早停、迭代或计算分配等真实决策与质量—成本目标；普通单次重建先用监督与固定处理基线。本周表格机制不自动证明三方向适配。

8. 三道理解题

题 1｜同一转移，三个目标。 从本课三份相同 fresh pre 出发：人为 review、r=−1 到 C1，SARSA 已选且实际沿用 cancel；ES 使用 π=b=(0.9,0.1)。分别计算 SARSA、QL、独立 ES 的后继项、y、δ、post。再按实际 cancel、r=0 到 z，给两张主表最终值、有效计数与完整 G。能否把三列顺序写入同表，或拿模型期望 6.8 替换估计 4？

题 2｜控制、覆盖和数值含义。 判断并说明理由：①SARSA 若本次选中 confirm，就与 Q-learning 在整个训练等价；②ε→0 且 Q 看起来稳定，有限日志已证明最优；③off-policy 无需覆盖；④Double 两张数组自动独立；⑤规则参照 5.12 是成功轨迹 G，可与 post 排名效果。请分别指出正确对象、必要条件或应返回的单元。

题 3｜GUI 日志与真实判据。 采集器在 review 后停止，旧 C1 与 mask 有效，但无已选 a′，随后 reset 到新 N2；QL、SARSA、给定有效 π 的 ES 各能否构当前目标？若旧后继或 mask 也丢失呢？列四项真实合同、一个独立持久成功判据、一个非 RL 基线与训练/推理各一项成本，并说明当前证据能支持什么。
