1. 今天解决什么问题，与前面哪些单元有关

第一周已经明确 Vπ 的含义，并用完整轨迹或 Bellman 关系求出给定 GUI 策略的价值。今天开始问计算问题：如果一开始不知道价值表，只知道环境模型与固定策略，怎样逐轮算出它？

动态规划（Dynamic Programming，DP）中的策略评估（policy evaluation，也称 prediction）回答“这个指定策略继续执行，期望回报怎样”。本课不改变策略，不学习转移模型，也不寻找最优动作。

迭代策略评估（iterative policy evaluation）从一个初始近似表出发，把旧表的后续价值代入 Bellman 右侧，生成一张新表，再重复。它使用模型中各可能结果的期望，不是实际采样一条轨迹来训练。

本课沿用前课同一个有限预算 GUI 教学环境，只把“已知的精确答案”变成“从零表计算并核对的目标”。要分清两种计数：h 是任务里还剩多少真实动作；k 是电脑已经对价值表做了多少轮计算。多算一轮不会给真实任务多送一步预算。

2. 学习目标

学完后，应当能够：

  1. 写出已知环境、固定策略下的同步策略评估更新，说明近似表 v_k 与目标 Vπ、迭代次数 k 与任务预算 h 的区别。
  2. 用 old/new 两张表手算两轮，检查全表改变量并解释第三轮停止核查；识别把本轮新值过早用于同轮更新的情况。
  3. 说明收敛直觉所需的有限表格、固定模型/策略和折扣条件，以及模型错误、计算成本和未知真实 GUI 条件的限制。

3. 直觉、定义和必要公式

3.1 输入是模型与策略，输出是该策略的价值

本课已知：合法动作集合、奖励与下一状态的联合概率 p、固定策略 π、折扣 γ，以及真实终止和任务预算。未知、需要计算的是策略价值表。

对象 本课含义 不要混淆
π 被评价的固定行为规则 评估过程中不做动作最大化或策略改进
p(s′,r｜s,a) 做指定动作后的下一页面与奖励联合概率 不是采样得到的一条结果，也不是模型置信分数
Vπ(s,h) 该模型、策略与预算下真正的期望回报 目标量，不等于每轮近似表
v_k(s,h) 完成第 k 轮计算后的价值近似 小写 v 表示当前计算结果
h 剩余真实动作数，完整状态包括 (s,h) 不是迭代编号或训练轮数
k 已完成的全表计算轮数 增加 k 不改变任何任务的 h

“模型已知”是计算条件：每个合法动作的可能结果和概率可供求和。真实模型可以由另外的数据工作得到，但那是独立环节；本课不会因为使用 p 就声称已经从未知环境学会了它。若输入的是近似模型，计算目标首先也是这个近似模型下的价值。

3.2 把 Bellman 关系变成同步更新

为连接有限预算例子，假设每个真实动作都消耗一步，页面转移/奖励在 h>0 时相同，预算另行减 1。对非终止、h≥1 的状态：

vk+1(s,h)=∑a∈Ah(s)π(a∣s,h)∑s′,rp(s′,r∣s,a)[r+γvk(s′,h−1)]v_{k+1}(s,h)= \sum_{a\in A_h(s)}\pi(a\mid s,h) \sum_{s',r}p(s',r\mid s,a) \left[r+\gamma v_k(s',h-1)\right]vk+1​(s,h)=a∈Ah​(s)∑​π(a∣s,h)s′,r∑​p(s′,r∣s,a)[r+γvk​(s′,h−1)]
  • s、s′：当前与下一页面的取值；完整状态还包含剩余预算 h。
  • A_h(s)：当前合法动作集合，a 是其中一个动作。
  • π(a｜s,h)：当前固定策略选择该动作的概率。
  • p(s′,r｜s,a)：给定当前页面与动作后，环境返回下一页面及奖励 r 的联合概率；两者不必独立。
  • r：这一步奖励的可能取值；γ 是未来奖励的折扣因子。
  • v_k(s′,h−1)：上一轮表中下一状态的价值；下一任务预算必须减 1。
  • v_(k+1)：本轮生成的新表；k 从 0 开始，v₀ 是初始化。

外层按策略选择动作取平均，内层按环境后果取平均。这里没有选择最优动作的 max，也没有学习率或随机采样项。即使 p 中某个结果概率很小，也应按给定概率纳入期望。

本课取 v₀ 全零，只是方便演示的初始化，不是在断言所有状态真正的未来价值为零。边界在每轮都固定：

vk(s,0)=0,vk(z,h)=0v_k(s,0)=0,\qquad v_k(z,h)=0vk​(s,0)=0,vk​(z,h)=0

z 为任务终态，h=0 表示本课真实任务预算耗尽。进入终态那一步的奖励仍计入 r；之后才没有新的奖励。外部采集截断则不能直接套用真实终止边界。

上述有限预算写法等价于把 (s,h) 作为完整状态再应用策略评估；一般 MDP 不一定有这个单独的 h，若模型随时间变化或预算消耗不同，也必须把相应规律明确放进完整状态与转移，不能机械地套“减 1”。

3.3 同步：本轮所有状态只能读取同一张 old 表

同步更新（synchronous update）使用两份数组：old 保存 v_k，new 保存 v_(k+1)。即使先算出了 new(F,1)，本轮 new(H,2) 仍只能读取 old(F,1)。全部状态写完后，才把 new 整体设为下一轮的表。

若直接原地覆盖并让后面的状态读取本轮刚算的新值，得到的是另一种原地更新（in-place update）。在适当条件下它也可以是有效算法，但结果传播速度会依赖顺序，不能把它产生的轮次表称为本课的同步表。今天固定两数组版本，便于独立复算。

例如在有限表格、γ<1 且适当遍历状态等条件下，原地策略评估也可以收敛。本例还可以从零边界向较大 h 逐层直接回代，那是有限时域的另一种计算安排，不等同于一次全表同步 sweep，也没有改变所求的 Vπ 目标。

3.4 用全表变化监测停止，别把计算轮次当环境步数

对 k≥1，定义本轮结束后的全表最大改变量：

Δk=max⁡(s,h)∣vk(s,h)−vk−1(s,h)∣\Delta_k=\max_{(s,h)} \left|v_k(s,h)-v_{k-1}(s,h)\right|Δk​=(s,h)max​∣vk​(s,h)−vk−1​(s,h)∣

Δ_k 比较的是新表 v_k 与上一张表 v_(k−1)。max 在这里仅用于找出哪个状态的数值改动最大，不是在动作中求最优。边界始终为零，包含它们不会改变最大值。

计算可以在 Δ_k 小于预先选定的正阈值 θ 时停止；θ 的单位是回报，不是学习率。也应设置计算上限 K_max，并明确返回“达到阈值”还是“达到轮数上限”。后者不能自动称为收敛。

Δ 小表示在当前模型上的更新已变化不大，不等于真实环境模型正确，也不自动等于真实业务误差小。本课不使用一个未注明下标的误差界来把 Δ 直接当作 v_k 的全部误差。

3.5 为什么反复计算能靠近目标？

把“用同一模型与固定 π 做一轮期望更新”的操作记作 Tπ。对于有限状态/动作表格、有界奖励、固定模型与策略，0≤γ<1 时，一轮更新对两张表差异的最大放大倍数不超过 γ：

∥Tπu−Tπw∥∞≤γ∥u−w∥∞\left\|T^\pi u-T^\pi w\right\|_\infty \le\gamma\left\|u-w\right\|_\infty∥Tπu−Tπw∥∞​≤γ∥u−w∥∞​

u、w 是两张候选价值表；Tπ 是同一个期望更新操作；无穷范数表示全表绝对值的最大值。两次更新使用相同的即时奖励，所以差异只来自后续表；先按概率平均，不会超过最大差异，再乘 γ。真价值 Vπ 满足同一 Bellman 关系，是这个操作的固定点，因此这种收缩解释了折扣条件下迭代靠近它的直觉。

γ 接近 1 时，收缩可能很慢。γ=1 时这个不等式不再提供严格收缩，不能直接推广成一般任务的无条件收敛保证；还需要任务终止等其他条件。当前教学例有真正有限的两步预算，即使不依赖严格折扣收缩，也可从零边界逐层传播。但“本例两轮得到精确值”来自它的有限深度，不是一般策略评估都只需两轮。

本节更新与两数组说明可核对 Sutton 与 Barto 第二版原稿第 4.1 节，重点是册页 74 的式 (4.5) 与册页 75 的同步/原地更新区别。

4. 手算与伪代码：同一 GUI 的同步策略评估

4.1 完整模型与固定策略

以下精确数字全部是教学假设，没有运行真实 GUI 研究实验。沿用 RL-004～007 的新模型，不更换奖励或另设新的失败成本。

页面与合法动作 下一页面 即时奖励 r 环境概率
H, open F −1 1.00
H, stop z 0 1.00
F, save z，成功 10 0.80
F, save z，失败 0 0.20
F, cancel z 0 1.00

每个页面—动作组的概率分别归一。每个真实动作 h 减 1；save 不另扣成本，h=0 或进入 z 后真正结束，无额外期限罚分或补发收益。γ=0.9，初态固定 (H,2)。本教学模型理想地假设页面与预算足够描述后果，不证明真实截图是完整状态。

主例固定采用 πα：H 的 open/stop 概率为 0.75/0.25，F 的 save/cancel 为 1/0。h>0 时这些概率保持不变，评估过程中不作策略改进。

为展示 h≤2 的完整表，列出 (H,2)、(F,2)、(H,1)、(F,1)，所有 h=0 和 z 为零边界。(F,2) 不从当前初态 (H,2) 到达，但在同一预算模型里合法，可以一并计算；只关注当前初态的可达子图时也可以省去它，不改变模型或初态价值。

4.2 第一轮：所有右侧都读取 v₀=0

先算任一 h>0 的 F：save 后终止，所以新值为 0.8×10+0.2×0=8。对 H，open 得 −1、stop 得 0，而本轮右侧所有未来仍是 old 的零：

v1(H,2)=0.75[−1+0.9v0(F,1)]+0.25(0)=−0.75v_1(H,2)=0.75[-1+0.9v_0(F,1)]+0.25(0)=-0.75v1​(H,2)=0.75[−1+0.9v0​(F,1)]+0.25(0)=−0.75

虽然本轮同时得到 v₁(F,1)=8，仍不能把 8 放进这条第一轮式子。v₁(H,1) 也为 −0.75，不过它引用的是始终为零的预算边界 v₀(F,0)。

4.3 第二轮：读取已经完成的 v₁

F 的两个预算层仍都是 8；H 的剩两步状态现在能读取旧表中的 F、剩一步价值：

v2(H,2)=0.75[−1+0.9v1(F,1)]+0.25(0)=0.75[−1+0.9(8)]=4.65v_2(H,2)=0.75[-1+0.9v_1(F,1)]+0.25(0) =0.75[-1+0.9(8)]=4.65v2​(H,2)=0.75[−1+0.9v1​(F,1)]+0.25(0)=0.75[−1+0.9(8)]=4.65

H 的剩一步状态仍只能引用 h=0，因此 v₂(H,1)=−0.75。多一轮计算没有增加它的环境预算。

(H,2) 0 −0.75 4.65 4.65

全表变化为 Δ₁=8、Δ₂=|4.65−(−0.75)|=5.4、Δ₃=0。第二轮的表在这个模型里已等于前课的精确 Vπα，但 Δ₂ 还不是零；第三轮读 v₂ 再算一遍，才观察到表完全不变。第三轮只是数值停止核查，不是新的一次 GUI 动作，也不是新增的模型步骤。

本例从零表开始，最多两层真实奖励的影响经过两轮传播后已经完整到达。更长预算或存在回路的一般模型，不能直接套“两轮精确”的说法；不同初始化还会改变中间表，轮次比较也必须说明初表。

4.4 简短伪代码：两数组、固定边界、清楚的停止原因

input: states, legal_actions, fixed_pi, model_p, gamma, theta, K_max
v = zero_table(states)                 # v_0; terminal / h=0 also zero
for k in 1..K_max:
    old = copy(v)
    new = zero_table(states)           # boundary entries stay zero
    for each nonterminal (s, h) with h >= 1:
        new[s,h] = sum_a fixed_pi[a|s,h] *
                   sum_(s_next,r) model_p[s_next,r|s,a] *
                   (r + gamma * old[s_next,h-1])
    delta = max_abs_difference(new, old)
    v = new                           # commit only after the full sweep
    if delta < theta:
        return v, k, delta, "tolerance_reached"
return v, k, delta, "iteration_limit"

states 是本次计算域，包含所需后继与边界；legal_actions、fixed_pi、model_p 分别提供合法动作、固定行为概率与已知联合核。循环 sum_a 只遍历合法动作；终态或 h=0 由表的零边界读取。theta 是正停止阈值，K_max 是正的计算轮数上限，均与真实动作预算 h 不同。delta 对应刚算出的 Δ_k；返回的是 v_k。

例如 θ=0.000001 且 K_max≥3，按本例精确算术在第三轮达到阈值。若 K_max=2，则返回的表恰好已经精确，但程序只应报告达到轮数上限，不能把尚未检查到的 Δ₃=0 编出来。实际浮点计算还需考虑数值精度。

5. 与前一种方法或概念的关系

前课已经知道什么 本课新增的计算机制 新条件或代价
Vπ 满足 Bellman 期望关系 把右侧旧值变成一轮更新，反复计算 需要明确模型、策略、初始化与停止条件
可以枚举完整轨迹求期望 把后续回报压进价值表反复复用 避免完整路径重复展开，但仍需访问模型结果
h 描述真实任务期限 k 描述价值计算的进展 两种编号不能互换，同轮不能偷用新值
给定策略与最优策略不同 本课只计算固定 π 的 Vπ 评估表数值准确也不等于策略已经最优

今天的 DP 是已知模型上的规划/评估计算，没有采集环境交互、没有梯度训练，也没有从未知数据学出转移概率。它可以作为 RL 的理论与算法基础，但不是必须采用 RL 才能做的事情。

同一指定策略的价值还可用完整路径枚举或 Bellman 线性方程精确求解。它们是本课计算结果的核对方法，也是不应忽略的对照；计算方法与策略本身的质量是两层问题。

6. 主要应用：可信 GUI 模型上的固定策略离线评估

本节属于工程推断。拟议用途是：若已经有可信、可计算的 GUI 转移/奖励模型，固定一个执行策略，先计算它在该模型里的期望表现。这不是用未知真实日志自动学出模型，也不等于模型中的评价就已经是实际任务结果。

数据与模型核查 状态—动作—后果记录、失败/取消、策略/模型版本、独立留出验证 【待确认】覆盖与偏差；未观测后果不能编造
评价指标 模型内 Vπ、计算残差、独立真实成功率/回报、步骤与成本 【待确认】真实评价协议，不能只报告 Δ 小
建模/训练成本 数据采集、标注、模型估计及验证；若模型已给定，本轮无需再训练 【待确认】建模预算，和 DP 计算分开统计
计算/推理成本 每轮遍历的状态、动作、结果数，两数组内存、轮数；实际执行另计调用与等待 【待确认】规模与资源，DP 不天然便宜
非 RL 基线 同模型同策略的精确枚举/线性方程；规则、监督定位与示范策略作为候选行为 【待确认】实现与匹配输入、预算和底层模型

两张价值表的内存随表大小增长，每一轮还需要对所列状态、合法动作和环境结果求和；状态或结果很多时，代价可能很大。模型建立本身的交互、标注和计算成本不能藏在“已知模型”四个字里。

首先应区分两个检验：计算是否正确求出了这个模型下的 Vπ，以及这个模型是否足以代表真实任务。前者可与同模型的枚举或线性方程比较；后者需要独立结果验证、覆盖检查与真实任务评价。若只是在错误模型上把 Δ 算到接近零，不能据此声称真实 GUI 成功率提高。

可提出一个研究假设：在真实输入权限、奖励、模型覆盖和成本明确后，模型内的固定策略评价能否帮助发现执行策略的薄弱状态？其可信度和实际价值仍需实验；本课研究状态为 未运行（NOT_RUN）。

SR 与模态路由只作边界联系：普通一次重建、独立单步路由不因本课出现 DP 就需要多步方法。SR 若有真实早停/计算分配，或路由若有获取信息后继续决定，再确认状态、合法动作、模型与代价。实际路由输入、标签定义和业务成本仍为【待确认】，不借其他任务合同。

7. 常见误解、失败条件和适用边界

误解或失败 本课纠正 复算或工程检查
k 增加就代表任务还有更多步 k 是计算轮数，h 是任务预算 检查下一任务层始终是 h−1
第一轮 F 已算成 8，H 同轮也可用 8 那变成原地读取新值 同步表 H 的首轮必须读 old(F,1)=0
原地更新都是错误算法 它与同步是不同计算安排 不把不同安排的轮次表混着解释
评估中选最大动作就更好 这样改变了被评估的策略与目标 固定 π 权重保持不变，策略改进留下一课
v₀ 全零说明所有状态真价值为零 这只是初始化 与边界强制为零区分
本例两轮精确，所以所有 DP 都两轮 本例只有两层未来影响 回路、长时域或其他初始化要另分析
Δ₂ 不为零，就说明 v₂ 必然不准 Δ₂ 比较 v₂ 与 v₁ 本例 v₂ 已精确，下一轮才观察到 Δ₃=0
Δ 很小就证明真实业务准确 只检查当前模型上的数值变化 另核实模型、反馈与完整任务结果
γ=1 也一定有相同收缩结论 严格折扣条件已改变 检查终止等附加条件，不作无条件保证
有 p 的符号就算学到了真实环境 模型是本课输入 明示来源与未知项，不把规划当模型学习

题 2｜两轮表格、停止检查与另一个固定策略。 对 πα 写出 v₀、v₁、v₂ 的完整表（H2、F2、H1、F1 和零边界），再核对 v₃ 与 Δ₁、Δ₂、Δ₃。若 θ=0.000001、K_max=2，该程序应返回什么停止原因？然后独立评估 πβ：仅 F 的 save/cancel 改为 0.5/0.5，H 仍为 0.75/0.25，重新从零表做两轮，F 和 H2 最终是多少？这是策略改进步骤还是另一次固定策略评估？

题 3｜模型内收敛是否等于真实任务有效？ 某 GUI 团队把教学成功率 .8 直接写入模型，用出现保存提示作为成功反馈；固定策略评估的 Δ 已很小，但真实输入权限、转移覆盖与成本尚不清楚。它能否声称已从未知环境学到了模型或真实成功率已提高？应补哪些观测/状态、动作、奖励反馈、起止数据、成本与基线条件？γ=1 时能否直接照搬严格折扣收缩结论，计算得到 Vπ 是否等于求得最优策略？

参考答案（练习完成后再看）

题 1。 F 的 save 立即终止，第一轮直接算出平均奖励 8；H 的同步新值必须读取旧表 v₀(F,1)=0，所以 v₁(H,2)=0.75×(−1)=−0.75。若先覆盖 F、随后 H 读到本轮新值，那是原地更新安排，不能称为本课两数组同步表；不等于所有原地算法无效。k 仅为计算轮次，(H,1) 执行 open 后仍只剩 h=0，没有保存机会，重复计算不会改变任务期限。

题 2。 按 H2、F2、H1、F1、零边界的顺序，v₀=(0,0,0,0,0)，v₁=(−0.75,8,−0.75,8,0)，v₂=(4.65,8,−0.75,8,0)，v₃ 与 v₂ 相同。Δ₁=8，Δ₂=5.4，Δ₃=0。K_max=2 时虽然本例 v₂ 恰好已经精确，程序仍未观察第三轮，应返回 iteration_limit，不虚构已满足 Δ₃ 检查。

πβ 独立从零表开始：v₁=(−0.75,4,−0.75,4,0)，v₂=(1.95,4,−0.75,4,0)，因为 F 的期望是 0.5×8=4，H2 为 0.75×[−1+0.9×4]=1.95。其第一轮仍不能在 H 使用同轮新算出的 4。这里是更换输入策略后进行另一次固定策略评估，不是在 πα 的一次评估中偷偷改变策略，也没有证明 πβ 是改进策略。

题 3。 不能。教学 .8 不是真实模型测量，DP 使用给定模型计算 Vπ，没有自动学习未知转移。Δ 小只表示这个模型上的迭代变化小，不能证明模型可信或真实成功率提高。应确认输入来源/权限、状态充分性、合法动作及执行反馈、真实转移与覆盖、奖励和成本单位、独立持久状态回读、初态重置、任务期限与外部截断、完整失败/取消日志及策略/模型版本；统计建模/训练成本、DP计算成本和真实推理/执行成本。

在同一模型同一固定策略下，先与完整枚举或线性方程核对计算；真实行为候选可包括固定规则、监督定位和示范策略，匹配任务、输入、底层模型与预算，另做独立真实评价。γ=1 不具有同样的严格折扣收缩保证，需要终止等附加条件；本例有限预算的传播特例不能替代一般证明。Vπ 是指定策略的价值，不等于最优策略已被找到；本课研究实验仍为 NOT_RUN。
